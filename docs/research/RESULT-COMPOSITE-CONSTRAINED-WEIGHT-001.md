## 十二、结论与下一步建议

### 12.1 逐条回答任务书的问题

- **`2F` 双振幅等权**：`OWN` 超额 N3 +0.1217% / N5 +0.1889% / N10 +0.2569% / N20 +0.2222%；相对 4F 等权基线 0/4 档更优（Δ = -0.2858% / -0.1246% / -0.0905% / -0.0098%）；四档平均同号率 `0.906`；梯度「非单调」。
- **`3F` 双振幅+量比等权**：`OWN` 超额 N3 +0.3812% / N5 +0.3870% / N10 +0.3187% / N20 +0.2162%；相对 4F 等权基线 1/4 档更优（Δ = -0.0263% / +0.0735% / -0.0286% / -0.0158%）；四档平均同号率 `1.000`；梯度「非单调」。
- **`4F-W` 四因子加权 35/35/15/15**：`OWN` 超额 N3 +0.3163% / N5 +0.3079% / N10 +0.3145% / N20 +0.2292%；相对 4F 等权基线 0/4 档更优（Δ = -0.0912% / -0.0056% / -0.0328% / -0.0028%）；四档平均同号率 `0.969`；梯度「非单调」。

### 12.2 权重倾斜是否值得继续做
**不需要**在权重方向上继续做搜索。理由是机制性的、不是「这一组没调好」：

1. 本轮唯一真正改变权重的方案（`4F-W`，35/35/15/15）在**四档上全部劣于等权基线**（ΔN3 `-0.0912%`、ΔN5 `-0.0056%`、ΔN10 `-0.0328%`、ΔN20 `-0.0028%`）—— 把权重向证据更强的两个因子倾斜，**没有**换来头部改善。
2. 这是**唯一的先验权重方向**（「证据强的因子给更多权重」）。若连这个方向都变差，剩下的「搜索方向」只能是**在同一批已读数据上拟合出来的**，属二次拟合。
3. 2F / 3F 与 4F 等权基线的差异（见 §六）主要来自**成员集合**而不是权重：成员集合变化改变的是「选哪些因子」，权重变化只是在**同一个成员集合内部重新分配**。本轮结果显示，前者的杠杆远大于后者。

### 12.3 是否进入新时间窗口 / OOS 验证

**建议：进入。** 但必须先补一个前置条件，顺序不能颠倒：

1. **P0（前置，必做）——先把本轮与前两轮的结论用「同一批已读数据」这件事隔离掉。**
   三方案的成员集合（`maxAmplitude` / `meanAmplitude` / `t1VolumeRatio` / `limitGap`）全部来自 `RESULT-SINGLE-FACTOR-V1-12F-001.md` 与 `RESULT-12F-TOPN-002.md` 的**同一批年份**，因此本轮的「头部 `POSITIVE`」**天然带有选择偏差**。
2. **P1 —— 新时间窗口 / OOS 切分**：把当前窗口按「时间」切开，用**先到的那一段**冻结成员集合与权重口径，只在**后到的那一段**读结果。⚠️ 本仓的 `Dataset v5` 是同一份数据，切窗口需要新建 `datasetVersion` 或按年份过滤；建议做法是**按年份切**（例如以 2023 年末为界），把 2019–2023 当「选择段」、2024 以后当「验证段」——这样不需要新数据，只需要**改变读取窗口**，且切分点是事先宣布的、可审计的。
3. **P2 —— 只有在 2 的 OOS 段上三方案仍保持头部 `POSITIVE` 且仍优于 12F 等权**，才值得讨论「组合排序键是否具备实用价值」。在此之前，本组结果一律只能作为**探索性**记录。
4. **不建议**同时开启「权重搜索 + 新因子 + 换坐标」多条线：每多一条线，多重比较的假阳性期望就多一分，而本轮判定基数已经在数百量级（§十一）。

## 十三、限制与窗口限定

1. ⚠️ **本轮三个 Run 与基线都取自同一窗口、同一批事件**（2019 起的全部首板回踩候选）⇒ **不是 OOS**，任何「更好 / 更稳」都只是**同一份数据上的样本内比较**。
2. ⚠️ **成员集合是事后挑的**：4 个因子由「对齐臂至少一档 `POSITIVE`」筛出（`RESULT-12F-TOPN-002.md`），本轮又在其上做 2F / 3F / 4F-W 的组合与权重预设 ⇒ **选择偏差无法从结果内部估计**。
3. ⚠️ **基准是「当日池等权」不是指数**：正超额 = 平均意义上优于随机抽签，**不等于跑赢市场**。池内所有候选都是首板后回踩股票，系统性下跌段会同时压低组合与基准。
4. ⚠️ **累计净收益 / 最大回撤是复利描述量**（每个决策日一单位资金，等权），不是实盘资金曲线；最大回撤为全窗口复利回撤，不同 N 的交易日集不同 ⇒ 跨 N 比较回撤不严格可比。
5. ⚠️ **`limitGap` 的方向属「先验未验证」**（`priorVerified = false`），它在 4F-W 中占 15% 权重；`t1VolumeRatio` 仅一档 `POSITIVE` ⇒ 两个「弱成员」的权重口径本身带有主观性，本轮只测了**一个**预设值（35/35/15/15）。
6. ⚠️ **模板不对「档位之间的差」出 CI** ⇒ §九 的梯度、§六 的 Δ 都**没有**置信区间，只能作为描述性形状，不能声称「某档显著优于另一档」。
7. ⚠️ **等权 vs 自定义权重的浮点路径不同**：`EQUAL` 走 `(Σx)/n`，`CUSTOM` 走 `Σw·oriented`；桶位分在横截面上大量**精确同值**，1 ULP 即可改变同值 tie-break ⇒ `4F-W` 与 `4F-EQ` 的差异中，理论上有极小一部分来自浮点路径而非权重语义。（本报告未对该项做分离实验；若需严格归因，应补一个「等权但改走 `CUSTOM` 路径」的对照。）
