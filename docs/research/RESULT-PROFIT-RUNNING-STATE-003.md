> 目标：只回答当前深度回撤右尾股票池是否适合采用“盈利激活后，再等待慢速趋势破坏确认退出”的框架。
> Dataset: `first_limit_pullback` / `datasetVersionId=660001`。固定池：`D20 < -10% && MA20Slope <= 0`；T+5 收盘形成池，T+6 开盘入场，T+6~T+20；严格 PIT。未修改首板、3F、Top3、仓位或策略，未创建 Candidate。

## 5. 重点年份

- **2020**：三个激活组的连跌2日和破MA10均值均低于 T+20；该年不适合采用慢速退出框架。
- **2023**：样本很小，+10% 激活组两个慢速确认高于同年 T+20，但 +15% 组并未一致占优；不能据单年选择。
- **2025**：+5% / +10% 激活组慢速确认均低于 T+20，+15% 组接近但未超过；右尾年份仍被退出截断。
- **2026**：+5% / +10% / +15% 组的慢速确认均小幅高于 T+20，但改善幅度有限，且方向不跨年度稳定。

## 6. 框架判断

### 6.1 慢速确认相对立即固定止盈

在三个激活状态中，两个慢速确认的均值均高于“达到目标立即退出”：

- +5% 立即退出净收益 4.80%，连跌2日 6.77%，破MA10 6.13%。
- +10% 立即退出净收益 9.80%，连跌2日 12.01%，破MA10 11.72%。
- +15% 立即退出净收益 14.80%，连跌2日 15.77%，破MA10 15.70%。

所以“激活后继续持有，再等待确认”比立即止盈更接近 MFE。

### 6.2 慢速确认相对固定 T+20

但两个慢速确认没有稳定优于 T+20：

- +5%：连跌2日 / 破MA10 比 T+20 低约 1.07pp / 1.71pp。
- +10%：低约 0.50pp / 0.79pp。
- +15%：低约 0.23pp / 0.30pp。

同时，+20% 大赢家保留率显著下降：

- +5%：T+20 47.51%，连跌2日 32.84%，破MA10 23.63%。
- +10%：T+20 47.51%，连跌2日 36.82%，破MA10 35.07%。
- +15%：T+20 47.51%，连跌2日 40.30%，破MA10 40.80%。

激活越晚，保留率越高，说明晚激活确实更接近真正右尾；但仍不足以解决慢速确认提前卖出大赢家的问题。

### 6.3 两个确认的分工

- `连续2日收盘下降`：在 +5% / +10% 状态下均值更高、捕获率更高，适合作为较早阶段的平衡型确认。
- `收盘跌破MA10`：在 +15% 状态下保留 +20% / +30% 大赢家的能力略好，适合作为更晚阶段的慢确认。
- 但这是描述性分工，不是规则组合，也不是择优结论。

## 7. 最终回答

**当前右尾股票池尚不适合直接采用“盈利激活后、趋势破坏确认退出”作为策略框架。**

更准确的结论是：

- 它明显优于“达到目标立即固定止盈”，因为给利润留下了继续扩张的空间；
- 但它没有稳定优于固定 T+20，平均值、MFE 捕获率和 +20%/+30% 大赢家保留率均明显更低；
- 激活越晚，退出结果越接近 T+20，但样本更少，且仍会牺牲大量大赢家；
- 2020/2023/2025/2026 的方向不一致，不能从单年结果反向选择退出规则；
- 因此只应保留为研究框架，重点继续研究“如何识别上涨已经结束”，而不是把现有两个慢速确认直接产品化。
