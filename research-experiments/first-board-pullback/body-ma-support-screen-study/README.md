# 首板实体与均线支撑筛选研究

## 筛选条件

- 首板日高开不超过 `2%`。
- `T+1..T+5` 不触及涨停价或跌停价。
- `T-10` 内没有前次涨停。
- 默认排除首板一字板。
- 默认按事件日 / `eventId` 确定性扫描最多 `20,000` 个 v5 事件；结果中明确输出
  `datasetEventCount` 和 `unscannedEventCount`。

## 支撑分组

以下条件互相重叠，不作为互斥分类：

1. `T+1..T+5` 收盘不破首板实体顶。
2. `T+1..T+5` 收盘不破首板实体 1/2。
3. `T+1..T+5` 收盘不破首板实体底。
4. `T+1..T+5` 收盘不破 MA5。
5. `T+1..T+5` 收盘不破 MA10。
6. `T+1..T+5` 收盘不破 MA20。

实体定义：

```text
实体顶 = max(首板 open, 首板 close)
实体底 = min(首板 open, 首板 close)
实体 1/2 = (实体顶 + 实体底) / 2
```

均线均包含当前交易日收盘。

## 入场与退出

- `T+6` 开盘入场。
- 主结果按实际 `holdingDay=1..15` 展开。
- 不比较固定 `T+10/T+20` 单点。
- 同时输出全样本和 `commonSample`。
