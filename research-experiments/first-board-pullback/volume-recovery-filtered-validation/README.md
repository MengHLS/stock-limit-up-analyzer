# 成交量恢复与组合过滤验证

## 冻结规则

- 严格收盘涨停首板。
- 首板实体高度 `(close-open)/close > 0.1%`。
- 首板换手率 `< 10%`。
- `T+1..T+5` 首次收盘回撤达到首板收盘下方 `100bps`，且未跌破首板开盘价，次日开盘买入。
- 买入后价格收盘跌破首板开盘价，下一可卖开盘退出。
- T+5 收盘确认 `T+1..T+5` 最大成交量未恢复到 T日成交量的 `100%`，则 T+6 可卖开盘退出。
- 否则持有到 T+10 收盘。
- 往返成本固定 `20 bps`。

## 对照

- `FILTERED_PRICE_EXIT`：经过实体 / 换手过滤，但只使用价格退出。
- `ALL_VOLUME_EXIT`：不做实体 / 换手过滤，使用价格 + 成交量恢复退出。
- `FILTERED_VOLUME_EXIT`：全部过滤 + 价格 + 成交量恢复退出。

## 声明

本实验是 v3 / v4 时间切片复核，不是未来未读数据 OOS。通过后仍需要新的独立 Holdout。
