## 1. FACT

### 1.1 冻结定义的时间窗口（**结构事实**）

| 因子 | 冻结定义 | 所需数据 | 决策点可用性 |
|---|---|---|---|
| **`maxAmp5`** | **事件窗 rd11~15 的日振幅最大值** | `post` rd11, rd12, rd13, rd14, rd15 | 🔴 **T=0 不可用** · ✅ T+15 可用 |
| **`avgAmp5`** | **事件窗 rd11~15 的日振幅均值** | 同上 | 🔴 **T=0 不可用** · ✅ T+15 可用 |

**振幅口径（沿用既有实现，未改动）**：`amp(rd) = (post[rd].high − post[rd].low) / close(rd−1)`，其中 `close(rd0) = prefix[0].close`

> 📌 该定义已在 `RESULT-POST-EVENT-STATE-TIMESCALE-STABILITY-001` §3.3 与 §7 登记为 **「rd11~15 滚动窗口」**，与旧 `maxAmplitude`/`meanAmplitude`（**rd1~5 固定窗口**）**不是同一因子**。

### 1.2 ✅ 只读探针实测（Dataset `780004`）

| 检验 | 结果 |
|---|---|
| **`prefix.relativeDay` 范围** | **`[−10, 0]`**（11 个相对日 · 各 58,707 ~ 58,983 行） |
| **`post.relativeDay` 范围** | **`[1, 80]`**（80 个相对日） |
| **`post` 是否有 rd=0** | 🔴 **无**（T 日 OHLCV 在 `prefix.rd=0`） |
| **post rd1 距事件日（自然日）** | min **1** / max **11** |
| **post rd5** | min **7** / max **17** |
| **🔴 post rd11** | **min 15 / max 26** |
| **🔴 post rd15** | **min 21 / max 32** |

> ## 🔴 **⇒ 在 T=0 决策点上，`maxAmp5`/`avgAmp5` 所依赖的 rd11~15 五根 bar 位于【未来 15 ~ 32 个自然日】**

### 1.3 ✅ 平台结构级闸门（**权威依据**，路径 + 符号名）

| # | 位置 | 内容 |
|---|---|---|
| 1 | `server/datasetRegistry/path.ts` | post 收集条件 `if (bar.relativeDay <= 0) continue;` ⇒ **post 从 rd1 起**；prefix 收集条件 `if (row.relativeDay <= 0) prefix.push(row);` ⇒ **prefix 至 rd0 止** |

| 4 | `server/researchExperiments/datasetPort.ts` | **「rd ≥ 1 → `usesForwardData` 结构级闸门」**；**「🔴 结构级 PIT 闸门：未声明 `usesForwardData` 时【调用即抛】」**（`禁止读取事件日之后的数据（rd=...）`） |

> ## 🛑 **⇒ 读 `rd ≥ 1` 属 `usesForwardData` 领域；而平台规则明确：此类特征【禁止参与策略决策】**

## 2. ATTRIBUTION

### 2.1 为什么 T=0 与 T+15 的比较**不可能**公平进行

| 障碍 | 内容 | 可否绕过 |
|---|---|---|
| **① 定义障碍（决定性）** | `maxAmp5`/`avgAmp5` **本身就是 rd11~15 的函数** ⇒ 在 rd0 处**未定义** | 🛑 **不可绕过** —— 绕过 = 读取未来数据（平台结构级禁止） |
| **② 不可用 T=0 类比替代** | 若改用 prefix rd−5..−1 的振幅，那是一个**新因子定义**（事件**前**振幅），语义不同 | 🛑 **任务明确禁止修改因子定义 / 新增因子** |
| **③ 执行口径** | T=0 决策的入场口径（rd1 `open`）在程序历史中**存在**（旧 SHORT/MEDIUM/LONG） | ✅ 可绕过 —— **但障碍①使其实质无意义** |

> ## 🔴 **⇒ 障碍① 是【定义层面】的，不是数据层面或方法层面的 ⇒ 不存在「公平比较」的构造方式**
> ## **⇒ 这正是任务所定义的 `C. T0_INCONCLUSIVE`：「**定义**无法进行严格公平比较」**

### 2.2 确切结论：`maxAmp5`/`avgAmp5` 的**决策点下界**

由定义直接推出：

```text
maxAmp5 / avgAmp5 需要 post rd11~15
        ⇒ 决策点 D 必须满足  D ≥ 15
        ⇒ 可用决策点：rd15, rd16, ..., rd80
        ⇒ 不可用决策点：rd0, rd1, ..., rd14
```

| 决策点 | `maxAmp5`/`avgAmp5` 是否可用 | 说明 |
|---|:---:|---|
| **rd0（T=0，事件日）** | 🔴 **不可用** | rd11~15 在未来 |
| rd1 ~ rd14 | 🔴 **不可用** | 至少 rd15 仍在未来 |
| **rd15（T+15，本程序一直使用）** | ✅ **可用** | rd1~15 全部 ≤ 决策日 ⇒ **PIT 合法** |
| rd16 ~ rd80 | ✅ 可用 | 但会引入冗余（rd16 起有 post 数据但定义不消费） |

> ## 📌 **⇒ 本程序此前所有 post-event state 轮次均在 rd15 决策，属【PIT 合法】** —— **不是因为放松了 PIT，而是因为决策点 = rd15 ≥ rd15**

### 2.3 与冻结 LONG-4 的对比（**同面板、同为「因子可用性」问题**）

| 因子族 | 定义所依赖的数据 | **T=0 可用？** |
|---|---|:---:|
| **冻结 LONG-4**：`amountPercentile`（事件日成交额日内分位）· `limitGap`（`daysSincePreviousLimit`）· `historyLimitCount` · `turnover` | **全部为事件日字段**（`prefix.rd=0` + `event` 表） | ✅ **可用** |
| **后事件状态族**：`maxAmp5` / `avgAmp5` | **post rd11~15** | 🔴 **不可用** |
| 旧 `maxAmplitude` / `meanAmplitude` | post **rd1~5** | 🔴 **亦不可用**（rd1~5 在 rd0 之后） |

> ## 🎯 **⇒ 划分线的确切位置：「事件日字段」= T=0 可用；「任何 post 窗口统计」= T=0 不可用**
> ## 📌 **本轮【未发现】任何 T=0 可用的后事件状态因子**（该族按定义建立在 post 窗上）

### 2.4 一个附带假设（**登记为推断，未验证**）

`ATTRIBUTION-001` 实测 **冻结 LONG-4 在 T+15 决策点近乎无 Alpha**（ΔmeanExcess **+0.197pp / +0.061pp**）。

> ⚠️ **假设（INFERENCE，非 FACT）**：LONG-4 是**事件日（T=0）因子**，其信息在到达 rd15 前可能**已被市场消化** ⇒ 在 T+15 重评估时失效。
> 🔴 **本轮【未验证】该假设** —— 需 T=0 决策点下的 LONG-4 实测（**本轮未运行**，任务未要求且不在本轮范围）。
