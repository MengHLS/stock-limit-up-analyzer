# 首板回撤：入场对齐退出协议 V2

> 状态：**FROZEN**
>
> 协议 ID：`first-board-pullback-entry-aligned-exit-v2`
>
> 协议版本：`2.0.0`
>
> 冻结日期：`2026-09-23`
>
> 基础协议：[`FIRST-BOARD-PULLBACK-EXIT-PROTOCOL-V1.md`](FIRST-BOARD-PULLBACK-EXIT-PROTOCOL-V1.md)
>
> 变更规则：V1 不原地修改。V2 只增加 `T+1..T+5` 涨跌停触达过滤，并沿用 V1 的入场、持有日、统计和禁止事项。

## 1. V2 增量

V1 的 `FB_CORE_EX_ONE_WORD_V1` 继续保留。

V2 新增主事件池：

```text
FB_CORE_EX_ONE_WORD_NO_LIMIT_TOUCH_V1
```

进入该事件池必须同时满足：

1. 满足 V1 的 `FB_CORE_V1`；
2. 排除首板日一字板；
3. `T+1..T+5` 路径完整、未停牌且 OHLC 合法；
4. `T+1..T+5` 任一日出现以下任一条件时必须剔除：

```text
high >= limitUpPrice
low <= limitDownPrice
```

浮点比较容差固定为 `1e-9`。

`limitUpPrice` 与 `limitDownPrice` 必须使用该日 Dataset 中的交易所涨跌停事实，不得用固定 `10%` 重新计算。

## 2. 入场与退出

V2 当前实现使用：

- 决策时点：`T+5` 收盘；
- 入场：`T+6` 开盘，要求 `canBuyAtOpen=true`；
- 持有日：从实际入场日起算 `holdingDay=1..15`；
- 对应事件日：`T+6..T+20`；
- 每个目标退出日不可卖时，使用其后第一个可卖收盘；
- 往返成本：`20bps`。

`holdingDay=5`（事件 `T+10`）是主参考锚点，`holdingDay=10`（事件 `T+15`）是辅助锚点。`holdingDay=15`（事件 `T+20`）只作为长尾参考，不得作为唯一结论端点。

## 3. 共同样本

所有曲线行必须使用同一事件集合：

- `T+1..T+5` 路径完整且无涨跌停触达；
- `T+6..T+20` 行情完整且未停牌；
- `T+6` 开盘可买；
- 每个目标退出日在最迟 `T+20` 前存在可卖收盘。

不满足条件的事件逐条进入剔除账，不得在不同持有日之间改变样本集合。

## 4. 输出

至少输出：

- 均值；
- 去最高 5% 后均值；
- 中位数；
- 胜率；
- P5 / P25 / P75 / P95；
- 日期聚类 Moving Block Bootstrap 95% CI；
- MFE / MAE；
- 最大收盘回撤；
- 实际退出延迟日和当日可卖率；
- 持有期间曾达到 `-5%/-2%/+2%/+5%` 的比例。

- 不得从 `holdingDay=1..15` 中选择收益最高的一天；
