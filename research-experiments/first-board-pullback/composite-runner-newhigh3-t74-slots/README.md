### 读法：**「多买」确实多抓到了超级票，但代价是资金被摊薄 + 多买的票整体亏钱**

- `slots-3-5`（只多买第 3 名、仓位上限不变）⇒ **≥ +50% 笔数一条没多**（9→9），总收益 **−32pp**：
  ⇒ 第 3 名虽然有同档的「曾经涨过」密度，但在**同一资金预算下**多买一只 = 少给赢家仓位，净效果为负。
- `slots-3-8` / `slots-3-12`（同时放开仓位）⇒ 超级票笔数确实从 9 → **11 / 15**，
  但总收益 **151% → 16% / −1.5%**，回撤 43% → 56% / 54%：**多出来的仓位主要买到了亏损票**。
- 四条臂的**最大单笔收益几乎完全相同（+130.4%）**⇒ 真正的大赢家始终是那几只，**放开名额并没有抓到新的同级别赢家**，只是把它们稀释了。

### 由本次结果推出的关键疑问（下一步要测的）

召回诊断说 rank1/rank2 里各有约 10.6% / 11.7% 的票**曾经涨过 +50%**；策略实际买入 1037 只 rank1 + 392 只 rank2，
按同比例估算 ≈ **156 只**入场票曾有过 ≥ +50% 的潜在空间，但**只有 9 只实现了 ≥ +50%**。
⇒ 缺口极可能不在「买入名单」，而在**退出/持有政策把赢家提前砍掉**（现役：盘中 −5% 止损、盈利后 5% 回撤止盈、
5 日时间退出 + 仅对满足 NEW_HIGH_3 的仓位延长到 74 日）。
