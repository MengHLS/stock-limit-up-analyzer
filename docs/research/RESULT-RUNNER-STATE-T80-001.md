# RESULT-RUNNER-STATE-T80-001

> 目标：基于固定 `first-limit-pullback-3f-top3@1.62.1` 实际成交样本，研究 T+10/T+15/T+20 当时状态能否区分 T+21～T+80 后续大赢家。只做单变量分层，不组合条件、不优化阈值、不设计 Exit、不创建 Candidate。

## 0. 固定样本与 PIT

- 实际成交样本：1,359 笔，来自 `RESULT-3F-TOPN-3-V1_62_1-T80-001` 的原 1.62.1 成交集合。
- 数据：真实 T+80 dataset `datasetVersionId=750001`（v7，post rd1..80）。
- 状态截点：T+10 / T+15 / T+20；每个截点仅使用 `rd<=cutoff` 的数据。
- 标签：从 `cutoff+1` 到 `rd80`；T+20 截点对应 T+21～T+80。
- 后续指标：MFE、MAE、+20% / +30% / +50% / +80% 达成率。
- 连续变量使用预先固定的经济分箱 B1～B5；二值变量 TRUE/FALSE；连续创新高/连续收低按 0 / 1 / 2+。
- 因本研究不设 +10/+15 activation，连续创新高/连续收低从实际成交日开始计数；其余变量口径与 RUNNER-STATE-RESEARCH-004 一致。
- 分箱不根据结果调整。

## 4. 重点结论

1. **T+10 最强的是“2日创新高”和“连续收低 2+”。** 前者在后续 MFE 与 +20% 上都更优；后者均值 MFE 不占优，但 +20% 达成率更高，更像“先回撤、后反弹”的右尾状态。
2. **T+15 仍支持“2日创新高”，并出现“连续创新高 2+”的增量。** 连续创新高 2+ 的顶部覆盖约两成，后续 MFE 较高，但 +20% 稳定性弱于 MFE，应按 Runner 识别而非胜率信号理解。
3. **T+20 最强的是“3日创新高”。** 其覆盖率合理、MFE 与 +20% 方向在多个年度同向，是 T+20 最值得继续跟踪的单变量状态。
4. **连续价格/收益变量的 B5 尾部覆盖过小，不能作为主结论。** 近2/3日收益、近5日高点距离等虽有大差值，但顶部覆盖约 3%～4%，只能作为后续稀疏条件提示。
5. **没有组合条件、Market Regime 或 Exit 规则。** 本轮只证明若干单变量状态值得进入下一轮 Runner 状态验证；尚不构成可交易策略。

## 5. 最终 Runner 状态候选结论

优先继续验证的单变量状态：

- `T+10: newHigh2 == TRUE`
- `T+10: consecutiveLowerCloses >= 2`（仅右尾标签）
- `T+15: newHigh2 == TRUE`
- `T+15: consecutiveHigherHighs >= 2`
- `T+20: newHigh3 == TRUE`

这些状态在 T+21～T+80 标签下表现出跨年度方向一致性或合理覆盖，应作为下一轮单变量 Runner 状态验证候选，而不是正式 Exit 或 Candidate。
