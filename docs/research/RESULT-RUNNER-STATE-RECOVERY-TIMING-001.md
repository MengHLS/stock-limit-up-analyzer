# RESULT-RUNNER-STATE-RECOVERY-TIMING-001

> 目标：验证 CLC2 后首次 `NEW_HIGH_3` 恢复在**实际恢复当天**是否携带增量信息。
> 固定：dataset `first_limit_pullback` / `datasetVersionId=660001`；execution projection 沿用已验证 T80（v5 官方行 + 选中事件 v7 rd17..80）；固定池 `D20 < -10% && MA20Slope <= 0`；共同锚点=首个 CLC2 日；复用冻结 `NEW_HIGH_3` 定义。
> 不搜参数、不创建 Candidate、不修改 Strategy、不做 Exit/OOS/WFA。
> 报告由 `scripts/reportRunnerStateRecoveryTiming001.mts` 从落盘 evidence 机械生成。

| **固定日历** `fixedCalendar` | 在同一日历位置（锚点+D 收盘）比较：截至该日**已恢复** vs **尚未恢复**；两组前向收益都从**同一个锚点+D 日收盘**起算 | 回答「在第 D 日这个信息时点上，恢复状态是否有信息」——**主口径** |

## 6. 结论

1. **`NEW_HIGH_3` 在实际出现当天确实产生信息，但方向取决于恢复窗口。** 固定日历口径下，T20 差值（已恢复 − 尚未恢复）：**D2–D8 为负**（约 −1.1 ~ −5.4pp），**D9 ++0.23pp、D10 ++0.90pp 转正**（D1 样本仅 15/16 条，不作依据）。
2. **「快速恢复优势」在控制日历时间后不再成立。** 上一轮的速度单调梯度主要来自**起点日历不同**：corr(恢复延迟, 恢复日后 T20) = -0.005 / -0.008 ≈ 0；按恢复日看，**D6–D9 反而是最强的当日恢复窗口**（P10 T20 均值 +5.15 ~ +6.72%），而非 D1–D3。
3. **优势是否来自恢复时点而非价格位置？两者高度纠缠。** 固定日历下「尚未恢复」样本的锚点→D 涨幅显著更低、相对 MA10 更靠下（仍有更多上涨空间），因此早段差值可能由**剩余空间**驱动；到 D9–D10，已恢复样本相对 MA10 已回到正值，仍未恢复样本仍显著落在其下方，此时恢复状态才转为正向。**不能把相关性直接解释为因果。**
4. **最值得进入后续研究的恢复窗口是 D6–D10**（当日恢复口径 T20 均值最高），并应以**固定日历**口径复核；D1–D5 的「恢复优势」在控制日历后不成立，不建议作为主线。
5. **本轮不产生正式 Exit/持有规则。** 只回答恢复日是否携带信息，不做 Exit/OOS/WFA、不创建 Candidate。

### 明确边界

- 主结论基于**固定日历**口径（两组同起点）；`perDay` 与「从各自恢复日起算」的口径存在起点日历差异，已单独标注，不作主结论。
- 「已恢复 vs 尚未恢复」在固定日历下同时伴随价格位置差异（尚未恢复位置更低），**恢复状态与剩余空间无法完全分离**，因此结论限定为相关性证据。
- 单状态、未组合评分、未搜阈值、未做 OOS/WFA；2026 为不完整年度，只作方向参考。
