# 首板后无涨跌停与振幅研究

## 研究问题

首板 T 后的 T+1..T+5：

1. 期间是否触及涨停或跌停；
2. 每日振幅 `(high-low)/preClose` 的大小；

这两个状态与 T+5 之后的固定视界收益有什么关系。

## 决策与收益

```text
上下文：T+1..T+5
入场：T+6 开盘
退出：T+10 / T+15 / T+20 收盘
```

如果 T+1..T+5 任意一天 `high >= limitUpPrice` 或 `low <= limitDownPrice`，归入
`HAD_LIMIT`；否则归入 `NO_LIMIT`。振幅分桶只在 `NO_LIMIT` 内比较。

## 振幅分桶

- `<2%`
- `2% ~ 4%`
- `4% ~ 6%`
- `6% ~ 8%`
- `>=8%`

## 已知边界

- 涨跌停判定使用当日 high/low 与交易所涨跌停价；
- 停牌、T+6 开盘不可买会导致后续视界缺失；
- 只有日线，不含盘中路径和逐笔成交；
- 尚未做日期聚类 Bootstrap、Holdout 或市场状态中性化；
- 当前 Dataset 只覆盖沪深主板。
