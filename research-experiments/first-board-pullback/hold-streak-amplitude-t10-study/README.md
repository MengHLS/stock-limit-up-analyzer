# 首板涨停价守线 × 振幅 T+6→T+10 研究

## 口径

- 首板收盘价严格等于交易所涨停价。
- 守线 streak：从 T+1 开始连续 close ≥ 涨停价，或 low ≥ 涨停价。
- 平均振幅：T+1..T+5 `(high-low)/preClose` 的均值。
- 最大振幅：T+1..T+5 的单日最大振幅。
- 入场：T+6 开盘。
- 主退出：T+10 收盘。
- 辅助：+2% / -2% 首次收盘到达后的止盈止损规则。

## 振幅分桶

- 平均振幅：`<4%`、`4%~6%`、`6%~8%`、`≥8%`
- 最大振幅：`<8%`、`≥8%`

## 目的

验证“连续不破涨停价”的收益是否在剔除高振幅样本后仍然存在。
