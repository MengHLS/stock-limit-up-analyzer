## 9. 与上一轮 VCB 探索结果的关系（为什么 UP 看起来曾为正）

在 `BEHAVIOR-RESEARCH-VCB-001` 中，按市场状态分层的 **event-level pooled** 结果曾显示 UP 下 VCB − 非VCB = +0.43% / +0.45% / +1.40%（T+3/T+5/T+10），看起来像条件性 edge。本轮把同一 UP 子样本改成任务要求的**同日配对口径**后：

- **pooled 口径仍然为正**（+0.430% / +0.453% / +1.396%）——与上一轮一致，因为事件集合相同；
- **逐日配对口径为负**（-0.078% / -0.129% / -0.496%）；
- 二者差异来自**事件聚集**：UP∩VCB 事件集中在少数 UP 月份/日子（2020、2023、2024），这些日子 UP 全池表现较弱，而事件等权的 pooled mean 被这些聚集拉高；按天等权的配对检验显示，在典型的 UP 交易日，UP∩VCB 并不跑赢同日 UP 非VCB。
- 因此上一轮的 UP pooled 正号不是可复现的 edge，本轮按固定 Gate 判 **NO_BEHAVIOR_EDGE**。

## 11. 结论解读

1. **UP 市场状态不能救活 VCB。** 在 UP∩VCB 上，逐日同日配对 spread 四个期限全部为负（-0.010% / -0.078% / -0.129% / -0.496%）；min1 口径更强（-0.095% / -0.268% / -0.407% / -0.686%，T+3 起显著为负）。VCB 在 UP 全池中的平均收益百分位只有 0.466～0.484。
2. **pooled 正号是聚集效应，不是 edge。** event-level pooled spread 在 T+3/T+5/T+10 为正（+0.430% / +0.453% / +1.396%），与上一轮按 regime 的观察一致；但按天等权的配对检验为负。原因是 UP∩VCB 事件集中在 2020、2023、2024 等少数 UP 时段，事件等权把这些时段放大，而典型 UP 交易日 VCB 并不占优。
3. **2024 单年主导。** 分年正 spread 只有 T+3/T+5/T+10 的 4/8 年（2020、2023、2024、2026）；2024 T+10 单年 +2.706%；剔除 2024 后 T+10 正年份降为 3/7。T+1 仅 2/8 年正。
4. **尾部集中。** T+5 去掉最高 1% 后 mean 从 +0.304% 转为 -0.090%；T+5 的 50% 总收益只来自 41 只股票。收益并非广泛分布。
5. **去重后不成立。** 连续命中压缩后四期限 spread 全为负；每股每年去重后仅 T+5 微正（+0.031%）。
6. **唯一通过的 C4**（pooled 去上下 1% 后为正）与 C1/C2/C3/C5 的方向冲突，属于事件池化口径的产物；按预定 Gate，不足以判 BEHAVIOR_EDGE_FOUND。

**→ 终止「UP + VCB」假设；不做该行为内部的排序因子 / TopN / 参数优化 / OOS / WFA / Robustness；继续研究下一个独立市场行为。**
