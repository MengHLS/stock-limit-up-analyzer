# 动态入场后每日路径分布研究

## 状态机

- `T+1..T+5` 首次回撤 100bps，且未跌破首板开盘价，次日开盘买入。
- 买入后收盘跌破首板开盘价，则下一可卖开盘退出。
- 否则持有到 T+10 收盘。

## 路径指标

- 每日标记收益：相对实际入场开盘价。
- 每日收益分位数：P5/P25/中位/P75/P95。
- MFE / MAE 及其发生日。
- 首次收盘触及 `-5%/-2%/+2%/+5%` 的比例和中位到达日。
- 按实际入场日和持有日拆分。

## 已知偏差

- 路径在动态退出日停止。
- MFE/MAE 用日线高低点估计，不是可成交盘中价格。
- 未实现盘口排队、滑点和部分成交。
