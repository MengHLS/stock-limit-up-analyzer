## 3. “累计涨幅 ≥100%”的精确定义

本轮采用两个 Dataset-native 字段：

- 基准价：`ds_first_limit_pullback_prefix.relativeDay=0` 的 `close`，即首板事件日收盘价。
- 后续高点：`ds_first_limit_pullback_post.high`，只取 `relativeDay >= 1` 且 `barPresent=1`。

精确定义：

```text
max( high(relativeDay=1..80) ) / event_close - 1 >= 100%
```

该定义不是单日涨幅，而是从事件日收盘这个历史基准价，到事件后 80 个交易日内某个历史高点的累计涨幅。选择事件日收盘作为基准的原因：

1. 它是 Dataset 内的 `prefix.relativeDay=0`，天然 PIT 安全；
2. 与 Dataset 已有 `highFromEventClose` / `closeFromEventClose` 路径语义一致；
3. 不依赖主观选择“某一段最低点”，可在未来复现。

## 4. 成功组 / 失败组划分方式

- T*：第一次 `high / event_close >= 2` 的交易日。
- 观察锚点：T* 收盘价。
- 成功组：`close(T*+20) > close(T*)`。
- 失败组：`close(T*+20) <= close(T*)`。
- 缺少 T*+20 的样本：单独标记为 `CENSORED`，不进入成功/失败比较。

因此“成功”在本报告中表示：**首次达到 +100% 后的 20 个交易日内，收盘没有跌破 T* 收盘**。它不是策略收益定义，也不代表可交易收益。

## 11. 关键分化行为

1. **前期强势本身不是明显分水岭。** 全历史成功组与失败组 P20/P40 中位数几乎相同（17.8% vs 17.9%、21.4% vs 21.2%）；P60 仅相差约 3 个百分点。
2. **分化主要出现在 T* 后的 T+5 至 T+10。** T+1/T+3 两组几乎相同；到 T+5 成功组中位数约 +17.8%、失败组约 +8.0%；T+10 为 +25.9% vs +1.9%；T+20 为 +35.8% vs -5.9%。
3. **失败组的核心特征是 T* 后出现更深的 MAE。** 全历史成功组 MAE 中位数约 -4.9%，失败组约 -16.4%；MFE 为 +62.3% vs +41.0%。
4. **早期创新高本身不区分成功/失败。** 两组的首次创新高中位数都在 T* 后第 1 日；失败组甚至更早出现第一次放量。
5. **放量不是稳定的正向条件。** 全历史失败组的 T* 量比和 T* 后最大量比反而更高。放量可能与情绪加速/衰竭同时出现，不能单独解释延续。
6. **成功的关键更像“T* 后不深度破坏，并在 T+5~T+10 继续走高”。** 这是描述性 Pattern，不是交易信号。

## 12. 有证据支持的 Pattern

- **Pattern A：事件日基准 → 未来高点 ≥100% 的股票，普遍伴随事件日放量和多次涨停，但前期 20/40/60 日强度并不稳定。** 最近样本前期 40/60 日中位数甚至为负。
- **Pattern B：成功与失败的分化不在 T+1/T+3，而在 T+5/T+10。** 全历史 T+5 开始出现中位数差，T+10/T+20 放大。
- **Pattern C：T* 后的 MAE 比“再次放量”更能区分两组。** 失败组 MAE 明显更深，MFE 更低。
- **Pattern D：早期创新高/重新突破前高在两组都常见。** 关键不是“有没有新的高点”，而是能否避免持续走弱。
- **Pattern E：组合画像更像“先有事件/量能，再决定能否延续”，而不是“前期已经很强”。** 前期趋势只能作为描述，不是本轮证据支持的决定因素。

## 13. 尚不能确认的 Pattern

- 不能确认“前期强势 + 成交额突然放大 + 连续涨停 + 整理/回撤 + 重新转强”是必要序列。最近样本不支持“前期 40/60 日强势”这一普遍前提。
- 不能确认“再次放量 = 后续延续”。全历史失败组量比更高，最近样本方向相反。
- 不能确认市值、行业、题材与延续之间存在稳定关系；市值数据缺失严重，行业标签只具描述性。
- 不能确认精确回撤阈值或“重新转强”的具体定义；本轮未做阈值优化。
- 不能确认 T* 当天的收盘价可交易；T* 可能是涨停/一字板或盘中最值不可成交。
- 全历史样本为事件级，不等于独立股票样本；同一股票重复出现会放大某些行为。

## 14. 下一轮值得验证的 Hypothesis

- **H1：T* 后前 5 个交易日的 MAE 是否比事件前 20/40/60 日强度更能区分 T+20 延续。**
- **H2：预先固定“浅回撤后再站上 T* 收盘/高点”的定义，研究它与 T+20 结果的关系；本轮不调阈值。**
- **H3：成交量是否存在非单调关系：过大的 T* 量比可能对应衰竭，而非延续。**
- **H4：用 T*+1 开盘/收盘而非不可成交的 T* 当天价格，检验执行可行性。**
- **H5：把“首次创新高”与“创新高后能否守住”分开验证，避免把早期脉冲误判为延续。**

## 15. 数据缺失与 PIT 风险

- v8 的 `preWindowDays=0`，没有 20/40/60 日前缀；前期趋势由 PIT 安全的 `stock_daily_prices` 补齐，明确在事件日切断，未读取事件日之后数据。
- 最近样本有 15/34 因 T* 后不足 20 个交易日而右删失；不能把它们当成失败组。
- `marketCap` / `floatMarketCap` 在本轮 v8 事件中不可用；`sourceCirculationValue` 只在部分事件中存在，且来自涨停记录。
- 全历史 `sector` 缺失 569/691，主题统计不具全历史代表性。
- T* 使用盘中最高价；若 T* 是一字板或触及后无法成交，T+1/3/5/10/20 收益不能直接视为可执行收益。
- 收益以收盘价计算，未统一处理现金分红、停牌、涨跌停无法成交、手续费和滑点。
- ST 排除依赖 Dataset v8 构建时的 `excludeSt=true` 与库内状态历史；状态历史置信度为 medium/UNKNOWN 的风险仍需保留。
- 本报告的未来高点、T+20 和成功/失败标签都是事后标签，不能作为实时交易条件。
- 本轮没有创建 Strategy、Candidate、Parameter Search，没有修改 DB schema 或历史数据。
