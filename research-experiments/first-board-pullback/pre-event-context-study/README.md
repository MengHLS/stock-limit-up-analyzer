# 首板前空窗期与前期涨幅研究

研究首板 T 日之前的两类上下文：

1. 距上一次涨停的交易日间隔 `daysSincePreviousLimit`；
2. `close(T-1) / close(T-n) - 1` 的前期涨幅，默认 n = 5 / 10 / 20。

## 后续观察

上下文在 T 日收盘时已知，不包含 T 日涨停本身。后续收益使用：

```text
T+1 开盘入场 → T+5 / T+10 / T+20 收盘退出
```

输出按间隔分组、前期涨幅分桶，以及“间隔 × T-10 前期涨幅”的联合分组矩阵。

## 不输出

- 最优涨停间隔；
- 最优前期涨幅区间；
- 策略、候选、参数排序；
- 统计显著性结论。

## 已知边界

- 无可信前次涨停记录时，间隔为 `UNKNOWN`，不伪造为无限间隔；
- 前期涨幅只用收盘价，不使用复权后价格之外的额外处理；
- 收益比较未做日期聚类 Bootstrap 或 Holdout；
- 当前 Dataset 只覆盖沪深主板。
