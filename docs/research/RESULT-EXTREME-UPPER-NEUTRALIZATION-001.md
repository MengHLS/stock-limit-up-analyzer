### 8.2 为什么 N1 与 N2 会分歧（重要）

`Q5` 的定义是**秩运算**（`neutralized score 横截面最高 20%`），而 `turnover_T` / `amp5` 的横截面分布是**重尾**的：

- **N1 用原始水平回归**：最小二乘拟合被极端值主导，残差中仍保留大量**秩**信息，因此「顶部 20%」的排序几乎没变（重叠率 60–68%）。
- **N2 直接在百分位秩空间回归**：移除了正是决定 Q5 成员身份的那部分变异（重叠率降到 40–47%）。

就「Q5 是否只是风格的代理」这个问题而言，**N2 与 Q5 的秩定义更吻合**。在 N2 口径下：`ret_5` 独立、`amp5` 与 `turnover_T` 均为风格代理。但为不掩盖分歧，本报告按**预注册规则**（两种口径一致才给确定结论）判定，故 `amp5` / `turnover_T` = `UNRESOLVED`，总 Gate = **`UNRESOLVED`**。

### 8.3 对核心问题的直接回答

> 「排除极端上端」究竟是一个独立的市场规律，还是高换手/高波动/规模等风格的代理？

**不是单一答案，取决于因子：**

1. **对动量（`ret_5`）——是独立规律**（在流动性与波动维度上）。两种中性化口径都保留 ~95–105% 的效应，t≈-10/-12，去极端与去重后仍成立，三时期方向一致。
2. **对振幅（`amp5`）——基本是风格代理**。它本身就与换手/波动高度重合（`EXTREME-UPPER` 前序任务已测：ρ(amp5, turnover_T)=0.66），控制这些风格后残差效应归零。
3. **对换手（`turnover_T`）——无法确定**，完全取决于控制变量的函数形式（水平 vs 秩）。
4. **规模维度完全未能检验**（市值数据缺失），**行业维度完全未能检验**（无 PIT 行业）。因此不能说「已证明独立于规模」。

**实践含义**：若要把「排除极端上端」作为下一阶段命题，**只应以 `ret_5`（动量）这一支为基础**；以振幅/换手构造的同名命题很可能只是「避开高波动高换手风格」的另一种说法。

## 9. 限制与风险（必须随结论一起读）

1. **规模（市值）完全不可用**：`liquidity_daily.circulationMarketCap` / `totalMarketCap` 全表 NULL。任务假设中的「独立于**规模**」这一半**本轮无法检验**，也未用任何方式补造。`lnAmt20` 只是**流动性/规模代理**，不等于市值。
2. **行业维度完全不可用**：`industry_assignments` 仅 2026-08-31 单时点快照，无历史 PIT，故未做（也未伪造）行业中性化。
3. **控制集有限且内部高度共线**：`amp5`、`turnover_T`、`vol20` 互相强相关（ρ(amp5, turnover_T)=0.66，且 100% 交易日为正）。对 `amp5` 做中性化时控制集中已含其高度相关的同族变量，残差可能被压得过窄，这是「秩口径下 amp5 效应归零」的机制之一。
4. **口径分歧本身即结论**：不能只引用 N1 或 N2 之一；总 Gate 就是 `UNRESOLVED`。
5. **未做成本 / 滑点 / 冲击成本**。前序 003 已排除「成交约束造成观测偏差」，但经济幅度（`ret_5` 的 T+5 中性化后仍 **-0.24%~-0.27%**）依然很小，未扣成本前不构成可交易优势。
6. **raw Q5 数值与 003 略有差异**（T+5 本报告 -0.253% vs 003 -0.258%）：因为本轮把比较限制在「因子值 + 控制变量均非空」的同一 eligible population（剔除 2,625 个成员日），这是为隔离中性化影响而做的预注册处理，不是数据冲突。
