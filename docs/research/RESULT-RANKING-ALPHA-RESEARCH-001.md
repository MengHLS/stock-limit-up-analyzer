## 0. Gate

```text
VCB = NO_RANKING_VALUE
BB  = NO_RANKING_VALUE
PR  = NO_RANKING_VALUE
```

**核心判据 `Top > Bottom` 不成立**：三个 feature 的 Top 桶在全部期限都**低于** Bottom 桶（BB/VCB 显著，PR 较弱）。也就是说，按行为强度排序后，最强的一批不是更强的未来收益，而是更弱的未来收益；TopN 也没有跑赢候选池整体。按任务给定的 Gate 标准，判 NO_RANKING_VALUE。

但需要如实记录：这三个 feature 具有**稳定的反向横截面区分能力**（Bottom > Top，BB/VCB 显著），并非"无区分度"。若研究问题允许反向使用排名，它们有潜在价值；但本轮按 `Top > Bottom` 的标准判定，故为 NO_RANKING_VALUE。

## 1. 预注册的连续 Rank Score（未调参）

行为本身是 0/1 条件，不能直接排序；本轮**先注册**一个连续强度分（直接取行为定义中的当日核心强度字段，不加权、不搜索）：

| Feature | Rank Score | 说明 |
|---|---|---|
| BB | `adjusted C_T / max(adjusted H over [T-60,T-1]) - 1` | 60 日平台突破强度 |
| VCB | `adjusted C_T / max(adjusted H over [T-5,T-1]) - 1` | 整理区上沿突破强度 |
| PR | `adjusted C_T / reclaimLevel - 1`（reclaimLevel=(swingHigh+pullbackLow)/2） | 回撤后重新站回强度 |

每个交易日、在 RCP-P0-v1 全池内按 score 降序排序：Top 1% / 3% / 5% / 10%、Bottom 10%、以及候选池整体（pool）。所有 score 使用 PIT-adjusted OHLC（T 日 factor=1，不引入未来 action）；执行价固定 raw T+1 Open。

**读数：**

1. **Top > Bottom 失败**：三 feature、四期限、5 个桶全部呈现"分数越高、未来收益越低"的**单调反向**关系（Top1 最负，Bottom10 最正）。BB/VCB 的反向关系显著（|t| 最高 5.13 / 4.26）。
2. **TopN 不优于池整体**：Top10 − Pool 也为负（BB -0.011%～-0.416%，VCB -0.046%～-0.548%，PR +0.012%（T+1）～-0.465%（T+10））；只有 PR 的 T+1 Top10 略高于 pool（+0.012%，t=0.80，不显著）。
3. **不是只有 T+1 有效**：反向关系在 T+1/T+3/T+5/T+10 都成立，且随期限拉长更明显——说明不是短期噪声。
4. **跨年不稳定（按 Top>Bottom 方向）**：正年数只有 1-3/8；反过来（Bottom>Top）在 BB/VCB 多数年份成立，但任务标准是 Top>Bottom，故不满足。
5. **极值驱动检查**：Top1 比 Top10 更负（BB T+10 -1.765% vs -0.150%；VCB -1.931% vs -0.133%），呈**单调**关系，不是由少数极值造成的假象；反向关系本身是横截面的、广泛的。

## 4. 结论与 Gate

- **BB**：稳定反向（Top<Bottom，|t| 3.5-5.1，正年 1-2/8）→ 按 Top>Bottom 标准 **NO_RANKING_VALUE**。
- **VCB**：稳定反向（Top<Bottom，|t| 3.0-4.3，正年 1-2/8）→ **NO_RANKING_VALUE**。
- **PR**：弱反向（Top<Bottom，t -0.9 ~ -2.1，正年 3/8）→ **NO_RANKING_VALUE**。

**明确结论**：这三个行为强度分在当前形式下**不能作为正向横截面排名因子**（Top>Bottom 不成立、TopN 不优于池整体）。它们表现出的是一致且（BB/VCB）显著的**反向**关系。按任务给定的 Gate 与 `Top > Bottom` 判据，三者均 `NO_RANKING_VALUE`，不得进入 TopN / 内部强弱排序；若未来要研究其反向关系，应作为**新的、独立注册的假设**（明确方向为 Bottom>Top），而不是在本轮结果上反向调参。
