## 1. FACT · E3 可行性勘定（**不可行**）

### 1.1 平台结构性禁止「同 bar 收盘成交」

`server/research/strategyAuthoring/positionCostAdapters.ts` **L783-784** 原文：

```ts
if (signalTiming === "T_CLOSE" && executionTiming === "T_CLOSE") {
  return issueResult(target, ["SIGNAL_EXECUTION_TIMING_CONFLICT: signalTiming=T_CLOSE 时不得同 bar 收盘成交"]);
}
```

`server/research/strategySchema/definitionValidation.ts` **L25** 原文：
> 「L6 `SIGNAL_EXECUTION_TIMING_CONFLICT`：**成交不得早于信号**（`signalTiming=T_CLOSE`…）」

| 词表 | 值 |
|---|---|
| `STRATEGY_SIGNAL_TIMINGS` | `["T_OPEN", "T_CLOSE"]` |
| `STRATEGY_EXECUTION_TIMINGS` | 见 `definition.ts` L169-175 |

⇒ 🔴 **平台【结构性禁止】「决策 rd15 收盘 + 成交 rd15 收盘」**（防前视）✓
