# RESULT-DYNAMIC-3F-ATTRIBUTION-001

> 任务：验证原 3F 在动态入场坐标下的单因子预测能力。
> 规范输入：《Dynamic Entry Factor Specification》。
> 本结果不创建策略版本、不做参数搜索、不做因子组合、不加入市场状态过滤。

## 0. 结论摘要

- 三个原 3F 因子在动态入场坐标下均保持与原冻结方向一致：`maxAmplitude_Te` 与 `meanAmplitude_Te` 为负向，`t1VolumeRatio` 为正向。
- `maxAmplitude_Te` / `meanAmplitude_Te` 在 T+1 已出现显著秩相关，但 T+1 的极端分位差 Bootstrap 区间跨 0；T+2 起极端分位差才稳定为负。
- 振幅类因子强度从 T+2 起明显增强。`meanAmplitude_Te` 在 T+5 达到最强；`maxAmplitude_Te` 在 T+4 达到峰值，T+5 小幅衰减。
- `t1VolumeRatio` 的秩相关在 T+3 达到最强，T+4/T+5 小幅衰减；T+4/T+5 的极端分位差 Bootstrap 区间跨 0，因此只保留为弱排序因子，不作为独立尾部交易信号。
- 所有分位组合的绝对净收益均为负；因子的价值表现为相对排序，而不是单因子正收益策略。

## 1. 冻结口径与 PIT

- 数据集：`first_limit_pullback` v5，`datasetVersionId=660001`，`READY`。
- 样本事件：73,003 个沪深主板、严格收盘涨停、Dataset 构建阶段已排除 ST 的首板事件。
- 决策日：Te = T+1 / T+2 / T+3 / T+4 / T+5。
- 因子信息边界：maxAmplitude_Te / meanAmplitude_Te / t1VolumeRatio 只读取 relativeDay ≤ Te 的行情。
- 标签：Te 收盘决策，Te+1 开盘入场（canBuyAtOpen=true），Te+5 收盘退出（canSellAtClose=true），持有 5 个交易日。
- 标签收益：close(Te+5) / open(Te+1) − 1 − 0.002；往返成本 20bps。
- 横截面：按真实 signalDate 分组；每个日期至少 5 个事件才计算 Spearman IC 和五分位组合。
- 统计：IC/ICIR 为逐 decision-date Spearman IC 的等权均值/均值÷标准差；Bootstrap 为按 event_id 聚类重采样 1,000 次，固定 seed=20,261,001。
- 方向判定：mean IC 符号。有效判定：|mean IC| ≥ 0.01 且 event_id cluster Bootstrap 95% CI 不跨 0；同时要求 Q5−Q1 的 cluster Bootstrap 95% CI 不跨 0，才记为 EFFECTIVE。尾部边缘不显著但 IC 显著时记为 RANK_ONLY。
- 原始 T+1..T+5 回踩 Gate 未用于 Te<T+5 的动态样本资格，因为那会引入未来数据；本结果只检验因子坐标，不新增事件过滤。

## 7. 特别比较

### 7.1 T+1 是否已经出现有效预测力

- 振幅类：T+1 mean IC = −0.0415，事件聚类 95% CI [−0.0510, −0.0332]，已有稳定负向秩相关；但 Q5−Q1 = −0.107pp，95% CI [−0.413pp, +0.195pp] 跨 0 ⇒ T+1 只能算 RANK_ONLY，不能作为稳定的极端分位选择键。
- 量比：T+1 mean IC = +0.0152，95% CI [+0.0053, +0.0239]，Q5−Q1 = +0.424pp，95% CI [+0.147pp, +0.707pp] ⇒ T+1 已出现可用的相对排序信号。

### 7.2 T+2/T+3 是否明显增强

- `maxAmplitude_Te`：T+2/T+3 mean IC 为 −0.0733 / −0.0871，Q5−Q1 为 −0.762pp / −1.036pp；相对 T+1 明显增强。
- `meanAmplitude_Te`：T+2/T+3 mean IC 为 −0.0706 / −0.0848，Q5−Q1 为 −0.647pp / −0.743pp；同样明显增强。
- `t1VolumeRatio`：T+2/T+3 mean IC 为 +0.0156 / +0.0165，Q5−Q1 为 +0.318pp / +0.351pp；T+3 为量比因子峰值。

### 7.3 T+4/T+5 是否继续增强或衰减

- `maxAmplitude_Te`：T+4 达到峰值（mean IC −0.0924，Q5−Q1 −1.064pp）；T+5 小幅衰减（−0.0913，−0.914pp）。
- `meanAmplitude_Te`：继续增强，T+5 达到全坐标峰值（mean IC −0.1005，Q5−Q1 −0.801pp）。
- `t1VolumeRatio`：T+3 后衰减；T+4/T+5 mean IC 仍为正（+0.0135 / +0.0146），但 Q5−Q1 95% CI 均跨 0，降级为 RANK_ONLY。

## 9. 限制与审计声明

- v5 是已读数据复核，不是 OOS；本结果不构成策略转正证据。
- 动态样本使用全部核心首板事件；原始 T+1..T+5 回踩 Gate 因在 Te<T+5 时含未来信息，未作为本次动态样本资格。
- 标签只使用目标 Te+5 收盘退出；目标日不可卖时剔除，不执行原退出协议的顺延搜索。
- IC 的事件聚类 Bootstrap 在重采样时固定完整样本的日内秩对，目标为事件聚类不确定性；Q5−Q1 在固定五分位归属下重采样。
- 未做多重比较校正；1,000 次 Bootstrap 和 15 个因子×Te 组合均按事前固定口径输出，没有事后择优。
- 分位绝对收益为负，表明三因子均不能单独形成正收益策略；本结果只回答动态入场坐标下的单因子排序有效性。
