## 1. 六条缺口（每条：事故 → 缺口 → 增补要求）

### 缺口 1 🔴 **被排除的样本从未被检查是否与目标同分布**

- **事故**：本 session 才发现「回踩门槛」剔掉的 **21,667 事件（29.8%）** 的右尾**系统性更厚**
  （rd20 `≥+100%` 占比 **0.26% vs 0.12%，+117%**）。而样本账一直是**平的**
  （`eligible 50,907 + excluded 21,667 = candidate 73,003`）—— **记账正确，但没人问「剔掉的那群，在靶上长什么样」**。
- **缺口**：§3-3「样本账必须平」只保证**算术**，不保证**语义**。一个 `excludedByReason` 桶可以**静默切掉信号本身**。
- **增补要求（P1）**：**每个 `excludedByReason` 桶必须报该群在靶指标上的画像**（占比 / 均值 / 尾率 / 分位）。
  若某桶的靶画像与保留群**显著不同**，该桶必须在结论区被显式讨论，不得只当作一行计数。

### 缺口 2 🔴 **靶指标未声明，且常与目标错配**

- **事故**：t74 链全程把**组合总收益**当主指标；而 `RESULT-151PCT-WINNER-CONCENTRATION-001` 证明
  **151.0958% = 9 笔**、top10% 占比 **438.7%** ⇒ 那个「主指标」实际是**约 5 笔的统计量**。
  同时 `bigWin50Count` / `bigWin100Count` **早已存在于 schema，却从未作为主判据**。
- **缺口**：实验契约（`ExperimentDefinition`）**没有「靶指标」字段**，也没有「靶必须匹配目标」的要求。
- **增补要求（P2）**：每个实验必须声明 **`targetMetric`**（+ 为什么它对应研究目标）。
  尾部目标必须把**尾部计数/概率列为主判据**，并**同时**报均值（本 session 反复验证：只报一个会得出方向相反的结论）。

### 缺口 3 🔴 **测量仪器的分辨力从未被评估**

- **事故**：3F 合成分只有 **≤18 档**、**3 档覆盖 86.9%**、**最高分并列 262 笔**，破平键 = `securityId.localeCompare`
  （**不透明 UUID**）。后果：三个完全不同的扰动造成几十到几百 pp 的摆动 ——
  加宽槽位 151% → **−1.5%** · 剔次新 → **65.39%** · trend 融合 → **−166~−228pp**。
  **这些不是「因子弱」，是「仪器坏」。**
- **缺口**：协议没有任何地方要求评估排序/评分**在入选边界上的分辨力**。
- **增补要求（P3）**：**选股类实验必须报「排序分辨力四件套」**：
  ① 不同取值数；② 最大取值占比；③ **入选边界处的并列规模**；④ 破平键是什么、其经济含义。
  若边界并列规模 ≥ 入选名额 ⇒ 该实验**实质上在测破平键**，必须在结论区如此标注。

### 缺口 4 🔴 **没有效应量对照，导致「小项在大项噪声里」被当成结果**

- **事故**：P0–P10 绝大多数**改选股、冻结退出**，而**退出政策（Runner）贡献 89.5%**。
  ⇒ 每次都在一个巨大主项固定时测小项 ⇒ Δ 全是大负数且不稳定。
  而 `-stopwide` 显示**单一参数**（6%→8%）就能让收益 151.10% → 64.64%（**86.5pp**）。
- **缺口**：没有「变动的因素 vs 固定的主导因素」的效应量要求。
- **增补要求（P4）**：实验必须报 **「变动项的效应量 / 主导固定项的量级」比值**。
  比值过低（如 < 10%）⇒ 结论必须标注**「该 Δ 落在主项噪声内，不足以支撑取舍」**。

### 缺口 5 🔴 **没有预注册与停止规则，导致广度堆叠（garden of forking paths）**

- **事故**：`research_experiment_run` = **47 实验 / 162 Run**，呈广度堆叠：
  trend → trend-gate → trend-v2 → slots → stopwide → top5 → carryover → carryover-refresh → late-entry → event-gate → subnew…
  **下一步做什么由上一轮结果决定**，但没有任何地方声明「这个族要问到什么为止」。
  既有程序自己的合并结论已经写着「**这条链上没有免费降回撤的旋钮**」—— 这正是**矿脉挖尽**的签名。
- **缺口**：`ExperimentDefinition` 无「预注册判据 / ABORT 条件 / 停止规则」字段。**我本 session 是在 PLAN 文档里手工补的，
  说明它是有效需求，只是没进协议。**
- **增补要求（P5）**：实验定义必须携带 **`preRegisteredCriteria`**（事前判据 + ABORT + 停止规则），
  且**事后不得修改**（改动即视为新实验）。**一族实验必须声明「停止规则」**（问几次、什么条件下关闭该方向）。

### 缺口 6 🔴 **没有时间/regime 分层要求，导致 regime 暴露被读成因子效应**

- **事故**：本 session 的根因分析显示 —— **6/9 赢家落在 2025–2026**、2025 单年 = 全期净利 **61%**、
  权益峰 **2022-03 直到 2025-05-12 才被超越（`maxDrawdownDurationDays = 907`，3.2 年空转）**。
  ⇒ 「3.2 年不动 + 1.3 年 151%」是 **regime 签名**。
  而 run `6210006` 的 14 阶段里 **`regime` = SKIPPED（未接线）**。
- **缺口**：§5 要求声明窗口，但**不要求按时间分层报告**。于是 regime 效应会被读成「策略有效」。
- **增补要求（P6）**：每个实验的靶指标**必须按时间分层**（至少逐年；与 `index_daily` 状态交叉更好）。
  若效应集中在少数年份 ⇒ 结论必须标注**「regime 观察，非因子效应」**，并被禁止作为转正依据。

## 2. 增补后的实验「必答清单」（拟写入 `.agents/research/SKILL.md` 新 §3.5）

```text
【每一项实验，无论大小，结论区必须回答】
1. 靶指标是什么？为什么它对应研究目标？                       ← P2
2. 被排除的每个桶，在靶上的画像如何？与保留群是否同分布？      ← P1
3. 排序/评分在【入选边界】的分辨力：取值数/最大占比/并列规模/破平键？ ← P3
4. 变动项的效应量 vs 主导固定项的量级，比值多少？              ← P4
5. 事前判据 / ABORT / 停止规则是什么？（事后不得改）           ← P5
6. 靶指标按时间分层的形态？效应是否集中在少数年份？            ← P6
7. 样本账（eligible + excluded = candidate）+ unscannedEventCount  ← 既有 §3-3/§3-4
```

**1–6 全是「报告要求」，不需要新基础设施**：多数可由既有 `customPayload` / `tables` / `statistics` 承载，
只有 `targetMetric` 与 `preRegisteredCriteria` 建议进 `ExperimentDefinition` 契约（可选字段，缺省不影响既有实验）。

## 3. 实验组合的重构（不是「再跑 47 个」）

**现状是广度堆叠；提案是按「回答一类问题」组织成少数几个族，每族声明停止规则。**

| 族 | 唯一问题 | 停止规则 |
|---|---|---|
| **F1 · 门控** | **池的语义门控是否切掉了靶？**（本 session 已知：回踩门切掉了尾更厚的 29.8%） | 每个门控维度做过一次「保留 vs 放开」的受控对照即止 |
| **F2 · 打分** | 打分在**入选边界**上有没有分辨力？ | 分辨力四件套达标才允许做排序实验；否则先修仪器 |
| **F3 · 退出** | 在**给定的**入选集上，退出政策的最优区间？ | 已知唯一有效维度（Runner 89.5%）；按 §3 判据做参数级，**不做网格** |
| **F4 · 时间/regime** | **收益是否集中在特定 regime？** | **唯一未接线、且证据指向根因的族**（见 §4） |

**明确不做**：
- ❌ 不重跑那 47 个（它们的机械产出可复用，结论按新清单**补报告**即可，不必重算）
- ❌ 不在分辨力未达标时做任何排序/因子实验（会测到 tie-break 噪声）
- ❌ 不把「放开回踩门槛」当成治本（那是 F1，只是**让更肥的尾进入可捕获范围**的前提）

## 4. 优先级建议（根因所在）

本 session 的根因分析：**右尾是「时间/regime」现象，而全部既有工具都是「横截面」工具。**
五条「尾–均值反向」（取向/gap/换手/历史涨停/门控）是**同一个结构事实的五次投影**；
唯一有效的杠杆（Runner = 89.5%）恰好是**唯一非横截面**的。

**⇒ 建议优先级：F4 > F1 > F3 > F2**

| 序 | 做什么 | 为什么 |
|---|---|---|
| **1** | **F4 · 接上 regime 层**：先做**只读判定**（收益逐年 + 对照 `index_daily` 状态），确认「151% 是 regime 敞口还是 alpha」 | 判定结果**决定后面所有工作的方向**；且是平台唯一未接线的维度 |
| 2 | **F1 · 门控对照**：`requirePullback` 保留 vs 放开（受控） | 已知尾更厚 +117%（rd20）；但**不利先验**：高波动 + −6% 止损可能又收割掉 |
| 3 | **F3 · 退出参数级**（照 §3 判据，不做网格） | 唯一已验证有效的维度 |
| 4 | **F2 · 仅在分辨力达标后**做打分实验 | 否则测的是破平键 |
