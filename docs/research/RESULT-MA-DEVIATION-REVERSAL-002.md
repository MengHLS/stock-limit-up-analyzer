# RESULT-MA-DEVIATION-REVERSAL-002

> 目标：验证固定 `D20 < -10%` 的深度负偏离组是否存在短期反弹路径，以及是否值得独立形成“回撤反弹池”。
> Dataset: `first_limit_pullback` / `datasetVersionId=660001`。池形成: T+5 收盘。严格 PIT，不修改 3F，不做 Top3，不搜索参数，不创建策略版本。

## 0. 固定口径

- `D20 = close(T+5)/MA20(T+5)-1`。
- 研究组：`D20<-10%`、`D20<-10% + MA20Slope>0`、`D20<-10% + MA20Slope<=0`。
- 对照：完整首板回撤池、`D20>=-10%`。
- 未来路径从 T+6 开盘起算，净值节点为 T+6/T+7/T+8/T+9/T+10/T+15/T+20 收盘，扣除 20bps。
- 构造变量只使用 T+5 及以前信息；T+20 是 Dataset post 最大可用绝对窗口。

## 6. 重点回答

1. **D20<-10% 的反弹主要发生在 T+6~T+10 吗？**
   早期确有贡献，但不是全部。T+10 累计 +0.59%，T+20 达到 +2.58%；T+10 后仍有明显正贡献。

2. **D20<-10% + MA20 DOWN 是否稳定优于 UP？**
   总体明显优于 UP（6/8 年、T+20 +3.24% vs -0.26%），但不是绝对稳定：2020 年 UP 更好，2023 年两者都为负。

3. **跨年度一致性如何？**
   1991 之外的多数年份 DOWN 优于 UP；但 2023 全组为负，2020 方向相反。只能称为有条件、非全周期一致的局部结构。

4. **反弹是否普遍，还是少数大涨股贡献？**
   有明显右尾依赖。D20<-10% 组 Top10% 正收益贡献 44.66%；去掉 Top10% 后均值 -0.62%。DOWN 组去掉 Top10% 后也仅 +0.05%，说明“普遍反弹”证据不足。

5. **是否值得独立定义为“回撤反弹池”？**
   值得继续做研究标签，但**暂不值得作为独立交易池**。T+20 均值、PF 和胜率优于完整池，但收益集中、2023 不稳定，且 MA20 DOWN 仍依赖少数赢家。

6. **是否需要止跌/重新站回均线确认？**
   从证据看，需要。当前深度负偏离本身同时包含高 MFE 和高 MAE；单纯 `D20<-10%` 不足以区分“继续下跌”与“快速反弹”。应继续研究独立确认条件，但本报告不设计交易规则。

## 7. 结论边界

- 未根据结果重新选择 D20 阈值；固定使用 `D20<-10%`。
- 未修改 3F，未做 Top3，未创建策略版本。
- T+20 是 Dataset 最大绝对可用窗口；不是从 T+5 起的完整 20 个交易日。
- DOWN/UP 为主要证据，完整池与 D20>=-10% 作为对照。
