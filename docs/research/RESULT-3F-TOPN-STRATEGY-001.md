## 重复首板事件与年度衰减诊断

先排除一个口径误解：因子研究**不是**“一只股票只允许一次成交”。
Dataset v5 有 `73,003` 个首板事件、`3,334` 只证券；`deriveTwelveFactorSamples`
只按 `eventId` 去重，同一证券的多个首板事件全部保留为独立样本。
因此约 `95.4%` 的因子样本本身就是同一证券的重复首板事件。

`v1.9.0` 的实际策略反而只交易了很少一部分重复事件：

| 方案 | 完成交易 | 涉及证券 | 平均每只交易次数 | 因子池平均每只事件数 |
| --- | ---: | ---: | ---: | ---: |
| Top3 | 1,866 | 1,276 | 1.46 | 21.90 |
| Top5 | 1,594 | 1,140 | 1.40 | 21.90 |

Top3 按同一证券的交易次序拆分：

| 次序 | 完成交易 | 平均收益率 | 胜率 | 净盈亏合计 |
| --- | ---: | ---: | ---: | ---: |
| 第 1 次 | 1,276 | -0.031% | 40.75% | -21,316.13 |
| 第 2 次 | 427 | -0.157% | 42.86% | -6,413.10 |
| 第 3-5 次 | 161 | -1.055% | 39.13% | -16,736.39 |
| 第 6 次及以上 | 2 | -3.853% | 0.00% | -527.12 |

重复事件的确更差，但**第 1 次交易本身也是负期望**，所以“每股票只取一笔”
不能解释整体亏损。更主要的差异是：

- 因子研究：每个决策日独立投入 1 单位资金，TopN 等权，持有 T+6 开盘 → T+10 收盘，
  没有并发持仓上限、没有资金路径依赖、没有止损/回撤止盈；
- 实际策略：最多 5 仓、单日最多买 2/3 只、每仓按现有总权益 20%、5% 止损、
  盈利回撤 5% 止盈。它是一个受资金路径约束的账户回测，不是因子研究那条重叠组合曲线。

年度交易层也显示，问题更像“2022–2024 的池收益恶化 + 路径约束放大”，而不是因子样本去重：
Top3 的年度净盈亏为 2019 `-380.79`、2020 `+2,569.24`、2021 `-7,171.16`、
2022 `-16,172.86`、2023 `-13,563.30`、2024 `-8,653.36`、2025 `+1,722.98`、
2026 `-3,343.49`。这与事件级 OOS 中 3F 多数年份仍有正超额并不矛盾，
因为两边衡量的不是同一条资金曲线。

## v1.8.0 历史基线

`v1.8.0` 只修正执行侧成本口径，不改因子、买入排名、仓位、退出规则或数据坐标。
此前 `v1.7.0` 的执行成本模型是佣金 `3 bps`、卖出印花税 `10 bps`、滑点 `10 bps/边`；
研究侧 `RESULT-OOS-COMPOSITE-3F-001` 的冻结坐标实际是 `20 bps/往返`，分解为：

```text
买入：佣金 2.5 + 滑点 2.5 + 冲击 2.5       = 7.5 bps
卖出：佣金 2.5 + 滑点 2.5 + 冲击 2.5 + 印花税 5 = 12.5 bps
往返合计                                      = 20.0 bps
```

执行成本模型没有独立冲击字段，因此 `v1.8.0` 将“滑点 + 冲击”合并为 `5 bps/边`，
并把佣金降到 `2.5 bps`、卖出印花税降到 `5 bps`。静态模型往返成本为
`2.5×2 + 5×2 + 5 + 0.1×2 = 20.2 bps`。

> 注意：模拟器仍会按成交额对滑点做流动性分层加成，因此最终实测成本高于静态的
> `20.2 bps`。本轮 Top3 实测为 `27.84 bps/买入名义`，Top5 为 `29.26 bps`。

## 0. 结论摘要

执行面板现在使用事件级内部身份
`securityId::event:<eventId>`，因此同一证券的每个首板事件都拥有独立的相对日序列，
不再被合并成一条终身序列。公司行为（分红、送转、配股、拆合股）先应用到持仓，
再进入权益计算；连续涨停且 T+1..T+5 没有回踩的样本已在 PIT 条件下排除。

## 1. 冻结口径

| 项 | 取值 |
| --- | --- |
| 因子 | `maxAmplitude`(LOW) + `meanAmplitude`(LOW) + `t1VolumeRatio`(HIGH) |
| 权重 | 三个分位因子等权，各 1/3 |
| 决策时点 | 首板后第 5 个交易日收盘（T+5，3F 首次可计算日） |
| 买入 | T+6 开盘 |
| 观察窗口 | `[5, 15]` 交易日；末端用于保证退出订单有执行行情 |
| 退出 | hold-while-selected 与 `TIME_EXIT = 5` 交易日，先到者 |
| 组合容量 | N3 / N5 均最多同时持有 5 只 |
| 单日新建仓 | N3 最多 2 只；N5 最多 3 只 |
| 初始资金 | 100,000 元 |
| 成本 | 佣金 3 bps（最低 5 元）、印花税 10 bps、过户费 0.1 bps、滑点 10 bps |
| 公司行为 | 现金分红、送转、配股、拆股、合股 |
| 回踩资格 | T+1..T+5 至少一个收盘价低于首板日收盘价 |
| 数据来源 | `registry` 直读 Dataset v5 |

## 4. 关键修正

1. **事件级身份**：面板身份从只有证券改成“证券 + 首板事件”，同一证券后续首板可以再次产生信号和成交。
2. **公司行为**：除权除息不再直接当作价格亏损；分红进入现金，送转和拆合股调整持仓数量。
3. **回踩过滤**：连续涨停或观察期内没有低于首板收盘价的样本不具备回踩资格。
4. **初始资金**：策略文档与留档均为 100,000 元，不再按缺失值或旧默认值展示。
5. **完整明细**：事件级 N5 共 2,348 笔，留档上限提高后页面可以显示全部明细。
6. **末端清算**：事件窗口最后一行没有下一行情时按最后可得收盘价强制平仓；零股允许整仓卖出，避免仓位永久占位、后续年份无法继续交易。
7. **容量收紧**：`v1.3.0` 将两套策略的最大同时持仓统一为 5 只，并分别限制单日新建仓 Top3 2 只、Top5 3 只；执行结果显式记录 `MAX_DAILY_BUYS_REACHED`。
8. **止损 T+1 顺延**：`v1.4.0` 修复「买入日已触及止损但因 T+1 冻结、下一交易日未重新触发」的死区。`002719.SZ@2019-01-21` 现为 2019-01-29 买入、2019-01-30 止损卖出，`holdingPeriod=2`；旧结果延迟到 2019-01-31，`holdingPeriod=3`。
