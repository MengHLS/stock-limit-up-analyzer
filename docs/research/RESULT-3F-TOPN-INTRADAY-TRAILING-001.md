# RESULT-3F-TOPN-INTRADAY-TRAILING-001

## 实验问题

把 3F Top3 的盈利回撤止盈从收盘检查改为盘中检查，并保留 `1.11.0` 的其余口径后，
实际成交和组合结果如何变化。

## 修复内容

- `TRAILING_TAKE_PROFIT` 新增 `INTRADAY` 检查模式。
- 旧策略声明的 `ON_CLOSE` 行为保持不变。
- `INTRADAY` 模式按持仓期最高收盘价计算回撤线：
  - 当日开盘价已越过回撤线时，按开盘价触发。
  - 盘中最低价越过回撤线时，按回撤线价格触发。
  - 因跌停等原因拒单时，触发状态跨日保留，并在后续决策日继续处置。
- 公司行为发生时，同步复权持仓期最高收盘价、风控建仓参考价、强势续持 MA 历史与旧收盘价
  - 送转、拆合按除权价格因子调整历史价格状态
  - 现金分红与配股按完整除权除息因子调整，避免除权跳空被误判为止盈

- 每 10 股派 `0.64` 元

2019 年交易在 `1.12.0` 修正版中的结果：

| 项 | 值 |
| --- | ---: |
| 买入日 | 2019-05-21 |
| 送转后数量 | 1,400 股 |
| 送转后买入成本 | 12.6601 |

| 退出原因 | 盈利回撤止盈（峰值收益11.44%，盘中回撤-5.00%） |

修复前，持仓期峰值仍保留送转前的 `18.5`，与送转后的成本 `12.6601` 比较，被错误计算为
峰值收益 `+46.13%`；2019-05-30 的除权价格又被计算成 `-27.30%` 回撤，导致错误止盈。
修复后，历史峰值同步复权，除权跳空不再触发止盈。

## 结论

盘中止盈和公司行为状态复权修复后，当前 3F Top3 口径仍显著降低组合收益：
累计收益由 `-42.96%` 降至 `-80.15%`，PF 由 `0.9500` 降至 `0.7602`。

该结果说明，当前 5% 回撤线在盘中触发时更容易被正常波动打穿，过早切断仍有上行空间的持仓。
可以确认退出规则与公司行为处理已正确执行，但不能把 `1.12.0` 作为更优策略版本。
