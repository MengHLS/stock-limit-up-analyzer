# 首板实体过滤与实际持有曲线研究

## 目的

先把首板日的一字板和过小实体过滤掉，再研究实际入场后的逐日收益曲线，避免
只看固定的 `T+10/T+20` 终点。

## 固定口径

- 事件：严格收盘涨停首板。
- 一字板：首板日 `O=H=L=C=涨停价`，默认排除。
- 实体高度：`(首板 close - 首板 open) / 首板 previousClose`。
- 默认最小实体：`0.1%`。
- 实体分桶：`0.1%~1%`、`1%~2%`、`2%~4%`、`4%~6%`、`6%~8%`、`>=8%`。
- 默认入场：`T+6` 开盘，可配置为 `T+1..T+6`。
- 最大退出日：默认 `T+20`。
- 持有曲线：从实际入场日起算 `holdingDay=1..N`。
- 共同样本：所有退出日使用同一批路径完整、每天均可卖出的样本。
- 成本：固定扣除 `20 bps`。

## 输出

- 实体分组的逐日平均 / 中位净收益、胜率、P5/P25/P75/P95。
- 逐日 MFE / MAE。
- 截至每个持有日触及 `+2%` / `-2%` 的比例。
- 锚点持有日的日期聚类 Moving Block Bootstrap。

## 边界

本实验不选择收益最高的退出日。`T+10/T+20` 只是曲线上的观察锚点，不是结论端点。

共同样本要求所有退出日均可卖，条件较严格；这是为了保证不同持有日之间的可比性。
