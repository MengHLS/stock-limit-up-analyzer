# RESULT-EXIT-STATE-DECISION-001

> 目标：研究**已有 Runner / Exit 状态出现后**，「继续持有」相对于「在状态出现时退出」的**增量价值**。
> 全部使用 **H_fill / 实际可执行口径**；单状态独立实验（**不组合**）；不搜阈值、不创建 Candidate、不改架构、不做策略晋升。
> 本报告由 `scripts/reportExitStateDecision001.mts` 从落盘 evidence 机械生成，数字未人工转录。

> ⚠️ **本报告的定位**：它只回答「状态出现时，继续持有比马上退出多赚/少赚多少」，**不回答**「该状态是否适合做退出规则」。状态与未来收益相关 ≠ 状态适合用于退出（见 §6）。

## 6. 关键警告：相关 ≠ 适合用于退出规则

本实验刻意把两件事分开：

1. **「状态与未来收益相关」**：例如 `MA10_SLOPE_POSITIVE` 组的后续收益比对照组低（`RESULT-RUNNER-STATE-CLOCK-MAP-001` 测得 −1.5 ~ −3.9pp），这确实是稳定的**负向**信息。
2. **「状态适合用于退出规则」**：要求的是「**在状态出现时退出，比继续持有更好**」。本实验测出的是：状态出现时**继续持有**的增量均值多为正、中位为负、胜率不足一半 —— 也就是说，**这些状态的出现并不构成「应当立即退出」的理由**；相反，立即退出在多数情况下是次优的。

这两条**同时成立并不矛盾**：状态出现后收益变差，是相对该状态的对照组而言；而相对「马上卖出」，继续持有仍然（在均值上）保留了右尾期权价值。**把 (1) 当成 (2) 会得出错误的退出规则。**

另一个必须点明的偏差来源：`EXIT_AT_STATE` 的胜率极高（最高 94%），是因为**状态只能在持仓已经盈利之后才被观察到**（例如 T+15 时仍满足 `MA10_SLOPE_POSITIVE` 的交易，此前多半已经涨过）。这个高胜率是**状态可观测性的选择效应**，不是退出规则的优势。

| E1 | 对全部 6 个状态 × 3 个观测日 × 最多 4 个持有期（66 个单元），**继续持有的增量均值多为正、增量中位几乎全为负、增量胜率仅 37%–51.3%**（仅 2 个边际 T+20 单元略高于 50%） |
| E2 | 增量的正号完全由右尾支撑：**Top10% 贡献反复超过 100%**，剔除最好的 10% 交易后总增量转负 |
| E3 | 继续持有的**风险代价随持有期单调放大**：≤−10% 增量比例从 T+20 的 ~5%–16% 升到 T+80 的 ~29%–40%；负部均值达 −16 ~ −18pp |
| E4 | **不存在「广泛型」单元**；年度方向普遍对半分裂（3/5、4/4、5/3） |
| E5 | 既有 Runner 延长臂（`NEW_HIGH_3` @ T+10 → T+80）与此一致：均值 +1.54pp / 中位 −2.28pp / 胜率 43.9% / 负部均值 −16.95pp |
| E6 | **CONSECUTIVE_LOWER_CLOSES_GE_2** 是唯一「状态出现时已经处于亏损」的状态（状态即退出的均值为 −4.10%/−3.13%/−3.25%，胜率仅 22%–33%），继续持有的增量均值最高（+1.17 ~ +3.33pp，为全部状态之首）——但中位仍为负（−1.22 ~ −2.56pp） |

### 7.2 具有稳定性的结论

- **「继续持有 = 右尾期权，而不是普遍改进」**：在全部 66 个单元、所有状态与所有持有期上方向一致。
- **「持有越久，中位越差、尾部越厚」**：从 T+20 到 T+80 单调恶化。
- **「状态出现即退出」不是一个被数据支持的普遍动作**：除个别单元外，立即退出的胜率虽然高（选择效应），但其收益低于继续持有的均值。

### 7.3 仍需后续实验验证

1. **机会成本未计入**：本实验只测单笔路径增量，**没有**计入延长持有导致的少开仓（既有实测为 −115,029 资金循环残差）。要判断延长持有是否真的提升组合收益，必须回到策略级执行链。
2. **状态出现的时点分布未建模**：同一状态在不同年份/不同市场阶段的可观测性不同，本实验只给出汇总与年度方向，未做状态出现频率的条件分析。
3. **`CONSECUTIVE_LOWER_CLOSES_GE_2` 的反弹路径**：均值增量为正但中位为负，且观测日敏感（`CLOCK-MAP-001` 已证明），需要固定观测日 + 单独建模。
4. **没有测试「状态消失」语义**：本实验只比较「状态出现时退出 vs 继续持有」，未测试「等待状态消失/反转再退出」——这是下一阶段才应进入的问题。
