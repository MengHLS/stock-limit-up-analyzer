# RESULT-RUNNER-CLC2-CONTROL-001

> 目标：验证 `CLC2` 本身是否具有**超出价格位置/剩余空间**的增量信息。
> 固定：dataset `first_limit_pullback` / `datasetVersionId=660001`；execution projection 沿用已验证 T80（v5 官方行 + 选中事件 v7 rd17..80）；固定池 `D20 < -10% && MA20Slope <= 0`；T+6 开盘入场。
> 事件日 = 激活后固定相对日上的 `CLC2` 状态；**不使用后续 NEW_HIGH_3 分组**；不搜参数、不创建 Candidate、不修改 Strategy、不做 Exit/OOS/WFA。

## 5. 结论

1. **CLC2 的独立增量很小，且只在短窗口存在。** 原始固定日历差 T20 为 +1.23pp（+10%）/+1.03pp（+15%）；精确分桶匹配后仍有 **+0.98pp / +1.33pp**（幅度与原始接近，说明价格位置并未把 T20 残差吃掉），但随窗口拉长迅速衰减：T40 为 +0.67pp / +1.33pp、T60 为 +1.12pp / +1.18pp，且 T40/T60 的胜率与中位差基本消失（+10% T20 中位差 +0.81pp，T60 中位差 -0.01pp）。
2. **原始组间差的来源确实是位置差异。** CLC2 组在事件日的累计收益（-16.75% vs -11.65%）与相对 MA10（-7.03% vs -0.33%）显著更低；**单变量分层**下按这两个变量分层的层内差分别降到 +0.41pp / +0.03pp——单变量层内几乎归零。但**多变量联合匹配（7 个协变量 + 精确 gap 桶）后 T20 仍保留约 1pp**，说明 T20 残差不能被单个价格位置变量解释，需要多变量联合控制才不再收缩。
3. **CLC2 的信息更接近「状态发生时所处的位置」，而不是「状态本身」。** 组间位置差异是原始差的直接来源；匹配后 T20 虽仍有约 1pp 残差，但该残差在年度上正负互换（2019/2023/2026 同时为负），并在更长窗口衰减——因此**不能判定为状态本身具有稳定、可用的独立增量**。
4. **判定：匹配后不存在跨年度稳定的增量 → Runner-State 研究线按预设标准关闭。** 依据是：(a) 匹配后 T20 残差约 +1.0~+1.3pp，虽方向一致，但远小于交易成本量级以外的可用幅度；(b) T40/T60 残差衰减到 +0.7~+1.2pp 且胜率/中位差消失；(c) 年度上 2019/2023/2026 三个年份在两个激活口径下**同时为负**，不存在跨年度一致；(d) 残差无法与 CLC2 持续长度（状态定义本身）分离——CLC2 组恒 ≥2、NOT 组恒 0。若日后重启，必须先解决这一识别问题，而不是继续寻找更优子窗口。
5. **本轮不产生正式 Exit/持有规则。** 只回答 CLC2 是否有独立增量，不做 Exit/OOS/WFA、不创建 Candidate。

### 明确边界

- 固定日历下每个事件按 offset=4..20 贡献多行，样本间**不独立**，统计量仅作描述，未做聚类稳健推断。
- `clc2Len` 无法平衡：CLC2 组按定义恒 ≥2，NOT 组恒为 0；这使「状态本身」与「该状态的定义长度」在本设计中不可完全分离。
- 匹配为无放回最近邻；被淘汰样本（约 10%）可能系统性不同。
- 未控制大盘/行业/流动性等未观测混杂；T80 超出可比范围未报告。
