## 输出指标（按用户关切的顺序）

1. **组合最大回撤**（%）；
2. 逐笔痛感：亏损笔均值、最差单笔、亏损超 6% / 超 10% 的笔数；

### 结论：**扩大止损是四输**（用户对回撤的担心与数据一致）

1. **回撤更大**：43.30% → 49.88% / 45.88% / 47.02%（三档全部更差）；
2. **收益更差**：151.10% → 64.64% / 76.53% / 45.13%；
3. **逐笔痛感更重**：P5 分位 −6.19% → −8.06% / −10.05% / −12.05%；亏超 10% 的笔数 12 → 15 / 130 / 88；
4. **超级票没变多**：≥+50% 笔数 9 → 8 / 9 / 8。

有意思的一处：放宽止损后**止损出场数反而减少**（579 → 372 / 299 / 242，更多仓位靠 MA 趋势止盈/时间退出离场），
但总收益仍然更差 ⇒ **被 6% 止损打掉的那些票，多数后来确实继续下跌**（放宽 = 多挨跌）。

### 对「回撤承受力」的含义

这条链上已经没有「免费降回撤」的旋钮了：

| 已实测的旋钮 | 回撤结果 |
| --- | --- |
| 换排序（v1 × 2 + v2） | −166 ~ −228 pp 负增量，回撤恶化到 60–96% |
| 多买 / 放开仓位（P2） | 43.30% → 44.88% / 56.27% / 54.29% |
| **扩大止损（本次）** | 43.30% → **45.88% ~ 49.88%** |

⇒ 要降回撤只能走**降低暴露**（每笔仓位比例 ↓ / 保留现金）或**组合层择时**（大盘状态、净值回撤熔断），
两者都是「收益-回撤」的取舍而非免费改善。
