## 7. 结论

1. **CLC2 是否只有在较长窗口下才有决策价值？** 是。组合层 A→B 增量：T+20 -8.27pp（有害）、T+40 -0.08pp（中性）、T+60 +11.12pp、T+80 +11.48pp（有益）。转折发生在 T+40 与 T+60 之间。
2. **收益是否来自资金循环？** 部分是。CLC2 退出在各窗口都释放了资金并带来更多后续成交（B 比 C 多 47 / 206 / 216 / 277 笔），组合差 = 单笔持有差 + 资金再循环新增交易的表现。短窗口下再循环进来的交易更差，长窗口下更好。
3. **哪些窗口稳定？** 没有全年度稳定的窗口。T+40 最接近中性，T+60/T+80 的组合层增益在多数年份为正但存在 2023/2025/2026 反向年份，T+20 方向明确为负。
4. **单笔 ≠ 组合**：CLC2 命中组的单笔「继续持有」增量均值四个窗口都为正（+0.88pp / +1.95pp / +4.97pp / +2.53pp），但组合层 A→B 在短窗口为负——这是资金占用与机会成本的直接体现。

### 明确边界

- 本报告为研究事实，**不构成正式 Exit 规则**，不创建 Candidate、不晋升策略、不修改正式 Strategy。
- 统一组合坐标为研究性坐标（关闭止损/趋势、扩容至 25 槽 × 4%），用于隔离窗口与 CLC2 效应，不等于可用策略。
- A 与 C 配置相同，故 A→B 与 B→C 互为相反数；请按各自问题解读。
