# 入场对齐的退出视界曲线研究

## 固定筛选

- 沪深主板，Dataset 构建阶段已排除 ST。
- 首板日收盘价严格等于交易所涨停价。
- 排除首板日一字涨停：`open = high = low = close = limitUpPrice`。
- 排除 `T+1..T+5` 任一交易日：
  - `high >= limitUpPrice`；
  - 或 `low <= limitDownPrice`。
- `T+1..T+5` 或 `T+6..T+20` 行情缺失、停牌或非法时，整个事件剔除。

## 交易口径

- 决策时点：`T+5` 收盘。
- 入场：`T+6` 开盘，要求可买。
- 持有日从实际入场日起算：`holdingDay = 1..15`。
- 对应事件相对日：`T+6..T+20`。
- 目标退出日不可卖时，使用其后第一个可卖收盘。
- 往返成本固定扣除 `20 bps`。

## 输出

- 同一共同样本下的逐持有日净收益曲线。
- 均值、去最高 5% 后均值、中位数、P5/P25/P75/P95、胜率。
- 日期聚类 Moving Block Bootstrap 的 95% 区间。
- MFE、MAE、最大收盘回撤。
- 实际退出延迟日和当日可卖率。
- 持有期间曾达到 `-5%/-2%/+2%/+5%` 的比例。

## 边界

- 不选择收益最高的退出日。
- 不输出策略、参数推荐或买入评级。
- `T+10` 和 `T+20` 只是持有曲线上的两个参考点。
- v3 / v4 是已读数据复核，不是未来未读数据 Holdout。
