## 4. 入场与退出：存在节奏错配迹象，但不能推出统一延长持有

RECOVERY首信号计划开盘距当时已知localLow的涨幅：均值17.83%、中位13.14%；localLow到确认日平均8.05个交易日格。确认规则确实要求已有一段反弹才进入，但没有更早可执行买点的对照，不能直接断言当时应该买得更早。

可买RECOVERY候选的5日窗口621条完整路径，只有16条（2.58%）收盘曾达+20%；20日窗口618条完整路径有96条（15.53%）。右尾通常需要更长时间，其中当日Top3的命中者中位到达时间为第14日，值得与原短期退出节奏核对。

008实际RECOVERY交易152笔、净损益−20,967.64元；ORIGINAL84笔、−14,999.78元。对实际交易以真实成交价为基准、按日期映射真实入场/退出日：

- RECOVERY有8笔在原退出前或退出日收盘曾达入场价+20%；18笔直到退出后20日内才首次达标；124笔在完整前后窗口均未达标，2笔窗口缺失。
- 这18笔后达标交易，首次达标全部位于首板事件T+20之后。T+20是新入场截止日，并非已买持仓必须退出的日期；它会限制通过新买/再入场捕获更晚上涨，不能与持有期限混淆。
- 后达标的18笔中，10笔原退出为亏损，5笔退出前最低价已触及入场价−6%；其余也可能经过盈利保护、MA或时间退出。后续上涨既有机会成本，也有持有风险，不等于当时可以无损等到它上涨。
- RECOVERY的99笔亏损交易中98笔有完整退出后20日路径，只有10笔期间收盘达入场价+20%；终点相对入场价均值仍为−3.59%。B全部亏损交易的完整路径为152/153，19条曾达+20%、终点均值−3.82%，与008复核一致。

因此，时间尺度匹配值得研究；当前路径不支持“全部放宽止损/延长持有便能改善收益”。后续峰值不是可实现收益，本次没有替代退出撮合或账户消融。原账户仍为A+3.24%/B−35.97%，不会因本次路径诊断变化。
