## 6. 结论

1. **`CLC2 → NEW_HIGH_3` 恢复具有独立增量信息。** 在共同锚点、无前视偏差的口径下，D1–D10 内恢复组 vs 未恢复组的 T+80 均值差：+10% 激活 +11.11pp（+1.30% vs -9.80%），+15% 激活 +11.97pp（+1.08% vs -10.89%）。
2. **恢复速度呈现单调梯度**：D1–3 +6.76% → D4–7 +2.42% → D8–14 -7.29% → D15–20 -10.83% → 未恢复 -18.44%（P10）。
3. **不是单纯价格位置效应**：在 LOW / MID / HIGH 三个锚点价格分层内，恢复组均优于未恢复组；锚点价格位置与 T+80 的相关性接近 0（-0.003 / -0.010），而恢复延迟相关性为 -0.195 / -0.206。
4. **样本与偏差提醒**：D1–D10 未恢复组样本充足（134 / 135 条）；但 D1–D20 未恢复仅 6 / 8 条，说明约 99% 的锚点最终都会恢复。这既是**幸存者偏差**的来源，也说明「未恢复」在长窗口下不可作为稳定分层变量。
5. **本轮不产生正式 Exit/持有规则。** 只回答「恢复是否携带独立信息」，不做 Exit/OOS/WFA、不创建 Candidate。

### 明确边界

- `fromRecoveryForward`（从恢复日起算）**条件于已恢复**，存在前视/幸存者偏差，不能与共同锚点口径混用作为因果证据；本报告主结论全部基于共同锚点口径。
- 恢复=「锚点后首个 NEW_HIGH_3」，是相关性证据而非因果；不排除存在未观测的共同驱动因素。
- 单状态、未组合评分、未搜阈值、未做 OOS/WFA；2026 为不完整年度，只作方向参考。
