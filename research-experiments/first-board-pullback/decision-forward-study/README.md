# 首板后回踩决策时点后续收益研究

## 研究问题

EXP-001 观察到首板后是否跌破首板日开盘价与后续表现存在明显差异，但 EXP-001 的收益锚是首板日收盘价，收益窗口从 T+1 开始，与路径条件期间重叠。

本实验改成决策时点之后的问题：

```text
在 T+k 收盘时，仅使用 T+1…T+k 已知路径分类
→ 从 T+k 收盘持有到 T+h 收盘
→ h > k，窗口严格为 rd ∈ [k+1, h]
```

## 输出

- 各决策日 T+1…T+5 × 后续视界 T+10 / T+20 的毛收益与净收益；
- 不破首板日开盘价组 vs 破位组；
- 回撤深度分桶；
- 平均净收益 95% 近似置信区间；
- 分年度结果；
- 固定往返成本敏感性。

## 不输出

- 最优决策日、最优视界、最优阈值；
- 策略、候选、参数搜索或排序；
- 统计显著性结论。

## 已知边界

- 价格按收盘到收盘计算，不是完整执行模型；
- 净收益只扣除统一成本参数；
- 未处理滑点、涨跌停不可成交、停牌、整手、公司行为和冲击成本；
- 当前 Dataset 只覆盖沪深主板。
