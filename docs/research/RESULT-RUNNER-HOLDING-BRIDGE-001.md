# RESULT-RUNNER-HOLDING-BRIDGE-001

> Baseline 口径修正：正式 1.62.1 性能基线仍为 1,359 笔 / +57.73%（T+20 执行，T80 仅作标签）；本轮 Bridge 矩阵使用 1,619 笔 / +15.79% 作为 T80 可执行研究基线。详见 RESULT-RUNNER-HOLDING-BRIDGE-001-CONSISTENCY.md。

> 目标：验证 T+6～T+10 的 PIT 单变量状态能否提前识别应突破原 1.62.1 时间退出、继续持有到 T+20/T+80 的交易。状态只影响时间退出后的持有期限；选股、3F Top3、T+6 入场、仓位、止损及其他退出规则保持不变。

## 0. 固定口径

- 策略：first-limit-pullback-3f-top3@1.62.1。
- 数据集：真实 T+80 datasetVersionId=750001（v7）；原 1.62.1 执行行使用 v5 官方投影，T+17～T+80 使用 v7 真实行情补齐。
- Bridge 决策点：第 5 个持有日（正常 T+10 收盘）只评估一次；仅当固定单变量状态命中，才把时间退出延后到 T+20 或 T+80。
- PIT：决策只读取截至当前交易日的行情；T+20/T+80 仅作为后续表现标签。
- 单变量矩阵：12 个状态 × {T+20, T+80}；不组合、不搜索阈值、不创建 Candidate。
- 官方 v5/T+20 历史基线为 +57.73%；真实 T+80 扩展数据对照为 15.79%，Bridge 矩阵用后者做同数据链比较。

## 5. 关键判断

1. Bridge 确实把一部分右尾 MFE 转成了实际 P&L：多个单变量组合 Full/IS/OOS 均高于 T+80 扩展基线，且 cost×2 仍为正。
2. 但收益不是无风险转化：Bridge 同时增加额外持仓日；大部分延长交易的最终退出由原有趋势/止损规则触发，而不是新增 Exit。
3. 平台具有多状态分布：关键状态包括 NEW_HIGH_2_T74、NEW_HIGH_3_T14/T74、CONSECUTIVE_HIGHER_HIGHS_GE_2_T74；T+80 目标整体优于 T+20，说明右尾需要更长持有窗口。
4. 不支持组合：本轮没有做状态组合、阈值搜索或 Exit 设计；以上只证明独立单变量平台值得下一轮正式 Runner 持有层验证。
5. 不创建 Candidate，不修改正式 1.62.1。
