# RESULT-RUNNER-HOLD-T20-NEWHIGH3-001

> 目标：验证 `T+20: newHigh3 == TRUE` 是否可作为原 1.62.1 时间退出后的 Runner 持有层。只允许 Runner 状态影响原时间退出后的持有期限，不改选股、3F Top3、T+6 入场、仓位、止损或其他退出规则。

## 0. 执行事实与语义边界

- 原 1.62.1 的时间退出最晚发生在第 10 个持有日；强势续持也不会超过第 10 个持有日。
- 固定实际成交样本共 1,359 笔；原时间退出：普通 306 笔 + 强势续持 114 笔；期末未平仓 5 笔。
- 在严格保持原退出的条件下，没有任何仓位自然存活到 T+20。
- 因此 `T+20 newHigh3 == TRUE` 不能在当前执行链中触发 Runner 延长，严格版 Runner 延长次数为 **0**。
- 若为了让仓位等待 T+20 状态而提前抑制第 5/10 日时间退出，会构成 PIT/退出规则变化，本轮禁止那样做。
- 本轮不新增 Exit、不组合条件、不优化阈值、不创建 Candidate。

## 2. T+20 newHigh3 的反事实研究层证据

以下统计来自固定 1.62.1 实际成交样本的 T+20 路径状态，仅用于研究中判断该状态是否值得进一步设计持有层，**不是本版策略的实际成交结果**。

| 样本 | N | 后续MFE | 后续MAE | +20% | +30% | +50% | +80% |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| newHigh3==TRUE | 373 | 25.53% | -16.16% | 39.14% | 27.35% | 14.21% | 6.97% |
| newHigh3==FALSE 对照 | 975 | 22.61% | -15.02% | 36.51% | 22.97% | 9.85% | 4.21% |

- T+20 样本：1,348 笔；`newHigh3==TRUE`：373 笔，覆盖率约 27.7%。
- TRUE cohort 相对 FALSE 对照：MFE +2.92%，+20% +2.63%。
- 状态带来一定右尾概率增量，但同时也伴随 MAE 扩大；没有证据表明这种增长能自动转化为实际策略收益。

## 3. 特别检查

- Runner 延长持有后的最终退出原因：**不存在**（延长次数 0）。
- 是否只是增加 MAE 和持仓时间：严格执行下没有增加持仓时间；反事实观察层中 MAE 从 -15.02% 扩大到 -16.16%，同时持仓风险暴露延长到 T+80。
- 是否转化为实际收益：**没有**。因为状态无法在原退出发生前参与执行，实际 P&L 与 Baseline 完全一致。

## 4. 最终判断

1. **正式策略持有层增量：没有。** 在该严格 PIT/原退出口径下，T+20 newHigh3 是 0 触发的 no-op。
2. **研究层价值：存在但有限。** 它提供 T+20 之后右尾概率的正向信息，但伴随 MAE 扩大，不能直接升级为持有规则。
3. **规则可执行性：当前不可执行。** 要让 T+20 状态影响持有，必须先单独设计和验证一套 T+6～T+20 的 PIT 持有桥接规则；本轮不做。
4. **不创建 Candidate，不修改正式策略。**
