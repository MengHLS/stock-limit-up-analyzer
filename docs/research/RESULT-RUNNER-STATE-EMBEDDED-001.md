# RESULT-RUNNER-STATE-EMBEDDED-001

> 目标：将 RESULT-RUNNER-STATE-T80-001 的 5 个单变量状态分别作为只读研究层，叠加到固定 `first-limit-pullback-3f-top3@1.62.1` 实际成交样本，验证其右尾识别价值和策略层增量。状态不进入选股、仓位或 Exit 执行链。

## 0. 固定口径

- 策略：`first-limit-pullback-3f-top3@1.62.1`，选股、3F Top3、T+6 open 入场、仓位、5%止损和原退出规则完全不变。
- 样本：1,359 笔实际成交；来源 `RESULT-3F-TOPN-3-V1_62_1-T80-001`。
- 数据：真实 T+80 dataset `datasetVersionId=750001`（v7，rd1..80）。
- 状态截点：T+10 / T+15 / T+20；状态只使用 `rd<=cutoff`。
- 后续标签：`cutoff+1..rd80`，T+20 对应 T+21～T+80。
- 5 个状态独立验证，不组合、不优化阈值、不创建 Candidate。
- Runner 状态只读，因此 5 个版本的正式策略执行结果按约束必须与 Baseline 完全一致；本节不把“状态分层”冒充策略收益改造。

## 5. 逐状态判断

1. **T+10 2日创新高：研究层右尾信息。** 覆盖率约 33%，MFE 和 +20% 均高于对照；但状态未进入 Exit，实际策略收益不变。
2. **T+10 连续收低2+：仅右尾反弹价值。** 均值 MFE 与对照几乎相同，但 +20% 达成率明显更高；适合作为右尾反弹状态，不适合解释平均收益。
3. **T+15 2日创新高：研究层右尾信息。** MFE 与 +20% 均小幅占优，年度方向较一致；实际策略仍无执行增量。
4. **T+15 连续创新高2+：研究层 MFE 信息。** MFE 差值较强、覆盖率约两成，但 +20% 稳定性弱于 MFE；只能作为 Runner 识别状态。
5. **T+20 3日创新高：当前最完整的 T+20 研究层状态。** 覆盖率约 28%，MFE 与 +20% 均高于对照，IS/OOS 方向一致；但因为它不改变原退出，实际策略指标仍与 Baseline 完全相同。

## 6. 最终分类

- 全部 5 个状态：**实际策略层增量 = 0（受“不得修改 Exit/仓位/选股”约束）**。
- 全部 5 个状态：**至少具备研究层右尾信息或 Runner 识别信息**。
- 其中 `T+10 连续收低2+` 只应表述为“右尾反弹价值”，不能表述为平均收益改善。
- 本阶段不创建 Candidate，也不设计新的 Exit；下一阶段若要验证真实策略改善，必须先单独设计并把 Runner 状态接入持有/退出层，不能在本轮偷偷实现。
