## 5. 特别验证（逐条回答）

### 5.1 OOS 是否仍然保持正向增量？——**是**

- 收益：B 47.22% → C 105.84%（+58.62pp）；cost×2：B 33.92% → C 81.94%。
- 风险：MaxDD 17.26% → 14.06%（下降）；PF 1.2948 → 1.4928。
- Runner 触发 41 笔（覆盖 11.85%），额外 PnL 89,259，额外持仓 276 天。

### 5.2 WFA 是否跨年份稳定，而不是依赖 2021/2025？——**增量方向稳定，绝对水平仍集中**

- **增量方向**：7/8 年 C 优于 B，中位增量 +8.11pp；剔除 2021、2025 后其余 6 年中 **5/6** 年增量为正。⇒ 增量**不是**只由 2021/2025 贡献。
- **绝对水平**：C 为正的只有 4/8 年（2021、2022、2025、2026）；剔除 2021、2025 后 C 累计 -11.52%（B -36.93%）——**仍为负**。⇒ 这套策略整体的盈利水平高度依赖 2021/2025 两个强年份。
- **cost×2**：逐年复利累计 B -34.46% → C 52.94%；剔除两个强年份后 B -59.05% → C -40.02%（仍为负）。

### 5.3 增量是否仍主要来自少数右尾大赢家？——**是，而且在逐年折中更极端**

- Full：逐笔额外 PnL 中位数 105.79 vs 均值 1554.89；**Top 10% Runner 贡献了 82.2% 的额外 PnL**。
- 逐年折里，多数年份的**逐笔额外 PnL 中位数为负**（2020 -108.00 / 2021 -257.54 / 2022 -336.15 / 2023 -196.97 / 2026 -289.67），Top 10% 贡献超过 100%（2020 120.2% / 2022 123.9% / 2023 997.2% / 2026 138.0%）。
- 持仓窗右尾达成率普遍抬升（如 OOS +20%：8.67% → 11.18%；+50%：0.87% → 2.30%），说明延长持仓确实多抓到了右尾——但**分布极度偏斜**。

- 全窗口与 OOS 的回撤都是**改善**的（FULL 54.81% → 43.30%；OOS 17.26% → 14.06%）。
- 但逐年折里 **2019 / 2022 / 2023** 出现回撤放大，其中 **2023 放大最明显**（且同一年收益也变差）⇒ 回撤风险不是被系统性消除，而是在弱年份被放大。

### 5.6 2023 / 2026 是否构成系统性问题？

- **2023 = 唯一在两种口径下都成立的相对劣势年份**：standalone B -4.89% → C -13.82%（-8.93pp），MaxDD 16.82% → 23.95%；continuous 视图同样变差。该年 Runner 命中 16 笔、直连额外 PnL 近零（377），拖累主要来自少开仓（残差 -9,308）⇒ **是"资金效率被占用 + 延长持仓未换来收益"的一年，不是单一极端事件**。
- **2026 不是系统性劣势**：continuous 视图下 C 略差，但 standalone 折下 C 明显更好（+10.22% vs +4.40%），cost×2 也由 -1.25% 转为 3.68% ⇒ 该年的相对劣势是**上一年末持仓/资金状态的传递效应**，而非规则本身失效。

## 6. 分类判定

> 说明：以下判定**不使用任何人为设定的收益阈值或评分公式**，只对 OOS/WFA 的客观方向、覆盖、集中度与机制做事实归纳。

客观结果汇总：

| 观察 | 事实 |
| --- | --- |
| OOS 增量方向 | ✅ 正（+58.62pp；cost×2 由 33.92% → 81.94%） |
| WFA 增量方向 | ✅ 正（7/8 年优于基线；中位增量 +8.11pp；剔除 2021/2025 后 5/6 年为正） |
| WFA 累计 | ✅ 正（167.34% vs 基线 9.50%；cost×2 52.94% vs -34.46%） |
| 绝对盈利集中度 | ⚠️ 高（C 正收益仅 4/8 年；剔除 2021/2025 后 C 累计 -11.52%，B -36.93%，两者皆负） |
| 增量来源集中度 | ⚠️ 高（Full Top10% Runner 贡献 82.2% 额外 PnL；多数年份逐笔中位数为负） |
| 机制纯度 | ⚠️ 部分年份的改善不来自 Runner 持仓本身（2021 直连额外 PnL 为负，改善全部来自资金循环） |
| 资金效率 | ⚠️ 逐年成交笔数下降、平均持仓日上升，多数年份残差为负 |
| 回撤 | ⚠️ 全样本/OOS 改善，但 2019/2022/2023 逐年折放大，2023 最明显 |
| 相对劣势年份 | ⚠️ 2023 在 standalone 与 continuous 两种口径下同时转差 |

### 结论分类：**CONDITIONAL**

- **不是 RESEARCH_ONLY**：规则的增量在**严格 standalone OOS（2025–2026，规则/执行冻结）中为正**，且 WFA 的 7/8 年增量为正、cost×2 累计由负转正——这是可复现的、跨年份方向一致的相对改善，不是只存在于全样本拟合里的现象。
- **不是 ROBUST**：三条客观事实不支持更高评级——(a) 绝对盈利仍高度集中在 2021/2025，剔除后 C 累计仍为负；(b) 2023 在两种口径下同时出现收益与回撤双恶化，且归因是资金占用而非单一极端事件；(c) 增量高度右尾化，且至少有一年（2021）的改善并不来自 Runner 持仓本身。
- **CONDITIONAL 的含义**：这条规则可以作为「**相对提升**」冻结进入下一阶段的正式策略验证，但不能被当作「已证明稳健的绝对收益来源」；上位策略（1.62.1）本身的年度盈利分布仍然是主要约束。

## 7. 结论与边界

1. **复现性**：full 窗口逐字段复现上一轮（parity PASS），standalone OOS 与仓库既有 canonical OOS 链一致（+47.22% / 346 笔）。
2. **OOS**：Runner 在完全冻结的 2025–2026 上仍产生正向增量（+58.62pp，且 MaxDD 下降、cost×2 更优）。
3. **Rolling WFA**：7/8 年优于基线、累计 167.34%（基线 9.50%）；但盈利水平集中、1 个年份转差、回撤在 3 个年份放大。
4. **机制**：规则的真实作用是取消最强 cohort 的 T+10 时间上限，让原止损/趋势规则继续决定离场（无任何一笔走到 T+80 时间退出）；代价是资金占用上升、建仓数下降。
5. **⚠️ 最重要的诚实边界**：`newHigh3` 这一状态本身是在**全样本（2019–2026）**上通过 Runner 状态研究（RESULT-RUNNER-STATE-T80-001 / -EMBEDDED-001）筛出来的。本轮冻结的是**规则的使用**，**不是规则的发现过程**；因此 2025–2026 的「OOS」对**状态选择**这一维并不干净，真实样本外表现预期应低于本轮数字。若要彻底消除该污染，需要在独立数据集或未来真实时间上做前瞻验证。
6. 不创建 Candidate、不修改正式 1.62.1、不新增买入方案、不调整 25% 单票上限。
