# RESULT-RUNNER-STATE-TRANSITION-001

> 目标：研究 +10%/+15% 激活后，「Runner 强势状态」与 CLC2（连续收低≥2天首次结束）之间的先后状态转换，以及转换后的后续表现。
> 固定：dataset `first_limit_pullback` / `datasetVersionId=660001`；execution projection 沿用已验证 T80（v5 官方行 + 选中事件 v7 rd17..80）；固定池 `D20 < -10% && MA20Slope <= 0`；状态定义逐字复用 RUNNER-STATE-RESEARCH-004 / CLOCK-MAP-001。
> 单状态转换、不做多状态组合评分、不搜参数、不创建 Candidate、不修改正式 Strategy、不做 Exit 实验、不做 OOS/WFA。
> 报告由 `scripts/reportRunnerStateTransition001.mts` 从落盘 evidence 机械生成。

## 5. 结论

1. **CLC2 的正向效果确实来自「回撤后的再上涨」，而不是 CLC2 本身。** 在同一口径下：`CLC2_TO_STRONG`（CLC2 之后重新走强）转换后 T+80 净收益均值最高——`NEW_HIGH_3` P10 +3.53%（年度 5/3）、`CLOSE_ABOVE_MA10` P10 +3.00%；而 `STRONG_TO_CLC2`（强势之后转弱进入 CLC2）基本落在 0 附近甚至为负（`MA10_SLOPE_POSITIVE` P10 -0.01%、P15 -0.36%）。
2. **强势→CLC2 与 CLC2→强势恢复存在明显不对称。** 前者是「走强之后转弱」，转换前收益均值 -4.21%～-5.39%（负），转换日偏中后段（rd17–21）；后者是「走弱之后重新走强」，转换前收益 +3.74%～+5.45%（正），转换日更早（rd10–15）。
3. **CLC2 不只是价格位置效应。** 若只是「价格低」效应，那么在锚点对照中，是否恢复强势应当差别不大；实测恢复组 T+80 均值 +1.69%，未恢复组 -9.53%（不过未恢复组样本仅 2 条，只能作方向提示）。更重要的是：恢复的**时机**（NEW_HIGH_3 中位 rd10、CLOSE_ABOVE_MA10 中位 rd12）显著早于强势→CLC2 的转弱时点（rd15–21），说明「再上涨」是 CLC2 正向效果的承载。
4. **最值得进入下一阶段研究的是 `CLC2 → NEW_HIGH_3 恢复`**：转换后 T+80 均值最高（P10 +3.53% / P15 +3.38%），T+20 与 T+40 的均值/中位/胜率一致为正，年度 5/3。`CLC2 → CLOSE_ABOVE_MA10` 次之；`STRONG → CLC2` 不建议作为下一阶段主线。
5. **本轮不产生正式 Exit/持有规则。** 只回答「哪些状态转换与后续表现相关」，不做 Exit、不做 OOS/WFA、不创建 Candidate。
