## 0. 结论前置

### 0.1 两个必须回答的问题

> #### ❓ 这些因子究竟是在寻找绝对上涨，还是在同一天股票池中寻找相对更强、右尾更厚的股票？

## 🔴 答案：**都不是。**

**它们不是在寻找「相对更强」，而是在寻找「相对更极端（更厚尾）」的股票 —— 尾部显著更厚，但均值显著更差。**

| 证据 | 数值 | 含义 |
|---|---|---|
| 同日 `ExcessMean > 0` 的格子 | **0 / 32** | 「相对更强」假设被**直接否证** |
| 同日 `ExcessMean` **显著为负**（CI 整体 < 0）的格子 | **26 / 32** | 不只是「没有超额」，而是**显著跑输同日池** |
| 同日 `ExcessTCR50` **显著为正**（CI 下界 > 0）的格子 | **23 / 32** | 右尾超额**真实存在** |
| 同日 `Tail Lift` CI 下界 > 1 的格子 | **24 / 32** | 同上（最高 `Lift` = **3.22**） |
| 单因子单持有期「`ExcessMean` 为正」的最多年数 | **4 / 7** | 均值方向**从未**形成跨年多数一致 |

**机制**：这些因子（振幅、换手、前期涨幅、回撤深度、涨停间隔）本质是**波动率 / 彩票性选择器**。它们在一天之内挑出**最极端**的几只，于是：
- 右尾更厚（`ExcessTCR50` 最高 **+1.63 pp**，`Lift` 最高 **3.22**）✅
- 但同一天内**均值更差**（`ExcessMean` 最低 **−3.99 pp**）❌

在**池日均收益恒为负**的首板事件池里，这个「同日内选更极端」的操作**净效应是负的**。这解释了此前全部链条：为什么 `Tail Lift > 1` 与 `Rank IC < 0` 能共存 —— 因为被选中的股票**方差更大**，同时抬高了两端。

> #### ❓ 每个因子的有效期限主要属于短期、中期还是长期？

| 期限 | 因子数 | 因子 |
|---|---:|---|
| **SHORT**（H5 / H10） | 2 | `t1VolumeRatio`(H10) · `drawdownDepth`(H10) |
| **MEDIUM**（H20） | **6** | `bodyHeight` · `turnover` · `meanAmplitude` · `maxAmplitude` · `limitGap` · `preReturn10` |
| **LONG**（H60） | **0** | —— |
| `NO_STABLE_HORIZON` | 0 | —— |

🔴 **横截面右尾超额的峰值在 H20（中期）**：`ExcessTCR50` 在 H20 达到 4 个持有期中的最大值（`meanAmplitude` **+1.63 pp**、`preReturn10` **+1.28 pp**、`maxAmplitude` **+0.99 pp**、`limitGap` **+0.87 pp**），年度一致性也在 H20 最好（5 个因子 **7/7 年**同向）。
🔴 **H60 是明确无效区间**：4 个因子的 `ExcessTCR50` 在 H60 掉到 ≤ 0，`ExcessMean` 恶化到 **−1.0 ~ −4.0 pp**。

### 1.2 🔴 核心方法：按交易日计算超额（**禁止把全部交易混在一起**）

对每个决策日 `d`：

```text
当日基准          All-Pool Mean / Median / TCR20 / TCR50 / TCR100
因子 TopK         TopK   Mean / Median / TCR20 / TCR50 / TCR100
同日 Excess       ExcessMean    = TopKMean  − AllPoolMean
                  ExcessMedian  = TopKMedian − AllPoolMedian
                  ExcessTCR20/50/100 = TopK TCR − AllPool TCR
                  ExcessTailLift = TopK_TailRate / AllPool_TailRate
```

**聚合方式**：先在**每个决策日内**求差，再对**日序列取日等权均值**并做**日簇 Bootstrap**。
🔴 这与「池化差」（把 56,987 笔交易混在一起相减）是**两个不同的量**；池化差会被「哪一天有行情」这个**时间序列**成分污染，**日等权配对差才是横截面能力的度量**。

## 4. 同日 Excess 结果（Q1 / Q2）

### Q1 · 横截面超额是否存在？

| 结果 | 数量 |

| 满足「`pickMean < 0` 且 `ExcessMean > 0`」的格子 | 🔴 **0 / 32** |

**`pickMean < 0`（绝对收益为负）在 32/32 格全部成立** —— 但 `ExcessMean` **全部 ≤ 0**，其中 **26/32 显著为负**。

> ### 🔴 **Q1 答案：不存在。**
> 因子**没有**在同一天选出「相对更强」的股票；相反，它们选出的股票在**同日内显著更弱**。

## 11. 🔴 负对照与自查发现的缺陷（必须与结论同读）

### 11.1 自查发现的缺陷：`RAND` 破平键**不是**随机对照

首轮实现按「随机 TopK 使用固定 seed，并保持现有 tie-break 规则」的字面要求，用 `rankCandidates(cands, direction, "RAND")` 做随机臂。
**实查发现该做法失效**：`rightTailMetrics#rankCandidates` 的 `key` 参数是**同值破平键**——

```ts
if (left.value !== right.value) return direction === "HIGH" ? right.value - left.value : left.value - right.value;
return compareByKey(left, right, key);   // ← key 只在「因子值完全相等」时生效
```

因此对**连续因子**（`bodyHeight` / `meanAmplitude` / `preReturn10` / `drawdownDepth` / `maxAmplitude`），当日几乎不存在完全相等的因子值 ⇒ `RAND` 选出**与 `ASC` 完全相同**的 Top3 ⇒ 该「随机臂」是**复制**而非对照。
（对离散因子如 `limitGap`/`historyCount` 才有效果：`limitGap` H5 的 `RAND` 臂 `ExMean −0.460` ≠ 因子臂 `−0.308`，可佐证机制。）

**⇒ 第一轮「负对照」的 64 个臂中有 59 个 CI 不覆盖 0 —— 这是缺陷的症状，不是管线有偏的证据。已作废该表，并重建正确的对照。**

### 11.2 正确重建的负对照：逐日**均匀随机无放回** K 子集

方法：在每个决策日内，对当日池做**与因子取值完全无关**的均匀随机抽样取 K 只（每格 **200 个独立种子**）。

## 13. 对「最终结论要求」的正式回答

> **这些因子究竟是在寻找绝对上涨，还是在同一天股票池中寻找相对更强、右尾更厚的股票？**

**都不是。** 它们既不是在寻找绝对上涨（`pickMean < 0` 在 32/32 格成立），**也不是**在寻找「相对更强」（`ExcessMean > 0` 为 **0/32**，26/32 **显著为负**）。

**它们是在同一天股票池中寻找「相对更极端、右尾更厚」的股票。** 这是一类**方差 / 彩票性选择器**，不是**强势选择器**：
- 同一天内，它们挑出的股票**右尾显著更厚**（`ExcessTCR50` 显著为正 23/32，`Lift` 最高 **3.22**，年度最深 **7/7**）✅
- 同一天内，它们挑出的股票**均值显著更差**（`ExcessMean` 显著为负 26/32，最深 **−3.99 pp**）❌

这解释了整条研究链的一致困惑：**`Tail Lift > 1` 与 `Rank IC < 0` 之所以能长期共存，是因为被选中的股票方差更大 —— 同时抬高了两端。** 在池日均收益为负的首板事件池里，「同日内选更极端」的净效应是负的。

> **每个因子的有效期限主要属于短期、中期还是长期？**

**6 个 MEDIUM（H20）· 2 个 SHORT（H10）· 0 个 LONG。**
`ExcessTCR50` 的绝对捕获量与年度一致性都在 **H20** 最好；`Lift` 的峰值在 H5；**H60 全线失效**（4 个因子转负）。

**⇒ 下一阶段不应继续做组合优化，而应进入「如何利用横截面右尾信号构建 Top3/Top5 选股规则」——且该规则必须先解决「同日内更极端 ⇒ 均值更差」这一结构性代价。**
