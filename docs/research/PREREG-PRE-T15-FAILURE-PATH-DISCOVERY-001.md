## 2. 靶指标（P2，**先声明**）

## 5. 稳定性判据（Stage 3，**事前**）

对每个标记，先算 `Δ40 = mean(r40 | 标记=真) − mean(r40 | 标记=假)`。

* **STABLE_FAILURE_PATH**（全部满足）：
  1. `n(标记=真) ≥ 1,000`
  2. `Δ40 ≤ −2.0pp`（经济意义下限，事前设定）
  3. **IS（事件年 2019–2022）与 OOS（2023–2025）符号一致，且二者均 `≤ −1.0pp`**（切分事前固定）
  4. **7 个年度中 `Δ40 ≤ 0` 的年份 ≥ 6**
  5. **决策日内置换检验 `p < 0.01`**（在 rd15 `tradeDate` 内打乱标记，1,000 次）
  6. **相邻时间尺度同号**：`Δ20 < 0` **且** `Δ30 < 0`（同为负）
* **PARTIAL_FAILURE_PATH**：满足 1~2 但 3/4/5/6 至少一项不满足。
* **NO_STABLE_FAILURE_PATH**：所有标记均不满足 1~2，或符号在 IS/OOS 间翻转。

> 额外要求：报告每个标记与**正式策略 Top3 入选集合**的重叠率（`marker ∩ Top3`）。
> 若重叠 ≈ 0 ⇒ **该标记对正式策略无增量**（须显式说明，不得包装成 Filter）。
