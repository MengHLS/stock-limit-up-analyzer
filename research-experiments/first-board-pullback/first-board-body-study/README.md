# 首板实体柱高度研究

## 研究问题

首板 K 线的实体柱高度是否与 T+1 开盘入场后的未来收益有关？

## 固定口径

- 主指标：`bodyHeight = (首板 close - 首板 open) / 首板 previousClose`。
- 辅助指标：`bodyRangeRatio = (close-open)/(high-low)`；一字板无区间，记为 `null`。
- 事件：收盘价严格等于交易所四舍五入口径涨停价的首板。
- 入场：`T+1` 开盘，要求 `canBuyAtOpen=true`。
- 退出：`T+5`、`T+10`、`T+20` 收盘。
- 成本：固定扣除 `20 bps` 往返成本。
- 统计：按事件日聚类的 Moving Block Bootstrap。

## 实体分桶

- `≤0.1%`
- `0.1% ~ 2%`
- `2% ~ 4%`
- `4% ~ 6%`
- `6% ~ 8%`
- `≥8%`

分桶是固定描述，不选择最优实体区间。

## 已知偏差

- 尚未做同日市场收益的完整中性化。
- 未实现涨跌停排队、滑点、冲击成本和部分成交。
- Bootstrap 不能替代独立 Holdout。

## 刻意不做什么

- 不输出最优实体高度或策略对象。
- 不将当前窗口的样本内差异声称为正式策略证据。
