## 6. 结论：阈值是否平台型 / 能否冻结为下一候选

### 6.1 平台性判定（机械判据：存在 ≥3 个连续阈值，OOS 均优于基线且彼此落差 ≤ 5pp）

**判定：不存在这样的区间 ⇒ 不是平台型，是尖峰型。**

- OOS 最优阈值 = **p33**（+66.95%）；相邻阈值最大落差 = **55.84pp**；OOS 全区间极差 = 55.84pp。
- **三个目标函数指向不同阈值**：OOS 最优 = p33，全窗口×1 最优 = p50，成本×2 最优 = p50 ⇒ 不存在同时占优的稳定区间。

### 6.2 逐项回答

| 问题 | 答案 | 证据 |
| --- | --- | --- |
| 阈值是否平台型 | **否** | 无任何 ≥3 连续阈值同时优于基线且落差 ≤5pp；OOS 相邻最大落差 55.84pp |
| OOS 是否一致改善 | **否（2/4 改善）** | p25 +57.46% / p33 +66.95% / p40 +11.11% / p50 +16.82%（基线 +47.22%） |
| WFA 是否改善 | **是（4/4）** | 正收益年份 3/8 → p25 5/8 / p33 5/8 / p40 5/8 / p50 6/8；中位数 -6.40% → +4.43% / +4.23% / +5.48% / +5.00% |
| cost×2 是否改善 | **不一致（3/4 优于基线，1/4 转正）** | p25 -28.46% / p33 -13.36% / p40 -15.36% / p50 +44.04%（基线 -20.57%） |
| 2023 亏损来源 | 见 §5 | 闸门版 2023 亏损反而加深；被闸门排除的 2023 交易为**净盈利** |
| 是否可冻结为下一候选 | **否** | 非平台型 + OOS 方向不一致 + 2023 反证 + 成本改善不可靠 |

### 6.3 结论

**① 不是平台型。** 四个阈值里，OOS 只在 p25/p33 优于基线（+57.46% / +66.95%），到 **p40 直接塌到 +11.11%**（相邻落差 55.84pp），p50 +16.82%；而全窗口×1 与成本×2 的最优阈值却是 **p50**（+116.96% / +44.04%）。三个目标函数指向不同阈值 ⇒ 这是**尖峰**不是平台。

**② 唯一一致的正向信号是 WFA（逐年）。** 四组阈值的正收益年份都从基线的 3/8 升到 **5~6/8**、年度中位数从 -6.40% 升到 **+4.2%~+5.5%**、最差年份改善。但「年度命中率改善」与「样本外收益改善」并不一致（p40/p50 的 OOS 明显差于基线），说明改善的是**分布形状**而不是**收益水平**。

**③ 2023 年是决定性反证。** 闸门把 2023 从基线的 **-4.89%** 打成 **-20.89%**；基线 2023 净盈亏 -4,834 元 / 211 笔，闸门版 -19,229 元 / 82 笔 ⇒ **被闸门挡掉的 129 笔合计净赚 +14,395 元**。即「涨停家数低 ⇒ 该避开」这条假设在 2023 年**方向相反**，闸门删掉的正是赚钱的交易日。

**④ 能否冻结为下一候选版本：不能。** 判据逐条：非平台型（✗）、OOS 一致改善（✗，2/4）、cost×2 改善（✗/不一致）、2023 反证（✗）。尽管 WFA 与部分阈值确实改善，但不足以支撑冻结。**本轮不进入 Candidate、不新增其它过滤条件**（遵守任务约束）。

**⑤ 下一步建议（不含新过滤条件）**：先解释「为什么 p40/p50 在 2025-2026 崩塌、却在 2019-2024 与全窗口大幅变好」，以及「2023 年低涨停家数日反而盈利」的机理；在机理未澄清前，任何阈值选择都只是在该窗口上挑数字。
