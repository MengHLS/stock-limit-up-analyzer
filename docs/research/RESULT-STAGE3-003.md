## 3. 🎯 定位（Goal 原则 5：先定位失败原因，不得为通过而反向修改研究口径）

### 3.1 失败机制

| 观察 | 解读 |
|---|---|
| **IS 熊市年收益大幅缩水**：2021 **+11.42% → +2.97%** · 2023 **+1.58% → −2.91%** | 🔴 **MA200 闸门在熊市禁止开仓 ⇒ 直接砍掉了熊市中的建仓机会** |
| 2020 也缩水：**+8.76% → +4.10%** | 闸门在 2020-02 起大量命中（疫情下跌段） |
| MDD **几乎未改善**（−17.21% → −17.32%） | 减少开仓**并未降低回撤** ⇒ 回撤来自**已持有仓位**，而非新开仓 |
| OOS MDD 大幅改善（−15.62% → −8.65%） | OOS 段闸门命中的时段恰与 2024 年初的回撤重叠（**样本特定**） |

### 3.2 🔴 机制性发现（**本轮真正的价值**）

> ## **策略的熊市收益来自【熊市中的新建仓】，而不是「持有旧仓」**
> ## ⇒ **在下跌市场禁止开仓 = 直接砍掉 Alpha 来源**（`STAGE3-002` 已确立 Alpha = 熊市防御）
> ## 📌 **该因子（rd11~15 低振幅）选出的标的在下跌市中【抗跌】** ⇒ 熊市正是其**最有效的建仓时点**
> ## ⇒ **这也反向解释了 E1 为何失败**：策略 Alpha 是「**在下跌市中选出抗跌标的**」；**均匀放大暴露**会同时放大**非抗跌标的**的损失 ⇒ Calmar 恶化
