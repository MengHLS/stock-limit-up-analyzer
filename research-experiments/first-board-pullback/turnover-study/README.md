# 换手率与未来收益研究

## 研究问题

首板日换手率高低是否与 T+1 开盘后 T+5 / T+10 / T+20 的收益有关。

同时检查首板日流通市值字段是否可用于研究。

## Bootstrap

统计不确定性使用按交易日聚类的 Moving Block Bootstrap：

- 同一交易日事件不拆开；
- 重采样连续日期块；
- 默认 `1000` 次、block `20` 个交易日；
- 固定随机种子，结果可复现。

## 当前数据状态

- `turnover`：可用；
- `floatMarketCap`：当前 Dataset 全部为空，流通市值关系标记为 `INSUFFICIENT_DATA`；
- 不根据当前股本和历史价格伪造 point-in-time 市值。

## 不输出

- 最优换手率区间；
- 最优市值区间；
- 策略、候选或排序结论。
