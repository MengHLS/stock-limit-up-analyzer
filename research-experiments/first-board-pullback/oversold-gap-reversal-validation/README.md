# 超跌长间隔首板冻结验证

## 冻结假设

`H_OVERSOLD_GAP20_DROP10_T10`

- 股票范围：Dataset 构建阶段固定为沪深主板、排除 ST。
- 事件 `T`：首次涨停。
- 条件一：`daysSincePreviousLimit > 20` 个交易日。
- 条件二：`close(T-1) / close(T-11) - 1 < -10%`。
- 决策：`T` 日收盘后，只使用事件日前信息和当日首板事实。
- 入场：`T+1` 开盘，要求 `canBuyAtOpen=true`。
- 主退出：`T+10` 收盘。
- 辅助观察：`T+5`、`T+20`，不参与 Gate 判定。
- 成本：固定扣除 `20 bps` 往返成本。

## 基准

同一事件日所有满足 `T-11/T-1` 数据要求、且具有相同 `T+1` 开盘和 `T+10`
收盘执行数据的 eligible 首板事件。计算超额收益时排除信号事件自身，并要求同日
至少有一条其他 eligible 首板。

## Observation Gate

只有以下数据准备条件全部满足才输出 `OBSERVATION_READY`：

- 有效信号样本不少于 300。
- 信号事件交易日不少于 80。
- 同日基准可比信号样本不少于 300。

样本不足输出 `INSUFFICIENT`。Observation 不判断收益是否正向。

## Holdout Gate

样本准备条件通过后，以下条件必须全部满足才输出 `PASS`：

- `T+10` 平均净收益大于 0。
- `T+10` 中位净收益大于 0。
- `T+10` 净收益胜率大于 50%。
- 日期聚类 Moving Block Bootstrap 平均净收益 95% CI 下界大于 0。
- 同日首板基准平均超额收益大于 0。
- 超额收益日期聚类 Bootstrap 95% CI 下界大于 0。
- 去掉最高 5% 收益后平均净收益仍大于 0。

任一项失败输出 `FAIL`。参数、窗口或阈值在 Holdout 前不得修改。

## 已知偏差

- 未模拟涨跌停排队、滑点、冲击成本、部分成交、整手和公司行为。
- `20 bps` 是冻结成本敏感性参数，不是完整成交模型。
- 同日首板基准用于控制市场共同波动，但不等于完整的行业 / 风格中性化。
- Observation 和 Holdout 由平台协议窗口强制执行，且不得重叠。
