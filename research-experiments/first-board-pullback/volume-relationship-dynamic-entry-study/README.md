# 首板前后成交量关系与动态入场研究

## 动态状态机

- 入场：`T+1..T+5` 首次收盘回撤至首板收盘下方 `100bps`，且此前未跌破首板开盘价，次日开盘买入。
- 退出：买入后收盘跌破首板开盘价，则下一可卖开盘退出；否则 `T+10` 收盘退出。

成交量不参与入场或退出，只作为研究特征。

## 成交量因子

所有量比均除以 `T日成交量`：

- PRE：`T-1/T`、`T-2/T`、`T-5/T`、`T-10/T` 及四个前置日期的均量比。
- ENTRY：触发日量比、`T+1..触发日` 均量比。
- POST：`T+1/T` 至 `T+5/T`，只用于研究入场后的量能路径，不反向筛选入场。

量比分桶：`<50%`、`50%~80%`、`80%~120%`、`120%~200%`、`≥200%`。

## 已知偏差

- 成交量未做复权或股本变化调整，直接使用 Dataset 的 volume 字段。
- 未实现盘口排队、滑点、部分成交和量价撮合。
- 属于探索性研究，不能替代独立 Holdout。
