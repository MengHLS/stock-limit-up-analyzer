## 1. 唯一的研究问题

> **这个评分到底能不能帮助我每天从首板股票里挑出前几名？**

## 2. 为什么不能直接引用分档结果

`RESULT-12F-COMPOSITE-001.md` 给出的是**全样本分档**结论
（D10 − D1 = +0.79pp，CI95 [0.00pp, 1.63pp]，`POSITIVE` 但边界性）。
分档与 Top-N 是**两个不同的问题**：

| | 分档（12F） | Top-N（本实验） |
|---|---|---|
| 切法 | 全样本按评分排序后**按人数等分**成 10 档 | 每个**决策日**内按评分排序取前 N 名 |
| 单位 | 档 | 日 |
| 基准 | 相邻档 / 头尾档 | **同一天全部候选**（= 随机 N 的期望） |
| 能证伪的情形 | — | 梯度只存在于尾部；头部与中部差 < 日内噪声；评分尺度被压缩后头部差异消失 |

🔴 一个评分完全可以在分档上单调、却在 Top-N 上毫无优势。所以必须单独测量。

## 3. 坐标（与 12F 逐字相同，除新增的「日分组」层）

| 项 | 取值 | 来源 |
|---|---|---|

| 入场 / 退出 | **T+6 开盘** / **T+10 收盘**（不可卖顺延至 T+20） | 与 12F 相同 |
| 成本 | **20 bps 往返** | 与 12F 相同 |
| 评分 | 12 因子等权桶位分（`FROZEN-BUCKET-CONTRACT-001`） | **零改动** |

新增的一层：**按 `eventDate`（= 首板日 T = 决策日）分组**，组内按评分降序取前 N。

## 4. 档位与日集

- 固定档：`N = 1 / 2 / 3 / 5 / 10`（`Top-1` 是「挑第一名」的最纯形式，必须在内）；
- 比例档：`Top-20%`（`round(当日样本 × 0.2)`，至少 1 个）；
- **本职日集（OWN）**：当日可用样本 ≥ 该档所需 N；
- **固定日集（DEEP）**：当日可用样本 ≥ 10，**所有档共用同一批决策日**
  ⇒ 跨档比较必须以这一口径为准（OWN 下各档的行集合并不相同）。

## 5. 判据

### 5.1 主判据（唯一）

```
对每个决策日 d：
  topNMean_d = 当日 Top-N 的等权平均净收益
  poolMean_d = 当日**全部可用样本**的等权平均净收益
  excess_d   = topNMean_d − poolMean_d                      （同日、同坐标、配对）

主指标 excessMean = mean_d(excess_d)
区间 = 日期聚类 Moving-Block Bootstrap 95%（block = 20 交易日，1 000 次，固定种子 20260926）
判定：CI 下界 > 0 ⇒ POSITIVE；上界 < 0 ⇒ NEGATIVE；跨 0 ⇒ INCONCLUSIVE；决策日 < 100 ⇒ INSUFFICIENT
```

🔴 随机抽 N 个股票的**期望**恒等于 `poolMean_d` ⇒ `excess` 就是「相对随机抽签的平均优势」。

### 5.2 副判据（必须与主判据分开读）

| 判据 | 回答的问题 |
|---|---|
| `portfolioMean` + CI + 判定 | **这样挑能不能赚钱**（绝对收益；即使超额为正也可能为负） |
| `dayWinRate` | 有多少比例的决策日跑赢当日池 |
| `pickHitRate` vs `poolHitRate` | 选中的股票上涨概率是否高于池 |
| 反转臂（取最低 N 个） | 评分是「能识别差」还是「能识别好」（**对称性检验**） |
| 深度曲线（K = 1..20） | 信号是否只存在于最头部 |
| 随机 N 基准（1 000 次模拟） | 观测值落在随机分布的第几分位 / 单侧 p |
| 15 键对照矩阵 | 综合评分 vs 12 个单因子，**谁更能帮我挑** |
| 年度切片 | 描述性的逐年稳定性（**不是**稳健性检验） |

## 9. 已知风险（必须在结论里同时声明）

1. 🔴 **持仓重叠**：持有 5 个交易日 ⇒ 相邻决策日持仓重叠，日度序列非独立观测。
2. 🔴 **等权口径**：主指标 = 各决策日等权平均（每决策日一单位资金），不是资金曲线。
3. 🔴 **基准不可交易**：当日全部候选等权在真实资金下无法同时买入 ⇒ `POSITIVE` 只说明「排序有信息」。
4. ⚠️ **多重比较**：15 键 × 6 档 × 2 日集 ≈ 180 个判定，α = 0.05 下假阳性期望 ≈ 9 ⇒ 全部结论为探索性。
5. ⚠️ **窗口限定**：v5 是单一区间，不可外推。
6. ⚠️ **样本权重**：`derive.ts` 未改动 ⇒ 与 12F 的候选 / 入池 / 剔除原因应当逐项相同（结果里有自检字段）。
