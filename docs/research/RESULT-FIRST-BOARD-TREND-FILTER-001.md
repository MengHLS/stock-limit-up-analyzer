# RESULT-FIRST-BOARD-TREND-FILTER-001

> 目标：验证“首板回撤 + 均线趋势过滤 + 原 3F 评分 + Top3”是否提升股票池筛选能力、减少无效交易。
> 本报告基于 Dataset Registry `first_limit_pullback` id=660001，共 73,003 个首板事件。

## 0. 研究口径

- 池形成时点：`T+5` 收盘。
- 评分：原 1.62.1 3F 等权合成分，按分数降序取每日 `Top3`；不复用 1.62.1 的仓位、exit 或参数搜索结论。
- 质量标签：沿用既有首板研究协议，`T+1` 开盘至 `T+5/T+10/T+20` 收盘；净收益扣 20bps 往返成本。
- 趋势过滤：
  - A：`MA5 > MA10 > MA20`；
  - A10/20：`MA10 > MA20`；
  - B：`close(T+5) >= MA10` 且 `>= MA20`；
  - C：`T+1..T+5` 每日收盘未有效跌破 `MA20`（容差 0.5%）；
  - AB / AC / ABC：对应规则交集。
- 基准组：首板回撤池 → 原 3F → Top3；实验组：先趋势过滤 → 原 3F → Top3。
- 全首板对照池：所有具备 T+1 开盘及 T+5/T+10/T+20 收盘的首板事件，共 **71,550** 个；3F 可评估池 **48,838** 个。

## 3. 重点回答

### 1）均线过滤是否减少无效首板股票？

是。尤其 `B` 和 `ABC` 将 3F 可评估池压缩到约一半：B 保留 55.39%，ABC 保留 47.88%。与此同时：

- T+5/T+10/T+20 均值相对 Baseline 明显改善；
- T+20 胜率由 28.26% 提升到 33.39%~34.25%；
- T+20 盈亏比由 0.911 提升到 1.153~1.165；
- 止损触达率由 91.5% 降至 87.3%~87.4%；
- 最大回撤代理从 -99.37% 改善到 -92%~-93%。

结论：均线趋势过滤确实减少了“处于弱势/破位结构”的首板，尤其价格位置规则 B 的效果最直接。

### 2）3F 是否更适合作为趋势股票池评分，而非直接交易信号？

本轮证据**不支持**把当前 3F Top3 当作趋势池的有效二次筛选器。相反，3F Top3 在多数规则下低于趋势过滤后的完整池均值：

- B：过滤后完整池 T+5 均值 -0.40%，3F Top3 变为 -2.11%；
- ABC：过滤后完整池 T+5 均值 -0.51%，3F Top3 变为 -2.05%；
- Baseline 的 3F Top3 也低于全首板池，未证明独立 alpha。

因此当前证据更像：**趋势过滤负责筛掉无效结构；现有 3F 评分没有继续改善趋势池收益，不能假设它天然适合作为趋势池评分。**

### 3）最优股票池构建规则是什么？

- **简单首选：B（收盘≥MA10 且≥MA20）**。池缩减 44.6%，三类未来窗口的均值和胜率最好，T+20 盈亏比 1.165，风险改善最稳定。
- **严格候选：ABC**。池缩减 52.1%，Top3 集中度最高，止损触达数和最长连续亏损更优；但 H20 均值略弱于 B，说明额外加入 A/C 主要换取更窄池与风险约束，而不是额外收益。
- **A 单独使用效果有限**：MA5/10/20 排列能改善部分收益，但不如 B/AB/ABC，且池缩减较小、改善幅度有限。
- 若继续推进，应先验证 **B 趋势池** 的 OOS/WFA/成本稳健性；3F 评分应作为待重新校准的评分候选，而不是直接沿用为趋势池排序器。

## 4. 限制

- 标注采用历史首板研究协议 `T+1 开盘 → T+5/T+10/T+20 收盘`，用于衡量股票池的事后质量，不等同于 T+5 收盘后的可交易策略收益。
- 最大回撤为重叠事件的日度等权组合代理，不是独立资金账户回测。
- 本阶段没有组合因子、没有重训 3F、没有创建策略版本。
