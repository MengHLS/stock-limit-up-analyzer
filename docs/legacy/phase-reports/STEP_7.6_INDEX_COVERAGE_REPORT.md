## 二、身份校验（index identity）

### 2.1 权威参考锚点（`CORE_INDEX_IDENTITY`）

| index | 基期（baseDate） | 首发（launchDate） |
|-------|------------------|--------------------|
| 000001.SH 上证指数 | 1990-12-19 | 1991-07-15 |
| 399001.SZ 深证成指 | 1994-07-20 | 1995-01-23 |
| 399006.SZ 创业板指 | 2010-05-31 | 2010-06-01 |
| 000300.SH 沪深300 | 2004-12-31 | 2005-04-08 |
| 000905.SH 中证500 | 2004-12-31 | 2007-01-15 |
| 000852.SH 中证1000 | 2004-12-31 | 2014-10-17 |

### 2.2 两个关键身份结论

1. **Sina 000300 自 2002 起 → `DATA_BEFORE_BASE`（强告警）**：沪深300 基期 2004-12-31，Sina 却声称 2002 就有数据（STEP 7.2 实测）。这早于基期，**不可能**是官方序列，只能是错误身份或第三方回填。`verifyIndexIdentity` 会标记 CONCERN。**禁止把 Sina 000300 当作沪深300 完整历史。**

2. **BaoStock 指数自「基期」起 → `DATA_BEFORE_LAUNCH`（弱告警，官方回溯）**：BaoStock 的 000300 从 2005-01-04 起（基期 2004-12-31 之后、首发 2005-04-08 之前），这是指数公司**官方回溯**到基期的序列，可接受，但「首发日之前」的数据本质是回溯计算、非盘中观测，研究使用时需知晓。

> 校验机制对「早于基期」和「早于首发」分级：前者强告警、后者弱告警，均不盲信。
