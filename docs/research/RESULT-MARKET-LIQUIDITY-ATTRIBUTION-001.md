# MARKET-LIQUIDITY-ATTRIBUTION-001

> 基线：`first-limit-pullback-3f-top3@1.62.1`。
> 目标：只替换 `definition.marketRegimeFilter`，研究市场成交活跃度是否是首板回踩 3F 有效性的独立市场状态变量。
> 数据窗口：2019-01-02 ~ 2026-09-04；训练段：2019-01-02 ~ 2024-12-31；OOS：2025-01-01 ~ 2026-09-04。

## 5. 判断

**结论：指标层存在一定独立信息，但交易层尚不足以确认“市场成交活跃度”是 1.62.1 的独立、稳健市场状态变量。**

1. **滚动120日成交额分位是唯一出现正成本压力证据的方向，但不形成稳定平台。** `rolling120-p33` 与 `rolling120-p40` 的 full 收益分别为 +81.94%、+72.84%，高于基线 +57.73%；cost×2 full 分别为 +12.42%、+19.74%，也优于基线 -20.57%。但 P25 的 cost×2 OOS 为 -9.68%，P33 为 -1.76%，只有 P40 为 +3.94%，阈值移动一个档位即跨过盈亏边界。
2. **OOS 没有保留 1.62.1 的上行，反而显著牺牲 2025。** 基线 OOS 为 +47.22%，rolling120 P25/P33/P40 分别只有 +10.08% / +14.77% / +14.65%；基线 2025 为 +39.14%，三者只有 +17.63% / +22.21% / +7.70%。因此 full 与 IS 的改善更像“过滤掉波动换取防守”，不是独立保留了牛市收益。
3. **重点年份表现混杂。** 2020：rolling120 P33/P40 为 -18.87% / -23.09%，优于基线 -25.74%，但 ratio20 三个变体均更差；2023：P40 +0.89% 优于基线 -4.89%，P33 反而 -9.83%；2025：所有六个变体都弱于基线；2026：P40 +1.25%、P25 -8.78%、P33 -8.41%，方向不稳定。
4. **ratio20 未通过成本压力。** ratio20 P25/P33/P40 的 cost×2 OOS 分别为 -7.62% / -5.77% / -15.51%，全为负；其 full 与 OOS 也普遍弱于基线。该定义不具备可晋级证据。
5. **指标独立不等于交易增量独立。** 成交额与涨停活跃度相关较低，但本阶段不能把这种“低相关”直接视为 alpha；一个独立状态变量至少应在相邻阈值、OOS、成本和重点年份上保持同向。当前没有出现满足该条件的稳定区块。
6. **本阶段不创建 Candidate。** 建议若继续，先把成交额状态与既有涨停状态做条件分层或双变量归因，验证低相关是否转化为可解释的边际收益；仍不得直接按本轮最佳单元格冻结参数。
