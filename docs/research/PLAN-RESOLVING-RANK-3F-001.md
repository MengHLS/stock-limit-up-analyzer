## 2. 四臂设计

全部四臂**同 dataset（780001）/ 同窗口（2019-01-01..2026-09-04）/ 同成本模型 / 同 `NEXT_OPEN` / 同 `maxPositions=5` / 同 `maxDailyBuys=2` / 同门槛（首板 + 观察窗内回踩）**。只变排序。

| 臂 | 排序方式 | 作用 |
|---|---|---|
| **A · 控制** | 现行 `(idx+0.5)/k` 桶位分 + `securityId` 破平 | **parity 门禁**：必须复现 `151.0958341843399%` / 1434 笔 / trigger 161，否则坐标漂移，实验作废 |
| **B · 分辨力** | **同一套冻结桶边界、同一方向、同一等权**，仅把桶内取值由「桶中点」改为**桶内分段线性插值** | 唯一被放开的变量 = 桶内分辨率；消除 86.9% 的并列 |
| **C · 破平敏感性** | 同 A，仅把破平由 `securityId` 升序改**降序** | 零契约变更，直接量化「151% 里有多少是破平顺位运气」 |
| **D · 无排序（零假设）** | 门槛后**不排序**，按 `securityId` 取前 3 | 选股层贡献 = 0 的参照线。**若 B ≈ D，则排序确实无信息** |

**臂 D 是本次实验的核心对照**：它是「3F 排序没有任何作用」这一零假设的直接实现。

## 3. 连续化映射的精确定义（臂 B）

对每个成员因子，用其**已冻结的桶边界**把原始值映射到 `[0,1]`：

```
x ∈ [edge_i, edge_{i+1})  →  t = (x - edge_i)/(edge_{i+1} - edge_i)
                             raw = (i + t) / k
oriented = orientation === 1 ? raw : 1 - raw
```

**关键性质（构造性 parity 证明）**：取 `t = 0.5`（桶中点）时 `raw = (i+0.5)/k`，**与现行公式逐位相同** ⇒ 现行行为是本设计的特例，parity 可在单元测试里断言而非靠跑 Run。

**唯一需要事前决策的自由参数**：首桶下界为 `-inf`、末桶上界为 `+inf`（如 `maxAmplitude` 的 2 桶）。必须事前登记并做敏感性检查：

| 方案 | 首桶下界 | 末桶上界 |
|---|---|---|
| S1（推荐） | `0` | `edge_last × 1.5` |
| S2 | 研究样本内该因子的 `P1` | `P99` |
| S3 | `edge_first × 0.5` | `edge_last × 2` |

S1/S2/S3 三选一为**主口径**，另两个作稳健性（若主口径结论在另两个下翻转 ⇒ 结论不稳，如实登记）。

## 10. 步骤 ② 的三个结论（含对既有结论的修正）

1. 🔴 **修正 `RESULT-151PCT-WINNER-CONCENTRATION-001` §10.1 的「零识别力」论断。**
   那里的 `Spearman(score, netPnl) = −0.075` 是在**1429 笔已成交**上算的 —— 那是一个
   **被 Top-3 选择截断、且混入可变退出政策**的总体，不是排序识别力的正确测量对象。
   正确总体（50,836 个候选 × 固定持有期）给出 **rho = +0.057（rd10）→ +0.112（rd60）**，
   随持有期上升，n≈48k 下 **高度显著**。
   ⇒ **3F 合成分是弱但真实的正向信号，不是噪声。**

2. ✅ **确认「分数不识别右尾」，而且比原判断更强 —— 它对右尾是轻微反向选择。**
   rd60 下 `>=+100%` 命中数：A=44 / B=37 / **D（无排序）=58** / 底 3=**70**。
   即**不排序比按分数排序抓到更多翻倍股**，反向对照抓到最多。
   机制与领域一致：`maxAmplitude` / `meanAmplitude` 都是 **LOW 方向**（偏好低振幅），
   而低振幅 = **两侧尾部都更薄** ⇒ 分数改善**均值**（避开左尾），同时**系统性压低右尾密度**。
   ⇒ **分数与策略的盈利来源（右尾）在结构上是对立的。**

3. ❌ **「18 档量化是瓶颈」被否定 ⇒ 不接线连续分。**
   连续化相对冻结分的增量在**任何持有期上都不超过 0.005 的 rho**，组合层甚至更差。
   ⇒ 被桶丢掉的信息**在结果上不存在**；信号本来就在**桶级**次序里，而桶级次序被完整保留。
   ⇒ 本方案 §2 臂 B 的采用条件**未命中**；`threeFactorContinuousScoreFeatures.ts` **保持未接线**。

**附加量化（对旧「脆弱性」论断的精确化）**：破平方向反转（A↔C）带来的均值为
+0.03pp / +0.16pp / +0.45pp / +0.52pp（rd10/20/40/60）。即在 rd40–rd60 上，
**一个毫无道理的破平反转就能移动 ~0.5pp/笔，相当于信号本身的 1/3~1/2**。
⇒ 准确的表述不是「组合 87% 由 UUID 决定」，而是：
**分数决定「选哪个桶」（信号所在），破平决定「桶里选哪几只」（无信息），后者叠加了与信号同量级的任意噪声。**
