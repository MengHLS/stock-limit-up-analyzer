### 2.1 🔴 结构性根因（本轮唯一可确证的方法学结论）

| 环节 | 分析 |
|---|---|
| **两臂的共同点** | 同一每日候选池 · 同 `TOPN = 3`/日 · 同 1,463 个有效决策日 ⇒ **尝试入场次数完全相同 = 4,389** |
| **差异所在** | **接受率**：因子臂 **98.1%**（4,304/4,389）vs 随机臂 **88.7%**（3,890/4,389） |
| **为什么接受率不同** | `MAX_CONC = N × F` **恰好等于稳态需求**（3 只/日 × F 日 = 3F = MC）⇒ **账本处于【饱和边界】** ⇒ 任何选股差异都会改变**持仓占用时序**（哪些 symbol 何时在场、何时释放）⇒ 进而改变 **book cap / symbol 冲突 / cash 约束**的触发频率 |
| **后果** | **随机臂天然处于容量劣势**（利用率低 6.1~7.7pp）⇒ **其 CAGR 被系统性压低** |
| **⇒ 对本轮结论的影响** | **观测到的 ΔCAGR 中【含利用率优势的贡献】，无法归因于选择能力** ⇒ **INVALID，不比较 CAGR** ✓ |

> ## ✅ **本门控是【预注册】的，且在查看任何 CAGR 之前即已定义 ⇒ 触发后如实报告，未因因子表现好而放行。**

## 6. 🔴 基准设计缺陷与修复路径（**仅登记，本轮不执行**）

| 项 | 内容 |
|---|---|
| **缺陷** | `MAX_CONC = N × F` **恰好等于稳态需求** ⇒ 账本处于**饱和边界** ⇒ **接受率对选股敏感** ⇒ 两臂利用率不可比 |
| **表现** | 因子臂接受率 98.1% vs 随机臂 88.7%；利用率 79.5~80.0% vs 71.9~73.9% |
| **影响** | ΔCAGR **被利用率优势污染**，无法归因于选择能力 |
| **候选修复 A（推荐）** | **利用率匹配**：为随机臂单独标定 `MAX_CONC`，使其实现利用率对齐因子臂（或反之），再比较 CAGR |
| **候选修复 B** | **改用利用率无关的主指标**：**单笔均净收益 / 单笔均超额**（`meanNet`）作为选择能力的首要度量，CAGR 仅作辅助 |
| **候选修复 C** | **统一目标占用率**：两臂均按固定目标占用来填满账本（而非按 `N×F` 恰好饱和） |
| **候选修复 D** | **提高 `MAX_CONC` 留出余量**（例如 `MC = 1.5 × N × F`），使两臂均不触顶 ⇒ 接受率趋同 |
| **附加要求** | 修复后必须**重新通过可比性门控**（`|trades 差| < 5%` 且 `|util 差| < 0.03`）才允许比较 CAGR |
