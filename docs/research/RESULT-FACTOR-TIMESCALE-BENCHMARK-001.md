## F. 七个最终问题

### 1. LONG 是否真正跑赢市场？ ⇒ ⚠️ **分层回答：逐笔是，净值否**

| 维度 | 结果 |
|---|---|
| **逐笔同窗口 Alpha（vs 沪深300）** | ✅ **+0.99pp / 笔**（4/7 年为正） |
| **Sharpe** | ✅ **0.3306 > 沪深300 0.3060** |
| **MDD** | ✅ **−30.31% 远浅于沪深300 −45.60%（浅 15.29pp）** |
| **净值 CAGR** | 🔴 **5.31% < 沪深300 5.74% < 上证指数 7.05% < 中证500 10.95%** |

🔴 **主因：资金利用率仅 66.5%**（avgConc **133.09** / MAX_CONC **200**）⇒ **大量现金拖累净值 CAGR**
（与 `LONG4-P2-WIDTH-001` 的发现一致：宽度收益主要来自**利用率**而非选股）

> ## **⇒ 结论：LONG-4 具备【逐笔选股 Alpha】与【显著更优的回撤】，但【净值 CAGR 未跑赢任何宽基指数】。**

### 2. MEDIUM 是否只是相对减亏，还是具备绝对收益？ ⇒ 🔴 **只是相对减亏**

| 检验 | 结果 |
|---|---|
| 绝对 CAGR（20bps） | 🔴 **−2.37%** · PF **0.9580 < 1** |
| 绝对 CAGR（0bps，最有利） | ⚠️ **+0.39%（≈0）** |
| **相对市场 Alpha** | 🔴 **−0.35pp（负）** · 年度仅 **1/7** 为正 |
| 相对随机 Alpha | ✅ **+11.58pp**（100% 击败） |

> ## **⇒ 「相对随机有效」不能升级为「市场 Alpha」。MEDIUM 的定位维持：独立中期相对强弱 / 减亏。**

### 3. SHORT 是否存在独立多头绝对收益？ ⇒ 🔴 **不存在**

· `preReturn10` Strong **0bps +0.04%（≈0）**、**10bps 起为负**、**低于指数同窗口（−0.06%）**
· `limitGap` Strong **全成本档为负**、**低于指数（−0.39%）**
⇒ **spread 是相对量，不构成独立多头盈利** ✓

### 4. 0~50bps 成本下哪些结论仍成立？

✅ **成立**：**LONG-4 绝对正收益**（5.91%→4.36%）· **SHORT 的 spread**（+1.41% / +0.66%，成本恒定）
🔴 **不成立**：**MEDIUM 绝对收益**（10bps 起为负）· **SHORT Strong 绝对收益**（10bps 起为负 / 全档负）
🔴 **成本脆弱**：**MEDIUM** 与 **SHORT** 均标记为**成本脆弱**

### 5. 哪些时间尺度值得进入下一阶段策略设计？ ⇒ 🟡 **仅 LONG-4（有条件）**

唯一在 **0~50bps 全档绝对正收益** + **逐笔市场 Alpha 为正** + **MDD 显著更浅** 的尺度。
🔴 **但进入前必须先解决 4 项**：①**资金利用率**（66.5% ⇒ 净值跑输主因）②**冲击成本与容量**（无订单簿数据）③**2025 年 Alpha 反向归因** ④**无风险利率纳入**（现 Sharpe 为 CAGR/vol 之比）
