## 2. 🔴 发现 1：短期窗口存在**定义性污染**（必须先声明，否则结论会被误读）

12 个因子的**数据来源**（逐字核对 `twelve-factor-composite-study/derive.ts#L400-L458`）：

| 因子 | 计算来源 | 对 **T+1~T+5** 窗口 | PIT 安全性 |
|---|---|---|:---:|
| `bodyHeight` | prefix rd0 + event.previousClose | 窗口**外** | ✅ PIT 安全 |
| `turnover` | event.turnover | 窗口**外** | ✅ PIT 安全 |
| `amountPercentile` | prefix rd0.amount（同日横截面百分位） | 窗口**外** | ✅ PIT 安全 |
| `limitGap` | event.daysSincePreviousLimit | 窗口**外** | ✅ PIT 安全 |
| `preReturn10` | prefix rd−1 / rd−10 close | 窗口**外** | ✅ PIT 安全 |
| `historyLimitCount` | event.historicalLimitCount | 窗口**外** | ✅ PIT 安全 |
| **`drawdownDepth`** | **min(low over rd1..5) / eventClose − 1** | 🔴 **窗口内** | ❌ 污染 |
| **`meanAmplitude`** | **mean((high−low)/preClose) over rd1..5** | 🔴 **窗口内** | ❌ 污染 |
| **`maxAmplitude`** | **max((high−low)/preClose) over rd1..5** | 🔴 **窗口内** | ❌ 污染 |
