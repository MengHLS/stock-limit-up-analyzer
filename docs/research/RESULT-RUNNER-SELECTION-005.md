# RESULT-RUNNER-SELECTION-005

> 目标：验证已验证的“继续上涨状态”能否把 +10%/+15% 激活后的深度回撤股票进一步压缩成更高 Runner 密度的候选池。只比较单变量状态，不组合条件、不搜索阈值、不创建 Candidate。

## 0. 固定口径

- Dataset: `first_limit_pullback` / `datasetVersionId=660001`；固定初始池 `D20 < -10% && MA20Slope <= 0`。
- T+5 收盘形成初始池，T+6 开盘为原始持有起点；严格 PIT。
- 激活：+10% 或 +15%；激活后 D1~D5 每日观察。
- 状态仅使用 RUNNER-STATE-RESEARCH-004 已固定变量：近5日高点距离、MA5/MA10位置、MA5/MA10斜率、近2/3日收益、2/3日创新高、连续创新高、收盘位置、量能、连续收低。
- 本轮不新增价格/均线/成交量阈值，不组合变量。单变量状态包括继续状态及对应的收低衰竭对照。
- 未来标签只用于评价：Runner为后续 high 达到 +20%，Strong Runner为后续 high 达到 +30%。
- “候选池”按单变量状态逐日计数；捕获倍数 = 该状态捕获的 Runner 比例 / 该状态在激活池中的覆盖比例。大于 1 表示右尾密度高于激活池平均。
- 日报中的“占当日深度回撤池比例”按可比口径定义为：同一激活目标、同一交易日仍处于激活后 D1~D5 观察窗口的事件数作为分母；未激活事件没有相同的激活后状态日，不能直接混入当日分母。完整初始池作为单独总基准。

## 5. 与完整深跌池、3F Top3 的职责差异

- 完整深跌池是初始池：负责提供后续右尾基础，但包含大量不会继续扩张的事件。
- Runner 状态不是初始选股器，而是激活后的持仓/候选升级层；它依赖已经先达到 +10%/+15%。
- 已有趋势池研究显示原 3F Top3 没有稳定改善趋势池质量；本轮的 Runner 状态直接使用上涨后的价格结构，和目标（后续右尾）更同向，因此更适合作为“继续持有/升级观察池”，不能与 3F Top3 的初始筛选任务混为一谈。

## 6. 关键结论

- 单变量 Runner 状态可以明显压缩激活池，并提升 +20%/+30% 密度；捕获倍数大于 1 的状态表示右尾事件没有被按比例丢掉。
- 接近近5日高、站上 MA5/MA10、均线双上行、短收益非负、创新高和连续创新高属于延续状态；连续收低是相反方向。
- 高 Runner 概率的状态通常更接近高点或更强趋势；但同时也可能有更大的后续 MAE，因此不能把它解释为“低风险持有”。
- 完整深跌池负责提供右尾来源，Runner 状态负责在上涨后提高右尾密度；Exit 仍需要单独处理“上涨结束后如何退出”，不能被 Runner 状态替代。
- 本轮不把任何单变量状态命名为最佳规则，也不组合变量；原始每日候选计数与逐年结果保存在汇总证据 JSON。
- 绝对右尾保留最强的是覆盖较宽的延续状态：+10% 激活后，站上 MA5/MA10 捕获约 78.83% 的 +30% 事件、近3日收益非负捕获约 85.50%；+15% 激活后分别为 81.91% / 83.74%。
- 密度提升最强的是覆盖较窄的强延续状态：+10% 激活后，接近近5日高点只覆盖 8.20%，但对 +20% / +30% 的捕获倍数为 1.69x / 2.34x；连续创新高 >=2 的 +30% 捕获倍数为 1.77x。+15% 激活后，接近近5日高点的 +30% 捕获倍数为 2.13x。
- 因此没有单变量能同时做到“高覆盖、保留全部大赢家、低回撤”。宽状态更适合作为继续持有池，窄状态更适合作为右尾密度观察状态；这仍不是交易规则。

### 6.1 三个环节的职责判断

1. **初始选股**：当前 `D20<-10% && MA20Slope<=0` 已经能提供右尾源，但单独持有到 T+20 的平均结果并不稳定；它的职责是先找到右尾供给，不是最终胜率保证。
2. **Runner 二次筛选**：本轮证据支持它能作为“继续持有/持仓升级”的观察层；接近高点、站上 MA5/MA10、连续创新高等单变量状态确实压缩了激活池，并提高 +20%/+30% 密度。但它不能替代退出，也不能保证低回撤。
3. **Exit 趋势衰竭**：仍是主要瓶颈。Runner 状态说明“后续仍可能扩张”，但延续状态通常伴随更高后续 MAE；而此前的慢速趋势破坏退出又明显牺牲大赢家。也就是：选股层已经能提高右尾概率，最终收益仍被“何时确认上涨结束”卡住。

因此当前优先级不是再扩大初始池，也不是把 Runner 状态包装成交易规则，而是把 Runner 状态作为条件持仓层，继续研究更晚、更确认的 Exit 趋势衰竭。
