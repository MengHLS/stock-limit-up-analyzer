# RESULT-TOPN-SPACE-FACTOR-001

> 目标：验证把「回撤/剩余空间」信息加入现有 3F Top3 排名后，是否能够改善每日 Top-N 选股质量。
> 固定：Strategy 基线 `first-limit-pullback-3f-top3@1.62.1`；dataset `660001`；execution projection = v5 官方行 + 选中事件 v7 rd17..80；每日 Top3；T+6 开盘入场；成本/仓位/退出口径完全不变；不研究 Runner/Exit；不创建 Candidate；不修改正式 Strategy；不做参数搜索/OOS/WFA。
> 报告由 `scripts/reportTopnSpaceFactor001.mts` 从落盘 evidence 机械生成。

Space 变量（全部只使用 T+1..T+5，严格 PIT；**未新增复杂因子、未搜索阈值**）：

**方向固定**：`−z(space)` 表示奖励「更深回撤 / 更低位置 / 更小前期涨幅」，与既有「深度回撤池」语义一致；权重固定 0.5，不做搜索。

## 1. Parity 验证（Baseline 对齐）

A 组（1.62.1 3F 复合分 Top3）在本执行链上的结果为 **1,619 笔 / +15.79%**，与 `RESULT-RUNNER-HOLDING-BRIDGE-001` 的 Bridge 执行基线 **1,619 笔 / +15.79%** 完全一致，说明本实验的 A 组没有引入额外偏差，B 组与 A 组的差异只来自排序信息。

## 5. 结论

1. **加入空间信息后，Top3 选股质量没有改善，反而明显恶化。** 总收益 +15.79% → -39.07%（-54.86pp）、MaxDD -54.81% → -80.51%（-25.70pp）、PF 1.066 → 0.955。
2. **恶化不是来自单笔收益，而是来自每日选股本身。** 胜率几乎不变（39.0% vs 40.0%），但约 51.0% 的决策日选出的股票与基线不同——被空间分数挑出来的组合整体更差。
3. **增量不跨年度稳定**：年度增量 2 正 6 负，且 2021 年单独贡献了 -51.79pp 的负增量；不存在稳定改善平台。
4. **判定：关闭该方向。** 在固定 0.5 权重、固定方向、无参数搜索、无组合搜索的前提下，把「回撤/剩余空间」加入 3F Top3 排名是**净损害**；本结果不建议晋升为正式 Strategy。
5. 1.62.1 的 3F 复合分排序在本执行链上仍是最优的已冻结选择（A 组 parity = 1,619 笔 / +15.79%），空间信息不应进入排名层。

### 明确边界

- 本轮只测了**一个**明确版本（固定权重 0.5、固定方向、6 个 PIT space 变量），不做多因子无限组合、不搜索权重/阈值；B 变差不能外推为「所有空间用法都无效」，但足以关闭「把空间信息并入 3F 排名」这一方向。
- space 变量仅使用 T+1..T+5，严格 PIT；A/B 除排序信息外入场/成本/仓位/退出完全一致，且 A 组与 Bridge 基线 parity 通过（1,619 笔 / +15.79%）。
- 未做 OOS/WFA、未创建 Candidate、未修改正式 Strategy。
- 组合层收益受资金循环影响，本轮未对「选股层单笔质量」与「资金循环」做完全分离。
