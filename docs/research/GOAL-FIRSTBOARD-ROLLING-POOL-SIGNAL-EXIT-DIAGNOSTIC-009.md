## 5. Gate C：三层诊断

### 5.1 信号层：买点后有没有上涨空间

纳入008**所有原始候选信号**，包括未进Top3、容量未成交者；资格排除单列。以B的ORIGINAL与RECOVERY作为主要分支对照，A的ORIGINAL作为原规则参照。相同事件/确认日同时出现在A和B的记录不能合并成两个独立样本。

主描述单位：每个锚点、每个分支的**首个允许参与排序的确认信号**。该次次日不可买或缺行情时原样标注，不以后一天更漂亮的信号替换。全部触发及后续触发另作补充，必须报告唯一锚点数，不能把反复触发当独立样本。

对每个信号使用原计划次日开盘价作为价格路径基准。下一日已知ST或不可买，记为不可买并保留原因；UNKNOWN沿用探索政策。成交日资格属于执行可行性，不反向改变前日排名。缺少足够执行条件时只标注 `EXECUTION_FEASIBILITY_UNKNOWN`，不能声称是可成交交易。

候选路径时钟：`entryRd = plannedFillRd`；H取3/5/10/20，窗口为 `entryRd..entryRd+H−1`，包含入场日，共H个市场交易日格。固定输出：

| 描述指标 | 定义 |
|---|---|
| 主要描述靶 | 20日内至少一次**收盘价**达到计划次日开盘价×1.20的唯一锚点比例/计数 |
| 终点收益 | 第H日收盘价/计划开盘价−1；报均值、中位、q05/q95、正值比例 |
| 收盘上涨空间 | 窗口最高收盘价/计划开盘价−1 |
| 不利波动 | 窗口最低价/计划开盘价−1（MAE，保留负号） |
| 高价上涨空间 | 最高价/计划开盘价−1，仅作盘中上界；区别于主要收盘靶 |
| 到达时间/先后顺序 | 首次收盘达+20%的日序；固定6%不利价位首次触及日序；同日发生先后不可知，标注AMBIGUOUS |
| 入场相对位置 | RECOVERY计划开盘价距当时已知localLow价格的涨幅、从localLow到确认日的间隔 |

逐H保留完整窗口/缺失分母；全窗口指标只用完整窗口，记录排除原因，避免可见早涨者留下、未达者因缺数据消失。可见部分独立输出并明确右尾结果未知。原始价/复权口径如存在问题如实限定；以上不扣成本、无账户容量，均称**价格路径描述**，不称策略复合收益。

至少按2024/2025、确认年月、计划成交事件年龄1–5/6–10/11–15/16–20分层。仅在双方都有样本的同月×年龄层比较，报告各层分母、权重与缺失；不足20唯一锚点的层标记小样本。市场状态有合格现成数据时补充，否则不把年份等同牛熊。保留每层原结果，禁止用总体均值宣称分支因果效应。

完成判据：每个候选信号有来源、确认/计划入场坐标、资格/可行性、分支、首信号标记、H路径有效性和上述描述指标；汇总可从明细复算，A/B重叠和重复触发有明确分母。

### 5.2 选择层：因子与容量在什么位置丢失机会

使用008真实确认日全序与Top3，不重选方向、K或权重。分别显示：参与候选 → Top3 → 实际入场 → 原退出后的净交易结果，区分未选、不可买、持仓/每日买入容量限制。

按分支核对 `preReturn10` 的不同值数、最大同值占比、Top3边界并列与破平键；Top3对其余参与候选的价格路径分布只作描述。前日参与名次不因次日资格重排。静态因子在两分支的排序作用不能由A的整体收益直接推广到RECOVERY。

64个遗漏锚点给出同日原因账，按原A真实交易净损益描述其画像；不能把这些损益直接加进B算“补回后的收益”。如解释满仓由哪些持仓造成，引用真实建仓检查时点的持仓事实，沿用引擎时序；缺乏证据则标UNMEASURED，不自行假设先卖后买。

完成判据：候选/选择/成交/缺口数逐层相平；全部64个遗漏事件可追踪；能够分别说明排序选择和容量限制的观察事实，不伪造反事实账户收益。

### 5.3 交易层：现有退出是否错配

只分析008真实A144/B236笔完整交易，按真实成交审计的ORIGINAL/RECOVERY分支连接。保留再入场次数、入场序号；“止损”标签按最终净损益区分真实亏损与盈利保护。

对每笔交易以实际成交价为路径基准，映射真实入场/退出日期，输出入场后3/5/10/20日路径，以及退出后第1..20日的回到入场价、收盘达到入场价+20%、第20日终点和首次到达时间。两种时钟分别标记，不能混用。亏损与盈利交易都统计，避免只分析亏损者便归因退出；缺失按窗口明确列出。

列明≥20%价格机会在原退出前、退出后才出现或未出现；若后来才到达，报告退出前最大不利波动、达到右尾所需时长及是否超出原T+20新买窗口。**原买入后的持有**与**再次入场**是两种问题，不能混淆。
