# RESULT-EXIT-PATH-RESEARCH-001

> 目标：不再把固定 T+20 收盘收益作为唯一核心指标，改为研究固定深跌反弹池的上涨路径、利润保持和退出捕获。
> Dataset: `first_limit_pullback` / `datasetVersionId=660001`。固定池：`D20 < -10% && MA20Slope <= 0`。状态构造只用 T+5 及以前信息；本轮不修改 3F、不创建策略版本、不创建 Candidate、不进行参数搜索。

## 0. 固定口径与执行假设

- 池形成：T+5 收盘。固定池事件 1,505 个；要求 T+6~T+20 完整 OHLC 后可评估 1,484 个，排除 21 个数据不完整事件。
- 入场：T+6 开盘。退出研究窗口：T+6~T+20。所有净收益扣 20bps；MFE/MAE 为未扣成本的价格波动。
- `MFE = max(high/entry)-1`，`MAE = min(low/entry)-1`。
- 固定目标：+3%/+5%/+8%/+10%/+15%/+20%，均为预先固定。首次触达目标即退出；若开盘跳空越过目标，按开盘价成交，否则按目标价成交。
- 滚动峰值回撤：使用截至前一交易日的已知峰值。下一交易日若开盘已低于回撤阈值则按开盘价成交，否则当 low 触达阈值时按阈值价成交。该规则是因果可执行的。
- 事后全局峰值回撤：先识别整个 T+6~T+20 的最高价，再从峰值之后的走势回看 3%/5%/8%/10% 回撤。它只用于描述“利润保持上限”，**不是可交易规则**。
- 同一根日线不假设 high 与 low 的先后顺序：峰值确认前的当日回撤不触发实时规则；若事件在 T+20 才形成峰值，则无法在本窗口内发生峰后退出。
- 峰值定义为首次达到窗口最高 high 的日期。T+20 峰值存在右删失风险，不能解释为“股票必然在 T+20 见顶”。

## 8. 重点问题回答

### 1. 大涨股票通常在哪个阶段形成峰值？

大级别上涨更偏后段：MFE>=+20% 的峰值日中位为 T+17，MFE>=+30% 为 T+17。整体峰值中位 T+13，但这是小赢家早峰与大赢家晚峰混合后的结果。T+20 新高比例很高，存在窗口右删失。

### 2. 达到 +5% / +10% / +20% 后，后续回撤有多大？

后续运行峰值回撤中位数分别为 -12.77% / -11.83% / -12.61%，P75 分别为 -8.87% / -7.94% / -7.94%。达到高目标后仍有两位数级别的典型回撤。

### 3. T+20 是否系统性低估了实际可实现收益？

不能简单认定。T+20 均值 3.45%；预先固定 +15% 退出全样本均值 3.13%，+20% 退出 3.60%。后两者不低，但 +3%/+5%/+8%/+10% 退出均低于 T+20。

原因是 T+20 同时包含晚峰收益和早峰回吐，而固定目标提前止盈则放弃了后续延续。只有在事后知道全局峰值并使用峰后回撤时，理论剩余收益才显著高于 T+20：3% 回撤均值 8.50%、5% 回撤均值 7.76%。这是不可直接交易的上界。

### 4. “固定止盈”与“峰值回撤退出”的收益捕获差异是什么？

- 固定止盈的实现确定、命中率清楚，但会截断大赢家；命中后持有到 T+20 在 +5%~+15% 区间普遍高于固定目标退出。
- 实时滚动峰值回撤试图保留上涨，但在日线窗口内过早触发：3% 阈值几乎 100% 触发，10% 阈值仍有 78.84% 触发率，平均退出收益明显低于事后峰值回撤。
- 事后全局峰值回撤可以捕获 57.03%~36.00% 的 MFE，但依赖未来峰值信息。
- 差异的本质不是“止盈价还是回撤价”，而是“什么时候确认上涨已经结束”。

### 5. 真正应该优化的是预测涨多少，还是上涨后如何退出？

两者都需要，但当前路径证据显示：**上涨后如何退出是更直接、更可操作的瓶颈。**

固定池 MFE 均值 14.91%，T+20 均值只有 3.45%；达到 +10% 的事件占比 53.03%，但达到 +10% 后的后续峰值回撤中位数仍有 -11.83%。说明很多事件已经提供了足够大的价格空间，损失主要发生在上涨后的持有和回吐阶段。该结论不否定选股，只是把问题从“预测最终涨幅”推进到“路径管理”。

### 6. 是否可以形成“先让利润奔跑，再根据回撤退出”的研究方向？

可以，但当前结果不支持把简单固定百分比回撤直接升级成规则：

- 大赢家峰值偏后，方向上支持让利润继续参与。
- 达到 +5%/+10%/+20% 后普遍存在大幅回撤，方向上也支持增加路径保护。
- 但实时 3%~10% 固定回撤过早退出，事后全局峰值回撤又不可交易，说明需要寻找“上涨趋势仍成立 / 峰值已经失效”的确认状态，而不是再搜索一个更好的固定百分比。
- 本轮因此只确认研究方向，不创建 Candidate，也不选择任何退出阈值。

## 9. 结论边界

- 未修改首板回撤定义、3F、仓位、TopN 或成本。
- 未搜索退出参数，未把任一目标、回撤或期限定义为最佳策略。
- 固定目标退出为路径描述性模拟；命中后继续持有至 T+20 仅作对照。
- 实时峰值回撤规则只使用当前及过去数据；事后全局峰值回撤使用未来路径，仅供研究利润保持上限。
- T+20 是 Dataset 最大可用绝对相对日，峰值时间存在右删失。
