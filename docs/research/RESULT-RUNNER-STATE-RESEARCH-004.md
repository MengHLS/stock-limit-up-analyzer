## 0. 固定口径

- Dataset: `first_limit_pullback` / `datasetVersionId=660001`；固定池 `D20 < -10% && MA20Slope <= 0`。

## 5. 状态解释边界

- Runner 标签只用于事后分组；所有状态变量都只使用状态日及以前的数据。
- 同一事件会在多个 offset 出现，表格中的记录数不是独立事件数；逐年和逐日统计均按该重叠口径解释。
- 固定描述分档不搜索最优阈值；这里只观察不同描述状态的方向和稳定性。
- 本报告不把某个 Runner 概率较高的状态直接定义为买卖条件，也不组合多变量规则。

## 6. 最终判断

本轮不是寻找“最佳止盈规则”，而是区分继续上涨状态与上涨衰竭状态。

### 10.1 继续上涨状态的共同结构

- Runner 与 Strong Runner 在大多数 year × offset 单元中同时具有：更接近近5日高点、更高的收盘相对 MA5/MA10、更正的短均线斜率、更正的高近2/3日收益、更高的 2/3日创新高比例、更高的收盘位置、更高的量能比和更长的连续创新高。
- 方向一致性很高：例如 +10% 激活后，相对 MA5、相对 MA10、近2/3日收益、3日创新高、连续创新高与连续收低在 35 个有效 year×day 单元中均为同一方向；MA10 斜率的一致率为 88.57%，是少数较弱的变量。
- +15% 激活后结论类似；相对近5日高点、MA5 斜率、2/3日创新高和连续创新高在有效单元中方向一致。

### 10.2 状态的典型量级

- +10% 激活后，贴近/突破近5日高状态的后续 +20% 概率为 85.56%，距高点 >5% 为 37.91%；站上 MA5 与 MA10 为 62.43%，均线下方为 19.83%。
- +15% 激活后的区分更明显：贴近/突破近5日高为 97.89%，距高点 >5% 为 48.09%；站上 MA5 与 MA10 为 76.76%，均线下方为 17.57%。
- 连续创新高 >=2 的后续 +20% 概率在 +10% / +15% 激活后分别为 75.29% / 89.57%；连续收低 >=2 仅为 25.99% / 32.11%。

### 10.3 关键限制

- 继续上涨状态同时对应更高的后续波动：+15% 激活后贴近/突破近5日高的后续 MAE 均值约 18.04%，连续创新高 >=2 约 15.19%。
- 因此“Runner 概率更高”不等于“从状态日收盘持有到 T+20 一定更好”；状态识别只说明后续更可能出现大幅扩张，仍需独立处理路径风险和退出。
- 报告不把任一变量命名为最佳单因子，也不把状态分档组合成交易规则。
