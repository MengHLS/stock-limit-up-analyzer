# RESULT-3F-TOPN-NO-PULLBACK-GATE-001

## 实验问题

移除 3F Top3「观察窗 T+1..T+5 内必须出现收盘价低于首板日收盘价」的候选资格门槛后，
实际成交、候选扫描量和组合结果如何变化；601038.SH 与 002502.SZ 两个 2019 样本的行为是否
发生预期变化。

## 变更内容

- 新增 3F 特征变体 `threeFactorCompositeScoreNoPullbackGate@1.1.0`。
- 新增配方 `first-limit-pullback-3f-top3-no-pullback-gate`。
- 原配方 `first-limit-pullback-3f-top3` 与旧版本行为保持不变，避免改动历史版本口径。
- 新版本 `first-limit-pullback-3f-top3@1.13.0` 使用无回踩门槛变体，其余口径沿用 `1.12.0`：
  - T+5 收盘决策，T+6 开盘买入；
  - 6% 盘中止损；
  - 5% 盘中盈利回撤止盈；
  - 第 5 个持有日收益 `>= 3%` 且收盘高于 MA5、MA10 时延长到第 10 个持有日；
  - T 日 `open < high`，排除一字板与 T 字板。

## 601038.SH 验证

事件：`601038.SH@2019-06-11`（首板涨停，非一字板）。

- 事件日收盘：`6.06`
- T+1..T+5 收盘：`6.29 / 6.09 / 6.09 / 6.70 / 7.37`
- 无回踩门槛后的 3F 合成分：`0.4167`
- 同日候选池：61 个事件，排除 T 日一字板/T 字板后 57 个有效候选
- `601038.SH` 排名：第 `47` 名
- 当日 Top3 分数线：`0.7167`

结论：移除回踩门槛后，该事件不再因 `rankValue=null` 被丢弃，但 `0.4167` 的 3F 分数
仍远低于当日 Top3 分数线，因此 `1.13.0` 中依然没有 `601038.SH@2019-06-11` 的成交。

## 002502.SZ 验证

事件：`002502.SZ@2019-01-03`。

### v1.11.0（收盘止盈）

| 项 | 值 |
| --- | ---: |
| 买入日 | 2019-01-11 |
| 卖出日 | 2019-01-18 |
| 卖出价 | 4.1979 |
| 退出原因 | 持有满 5 个交易日 |

2019-01-17 盘中最低 `4.05` 确实跌破 `4.28 × 0.95 = 4.066` 的回撤线，但旧口径只在收盘
检查回撤，而当日收盘 `4.23` 在回撤线上方，因此回撤止盈没有触发；真正触发的是时间退出，
并按 T+1 开盘执行，所以卖出落在 2019-01-18。

### v1.12.0（盘中止盈）

| 项 | 值 |
| --- | ---: |
| 买入日 | 2019-01-11 |
| 卖出日 | 2019-01-17 |
| 卖出价 | 4.0640 |
| 退出原因 | 盈利回撤止盈（峰值收益 0.46%，盘中回撤 -5.00%） |

盘中回撤止盈在该版本按触发价当日卖出，不再顺延到下一交易日开盘。

### v1.13.0（无回踩门槛 + 盘中止盈）

`002502.SZ` 在 `2019-01-11` 没有被买入：移除回踩门槛后候选池扩大，当日两笔买入名额由
`002297.SZ` 与 `600855.SH` 占用。该现象是候选池与单日买入上限的结果，不是盘中止盈未触发。
盘中止盈的同日成交路径由 `tests/server/research/simulator/simulator.test.ts` 中的
「盘中跌破触发线时当日按触发价卖出」用例覆盖。

## 结论

1. 无回踩门槛已作为新版本 `1.13.0` 落库并完成回测，旧版本口径未被改写。
2. 移除门槛使候选扫描量显著增加，`1.13.0` 相对 `1.12.0` 的结果改善但仍显著为负。
3. `601038.SH@2019-06-11` 在新版本仍不触发，原因是 3F 分数排名不足，而不是回踩门槛。
4. `002502.SZ` 在 `1.12.0` 已经按盘中回撤当日成交；`1.13.0` 没有买入它是候选池变化与
   单日买入上限导致，不是止盈顺延问题。
