## 十一、下一步裁定

### 11.1 是否值得进入「不等权 / 权重搜索」

**取决于两个可读的判据**（都在 §四 / §五 / §六 的表里）：

| 判据 | 本次实测 | 对「值得做权重搜索」的含义 |
| --- | --- | --- |
| 头部档（N3/N5）是否出现 `POSITIVE` | N3 `POSITIVE` / N5 `POSITIVE` | 若仍全 `INCONCLUSIVE` ⇒ 头部没有可放大的信号，搜权重只是在拟合噪声 |
| 四因子是否已追平/超过最强成员单因子 | 4F N3 `+0.4075%` vs `maxAmplitude` `+0.3522%` | 若组合仍不及最强单因子 ⇒ 权重搜索的「最优解」会退化为「只留最强那个因子」 |
| 跨 N 梯度形态（方向） | 随 N 递减（头部更好）（ρ = -0.80） | 方向朝「头部更好」⇒ 头部差异**值得**用权重去放大；反之（12F 那样朝尾部）则不值得 |

**裁定（由上表实测值直接推出）**：

**值得进入 —— 但必须限定为「受约束的不等权检验」，而不是自由权重搜索。**
实测支持进入的三条：① 四档**全部** `POSITIVE`（该框架下头部第一次出现正超额）；② 梯度方向从「越小越差」**翻转**为「越小越好」；③ N3 已**超过最强成员单因子**。

🔴 **但不值得做自由/连续权重搜索**：4 个成员是**事后从同一批已读数据里挑的**（依据 12F / 单因子结果）⇒ 再用**同一窗口**搜连续权重 = 在同一份数据上**二次拟合**，得到的权重不会比「这 4 个等权」更可信，只会更好看。

✅ 建议的 P0 形态 = **少量预设方案一次跑完、全输出、不择优**（结构上禁止「跑多次挑最好」）：
  - 与「振幅类双因子（`maxAmplitude` + `meanAmplitude`）等权」对照；
  - 与「去掉唯一先验未验证成员 `limitGap` 的三因子等权」对照；
  - 与「振幅权重加倍」这一类**单点**权重方案对照（不是搜索，是几个预设点的对照）。

✅ 真正的权重搜索应等**新窗口 / OOS**：本窗口内所有组合的绝对收益为负（§十第 2 条），在负收益坐标上优化权重，得到的权重对坐标本身没有免疫力。
