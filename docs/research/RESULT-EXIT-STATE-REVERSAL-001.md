# RESULT-EXIT-STATE-REVERSAL-001

> 目标：研究已有 Runner / Exit 状态从「成立」变为「失效/反转」后，在 **失效后的下一交易日 open 退出** 是否比 **继续持有至 T+40/T+60/T+80** 更有增量价值。
> 固定：`first-limit-pullback-3f-top3@1.62.1`，入场 / 选股 / 仓位 / 止损全部不变；**全部为 H_fill / 实际可执行口径**；单状态独立（**不组合**）；不搜索阈值；不创建 Candidate；不改架构；不做策略晋升。
> 本报告由 `scripts/reportExitStateReversal001.mts` 从落盘 evidence 机械生成，数字未人工转抄。

> ⚠️ 本报告的定位：它只回答「状态失效时退出 vs 继续持有，哪个在持有层更划算」，**不回答**「该状态失效是否应升级为正式 Exit 规则」（见 §8）。

| 口径 | 精确定义（全部可执行） |
| --- | --- |
| `ENTRY` | open(rd6) = T+6 开盘（实际成交） |
| `ESTABLISH (RAW)` | E = 窗口 [rd6, rd75] 内最早使 state(E)=TRUE 的日 |
| `ESTABLISH (SUSTAINED)` | E = 窗口内第一段 **≥5 个连续 TRUE** 运行的末日 |

**增量 = 继续持有的可执行收益 − 失效日卖出的可执行收益**（逐笔配对，同一入场价 open(rd6)）。

> SUSTAINED 变体的作用：状态必须真正**持续成立过 ≥5 天**才允许讨论「失效」。这样过滤掉「当日出现、次日即消失」的伪状态（见 §1）。

- 失效定义 = MA10 首次由上行转为不再上行（均线走平/下行）。
- 覆盖率 ~96%，失效中位在 rd31，失效时已持有约 29 个交易日——它更多是「趋势已经走完一段」之后才触发。
- 继续持有到 T+80 的增量均值 +0.76pp、中位 -2.02pp，正比例仅 42.9%，且 2019/2023 与 2026 明显为负。
- 与 CLOCK-MAP-001 的结论一致：MA10 斜率方向在**事件日坐标**下方向稳定为负（状态失效后继续持有并不占优），但不足以单独作为退出触发。

### MA5_ABOVE_MA10

- 失效定义 = MA5 首次跌破 MA10（死叉）。
- 形态与 MA10 斜率几乎同构：覆盖率 ~98.6%、失效中位 rd27，增量均值 +1.14pp、中位 -2.23pp。
- 与「MA5/MA10 关系」在 CLOCK-MAP-001 中被列为 shift-robust 变量一致；但同样只是右尾性质，中位为负说明对多数交易继续持有更差。

### NEW_HIGH_3

- 失效定义 = 首次没能在收盘创出 3 日新高；覆盖率 36.6%，明显低于均线类。
- 这是一组**已经上涨过**的交易：失效时已持有 36.5 日，失效退出均值 12.39%、中位 7.65%、胜率 68.5%——高胜率来自**选择效应**（只有先涨起来的交易才会在 rd40 附近出现这种状态）。
- 继续持有增量均值 +0.56pp、中位 -2.01pp、正比例 44.5%：典型右尾结构，2026 为 −12.78pp。

### CONSECUTIVE_HIGHER_HIGHS_GE_2

- 失效定义 = 连续抬高的高点计数首次跌破 2。
- 覆盖率 28.7%，失效中位 rd42；三档继续持有的增量**均值**全为正（T+40 +1.96pp / T+60 +1.18pp / T+80 +1.26pp），但中位始终为负、正比例约 45–49%。
- 结构上仍是「少数大赢家继续扩大 + 多数交易在失效后走弱」。

### CONSECUTIVE_LOWER_CLOSES_GE_2

- ⚠️ 语义特殊：该状态的「失效」是**连续收低结束（收盘不再低于前一日）＝反弹开始**，与其余四个状态「趋势破坏」方向相反，解读时必须区分。
- 覆盖率 29.2%，失效中位 rd41；失效时已持有 36.2 日。
- **失效退出当下是亏损的**：均值 -7.64%、中位 -9.54%、胜率仅 24.4%。
- **继续持有反而更好**：T+80 增量均值 +2.09pp、中位 +0.29pp、正比例 51.6%，年度 7/1。
- **这是本轮唯一在 SUSTAINED × T+80 下同时满足「增量均值>0 且中位>0 且正比例>50% 且年度 7/1」的单元**（唯一 BROAD 单元）。它说明在深度回撤池里，连续收低结束（反弹确认）之后**不是**适合退出的时点，反而更接近「继续持有」的时点。
- 该结论属于**持有层事实**，不等同于「应改为持有到 T+80」，也未被验证为正式 Exit 规则（见 §8）。

## 7. 与「状态出现即退出」（EXIT-STATE-DECISION-001）的区分度对比

| 维度 | EXIT-STATE-DECISION-001（状态出现即退出） | 本轮 REVERSAL-001（状态失效时退出） |
| --- | --- | --- |
| 事件时点 | 状态**出现**（多为早期 rd10–20） | 状态**首次失效**（RAW 早期 / SUSTAINED 多为 rd27–42） |
| 典型失效退出收益 | 出现即退出常为正（选择效应） | SUSTAINED 均线类接近 0～+1.7%，尾迹类 +12%（先涨过） |
| 继续持有增量形态 | 多数为右尾型，中位为负 | 同上，但 CLC2 出现唯一中位为正单元 |
| 区分度 | 6 状态 × 3 观察日，仅 3.0% 单元为 BROAD 且为薄样本 | 5 状态 × 2 变体，5 个 SUSTAINED 单元中 1 个 BROAD，且 CLC2 年度 7/1 |

**结论**：状态**失效**相对状态**出现**确实提高了区分度——尤其是 SUSTAINED 把「趋势真正持续过」与「一日噪声」分开后，CLC2 呈现出与其余状态方向相反的清晰结构。但绝大多数的增量仍然是**右尾型**：均值被少数大赢家抬高，中位为负。

## 8. 结论与研究边界

### 8.1 本轮得到的事实

1. **失效退出 vs 继续持有**：在 SUSTAINED 口径下，5 个状态里有 1 个单元（CLC2 → T+80）呈现 BROAD 结构（增量均值 +2.09pp、中位 +0.29pp、正比例 51.6%、年度 7/1）；其余 4 个均为右尾型（均值>0、中位<0）。
2. **失效退出并不普遍优于继续持有**：除 CLC2 外，所有状态的中位增量都是负的，说明对多数交易而言，等到状态失效再卖出反而比继续持有到 T+80 更差（或接近）。
3. **均线类失效（MA10 斜率转非正 / MA5 死叉）是最早、最普遍的触发**（覆盖率 96–99%，失效中位 rd27–31），但其增量中位为 -2.02pp / -2.23pp，对多数交易不利——它们更像「已经走完一段后的确认」，不是增量退出信号。
4. **创新高类失效（NEW_HIGH_3 / 连续抬高等 2）发生在已经上涨过的交易上**（失效退出均值约 +12%），继续持有呈右尾型；2026 明显为负，2020/2025 为正。
5. **CLC2 的语义与其他相反**：它的「失效」是反弹开始，因此「失效即退出」在本状态下的含义是「反弹确认时卖出」，而数据显示这恰恰是**最差**的选择（失效退出均值 -7.64%、胜率 24.4%）。

### 8.2 稳定 / 待验证

| 结论 | 状态 | 依据 |
| --- | --- | --- |
| 可继续使用（方向稳定） | 均线类失效后继续持有并不占优（中位为负，CLOCK-MAP-001 shift-robust） | 两变体 + CLOCK-MAP-001 一致 |
| 可继续使用（方向稳定） | CLC2 反弹确认后继续持有优于反弹即卖 | SUSTAINED 唯一 BROAD，年度 7/1 |
| 对口径敏感，需重做 | RAW 首次失效（rd6–11 噪声主导） | 5 状态几乎同值，无区分度 |
| 样本薄 / 年度不稳，待验证 | NEW_HIGH_3 / 连续抬高 ≥2 的右尾增量 | 2026 −12.78pp / −16.50pp |

### 8.3 明确边界

- 本轮**没有**验证「失效退出」作为正式 Exit 规则；`EXIT_AT_FAILURE` 是研究层对照口径，未接入 Strategy/Backtest 执行链，也未计入组合层资金循环/少开仓的机会成本。
- 「失效后未来收益较低」≠「适合退出」：本报告的增量是**持有层配对差值**，不含资金占用、不含开仓替代收益。
- 未做：参数搜索、状态组合、阈值优化、Candidate 创建、策略晋升、架构修改。

### 8.4 建议的下一项研究实验（只描述研究问题，不做策略推荐）

1. **CLC2 路径的独立复现实验**：固定观察口径，验证「反弹确认后继续持有」在组合层是否仍成立，并计入资金循环机会成本。
2. **失效语义稳健性**：对 RAW vs SUSTAINED 的差异做一次口径敏感性说明，明确后续实验统一使用哪一口径。
