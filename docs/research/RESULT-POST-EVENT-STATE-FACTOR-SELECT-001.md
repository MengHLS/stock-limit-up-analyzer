> ## 🔴 **⇒ 两种读法下均【不构成合理区分】⇒ 依任务规则必须输出「暂不择一」**

### 3.1 为何不构成「合理区分」

| # | 理由 |
|---|---|
| **1** | **两侧各自在【不同维度】取得一致（两窗口均为优胜）的优势** —— `maxAmp5` 赢「幅度与下限」，`avgAmp5` 赢「尾部抗性与跨窗口一致性」 |
| **2** | **二者代表【两种不同的稳健性定义】**：「下限更高」（max）vs 「一致性更好 / 坏年更抗」（avg） |
| **3** | 🔴 **任务未指定研究目标偏好**（是追求更高幅度，还是追求更低尾部风险与跨窗口一致性）⇒ **不存在可据以裁定的加权** |
| **4** | **`avgAmp5` 独得【整个】准则 ④（尾部抗性）** —— 该项在两窗口的「绝对损失」与「相对优势」两个子读法下**均为胜**，**不是边缘胜负** |
| **5** | **`maxAmp5` 独得准则 ② 与 ⑤，但 `avgAmp5` 的 IC 优势（逐年 7/7）亦为系统性** —— 尽管 **IC 未转化为组合优势**（avg 的 ΔmeanExcess / Δ贡献 在两窗口均更低） |
| **6** | **③ 的解释歧义本身即证明区分不稳健** —— 换一个同样合理的读法，结论即由「3:3」变为「3:2」 |

> ## 🛑 **⇒ 依任务明确规则：「如果两者在已有证据下无法合理区分，必须输出『暂不择一』，不得人为制造优胜者」**
> ## **⇒ 本轮输出 `KEEP=暂不择一`，未制造优胜者。**
