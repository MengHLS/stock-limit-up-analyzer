## 6. 附录 A · 度量方法的修正（**写于 S1/S2 孤立分段跑之后、S3 之前**）

### 6.1 为什么必须修正（**实测发现的两个缺陷**）

| # | 缺陷 | 实测证据 |
|---|---|---|
| **D-1** | **`equityCurve` 不受 `simConfig.dateRange` 约束** | S1（`2019-01-03 ~ 2020-12-31`）的年线输出延伸至 **2021 / 2022 / …**（`ANNUAL(B)=2019:4.05% 2020:8.76% 2021:-1.99% 2022:0.00% …`）⇒ 若按「曲线末点」算 `TOTAL`，会把段外区间的变动计入 |
| **D-2** | **孤立分段跑会在【段界截断持仓】** | S1 `stuck=118` / S2 `stuck=125`（占该段成交 **8.6% / 5.8%**），**远高于全期的 2.64%**；且 `holdAvg 37.57 / 38.67` **低于 40** ⇒ 段界强行打断了 40 日持有 |

### 6.2 修正后的方法（**主方法 = 全期单跑 + 离线切段**）

| 项 | 定义 |
|---|---|
| **主方法（Primary）** | **全期单跑一次**（`2019-01-03 ~ 2026-01-28`，冻结配置）→ **落盘 `equityCurve`** → **按段日期离线切分** |
| 合法性依据 | 本策略**无任何可拟合参数**（§2.2）⇒ 全期跑不构成「用段内数据调参」 |
| 优点 | **无段界截断伪影**；`stuck` 回到全期水平；段内 `holdAvg` 回到 ~40 |
| **交叉校验（Cross-check）** | **孤立分段跑**（已获 S1/S2）作为稳健性对照 —— 若两种方法的**结论方向一致**，则结论更稳固；若不一致，**以主方法为准并登记差异** |
| `TOTAL` | 切段后 `eq[段内最后一点] / eq[段内第一点] − 1` |
| `MDD` | 切段后段内 `equity` 序列的峰值回撤 |
| `ANNUAL(B)` | 切段后**仅段内年份**；首年基期 = 段内第一点 |
| 基准 | `000300.SH` 同段同期（不受本缺陷影响） |
