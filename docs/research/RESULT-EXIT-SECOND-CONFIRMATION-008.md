> 目标：验证首次 Runner 强→弱后的二次确认，能否区分临时回撤与持续衰竭。允许有限的固定路径组合，不新增变量、不搜索阈值、不创建 Candidate。

## 0. 固定口径

- Dataset: `first_limit_pullback` / `datasetVersionId=660001`；固定池 `D20 < -10% && MA20Slope <= 0`。
- 基础事件：EXIT-CONFIRMATION-007 中首次强→弱且可观察的事件。
- D+1/D+2/D+3 二次确认状态：
  - 恢复强状态；
  - 持续弱；
  - 持续弱且未重新创新高；
  - 持续弱且短收益未恢复；
  - 持续弱且收盘位置未恢复。
- 所有条件均由 RUNNER-STATE-RESEARCH-004 固定变量构成；组合数量固定，不进行参数搜索。
- 恢复状态采用“继续持有到 T+20”路径；持续弱类状态采用“在对应 D+k 收盘退出”的描述性对照。

## 5. 结论

- `Strong → Weak → Recover` 与 `Strong → Weak → Continue Weak` 是明显不同的路径类型。恢复组的后续 MFE、最终收益和 Runner 概率明显高于持续弱组。
- 在持续弱组内，再增加“未重新创新高”“收益未恢复”“收盘位置未恢复”等固定路径条件，会进一步提高衰竭解释力；但不做单因子择优，也不把它们产品化。
- D+1/D+2/D+3 延迟确认通常改善相对 D0 的退出收益并降低 lost20/lost30，但改善在不同首次转弱类型和年份之间并不一致。
- 二次确认的主要价值是识别“假衰竭”：首次转弱后能恢复强状态或重新创新高的事件，不应与持续弱状态事件等同处理。
- 本轮不创建 Exit 规则或 Candidate；若后续继续，应优先验证“恢复/持续弱”路径分层，而不是继续增加参数。
