## 1. 唯一研究问题与完成范围

在首板触发的滚动观察池中，基于**当天收盘可知**的信息，每天按股票选择最多3个候选，能否比同日同池随机选择提高**从下一日开始的20交易日右尾机会**？代价是多少？

## 4. 股票池规则：事件历史保留、每日股票不重复

1. 保留所有原始首板事件及id。每日先产生当时仍在rd1..40的事件成员。
2. 同symbol多成员在池时，**只保留最早尚未过期成员作为当日锚点**，其余在`relatedEventIds`登记；原成员未过期时，新首板不刷新旧锚点/年龄。
3. 最早成员过期后，若还有当时已发生且未过期成员，可切到其中最早一个；因此单次事件最多观察40日，但股票反复发生事件时可能连续在池。锚点切换显式记账。
4. 三天两板、五天三板属于截至当天可知的路径状态：记录近3/5交易日涨停次数、近期连续涨停、最近涨停距离；**本轮仅描述，不作为新增评分或过滤**。沿用权威涨停事实，不用失效boardCount字段猜测。
5. 连续跌停不删除原事件、不因未来结果剔除；记录截至当天的状态、当前可买/可卖标志。没有可靠逐日跌停事实就注明不可用，不新写另一套价格限制公式。
6. 区分`inWatchPool`、`signalEligible`、`nextOpenExecutable`。前两项只能使用当日已知信息；第三项是下一日真实执行结果，不能提前用于排名。
7. 因同股票只保留一成员，日选择不会重复symbol；研究不等于账户，跨日重复选中仍记录，但必须另外报告首次/重复信号和独立赢家，不重复声称多个赢家。

必要的每日账：date/symbol/anchorEventId/eventAge/relatedEventIds/状态可用性/两因子值与缺失原因/资格与拒绝原因/信号排名。任何资格变化均能归因到当时数据。两主臂及Random共同使用“两因子均可评估”的当日池，缺失成员仍保留观察账并报告画像；未来标签缺失不得进入当日资格条件。

## 5. 收益标签、右尾指标与成交风险

### 5.1 标签与观察上限

标签A（主）：假设下一交易日开盘入场，持有20交易日的价格净收益。使用已存在标签/可卖顺延原语；主退出不可卖时顺延到其后首个可卖收盘，最多再10交易日，并披露顺延成本假设。本标签是研究标签，不称平台NEXT_OPEN策略回测。

标签B（辅助）：未来20日内最高价相对上述入场价的涨幅，用于右尾机会发现。**不是可实现收益**，不能用最高价模拟卖出。记录+20%机会率及信号提前量作为辅助。

两标签均从信号之后起算，不含信号形成期收益。价格复权、分红和执行事实与既有Dataset/标签原语一致，口径不一致先解决或BLOCKED。

下一开盘不可买的信号保留在信号账：执行性标签记NO_FILL，**不事后从信号池删除或递补第4名**。所有信号计数、可成交子集收益和无成交比例分别报；需要统一全信号效用时可把NO_FILL记现金收益0，但必须明确这是决策槽位效用，不能伪造成交。

末端没有完整未来窗的记录按右删失标记，不从池成员账删除。持续不可卖且超过顺延上限时，用上限日MTM并标未退出，同时报数量/损失，不能丢掉或伪造成交。未知数据与真实停牌/退市严格分开。

### 5.2 主判据及不得隐藏的代价

| 指标 | 固定用途 |
|---|---|
| **20日固定持有净收益≥+20%的概率，相对同日Random的差值** | 主右尾判据；20bps为主、50bps敏感性，不用未来最高价代替 |
| +20%路径机会率 | 辅助发现指标，不能单独判研究保留 |
| ≥+50% / ≥+100% | 只描述计数；20日稀有目标不因样本少延长期限追显著 |
| 净均值、中位数、胜率、≤−10%概率、Q05 | 右尾需要付出的普通亏损和左尾代价 |
| 每日候选数量/覆盖、缺失、NO_FILL、无法退出、重复信号比例 | 是否能形成可参与的机会 |
| 唯一symbol-上涨机会段计数、赢家召回率、首次信号时间 | 防止同一次上涨被每天计成新赢家；机会段离线用于分析，不作实时入池规则 |

唯一赢家采用明确的离线合并定义：同symbol的相邻信号标签窗共享交易日则属于同一机会段。记首次识别、信号次数、各次标签；不能把未来机会段边界用于实时选择，也不能将机会段数当独立样本数。

每日配对差序列采用已有日期moving-block bootstrap，主block20、敏感性block40，固定1000次。另输出按symbol/机会段等权摘要，说明日期共同冲击与同股重复依赖。不能bootstrap单个股票日来宣称独立。两预声明主臂用Bonferroni同时区间：每臂**97.5%双侧CI**；不以大量辅助检验择优。复用统计原语，若不支持置信水平做最小有测试的扩展，不复制第二套统计实现。

### 5.3 本轮事前收口规则（研究标签，不是策略晋级）

- **RIGHT_TAIL_EVIDENCE**：主右尾差值调整后CI下界>0，2024与2025片段点估计同向，block40差值CI下界也>0；至少50个唯一机会段包含该臂的主右尾命中；NO_FILL必须一并披露。即便满足，也不自动称可交易。
- **RISK_TRADEOFF**：满足上述右尾证据，但≤−10%概率相对Random显著增加或净均值相对Random显著更差。必须以此限定取代无条件推荐；不得为了通过删除跌停样本。
- **INSUFFICIENT_EVIDENCE**：CI跨0、年度反向、机会段命中不足、数据覆盖或依赖敏感性不足。区分无效与无法判断。
- **NO_SUPPORT**：主差值CI上界≤0，明确本配置无支持。
- 所有主臂研究负面或不足即收口；不追加变量、期限、TopK或门槛。以上阈值为本MVP操作约定，不是金融学普适标准；用户发送启动指令即接受此固定方案。
