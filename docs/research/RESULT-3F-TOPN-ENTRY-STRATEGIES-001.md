## 实验范围

- 对照组：`v1.44.1`（SL-18.1，峰值回撤 8%）；
- B 组：观察窗平均振幅 / 最大振幅 / 破位深度三类硬过滤及其组合。

数据坐标：Dataset v5（`dataset_version.id=660001`）/ 2019-01-01 ~ 2026-09-04 /
`first-limit-pullback-3f-top3` / T+5 收盘决策、T+6 开盘买入 / 退出链与 `v1.44.1`

## 解读

1. **只有 `b4`（最大振幅 < 12%）优于对照组**：累计收益 +30.21%（+2.25pp）、PF
   `1.0954`（更高），最大回撤 52.59%（+0.91pp，在 1.3pp 容忍内）。它是 B 组唯一
   值得继续 OOS/walk-forward 的候选。
2. **平均振幅过滤全线恶化**：`<8%` 已从 +27.96% 掉到 +18.75%；`<7%`、`<6%` 直接变为
   亏损。结论与评分分层证据一致——中低振幅档包含大量强势续持右尾，硬门槛会把它们删掉。
3. **破位深度过滤灾难性**：`> -10%` / `> -8%` 把几乎全部正常回踩候选挡在门外，成交
   从 1362 涨到 1651（候选被推给低分/深破位替代），期末权益只剩 2.3~2.7 万。该方向
   在 v1.44.1 的“首板回踩 + 强持有”退出链下不成立。
4. B 组结论：**不建议继续做平均振幅/破位深度硬门槛**；下一优先级转向市场状态过滤
   （A），并把 `b4` 作为唯一绝对风险候选合并进入后续测试。

### C 组解读

- `c1` 的收益几乎与对照组持平（-0.32pp），但最大回撤从 51.68% 降到 **31.61%**，
  PF 从 1.0909 升到 **1.1245**、夏普升到 0.3081 —— 风险侧明确优于对照；

### C 组问题诊断：为什么回撤降了、收益没怎么提

按评分分档，控制组与 c1/c2 的完成交易净盈亏贡献如下：

| 档位 | 规则 | 控制组净盈亏 | c1 净盈亏 | c2 净盈亏 |
| --- | --- | ---: | ---: | ---: |
| 高分 `>=0.7167` | 三组均按 20% | +19,717 | +24,023 | +26,400 |
| 中分 `0.55~0.7167` | 控制 20% / c1 10% / c2 5% | **+39,447** | +20,900 | +6,937 |
| 低分 `<0.55` | 控制 20% / c1 5% / c2 5% | -8,360 | -1,808 | -1,676 |
| 合计 | — | +50,804 | +43,115 | +31,661 |

结论：

1. **中分档才是 v1.44.1 的主要利润来源**（+39,447 / +50,804 ≈ 78%），
   而它恰好是 c1/c2 减仓最狠的档位（10% / 5%）；
2. 高分档“满仓”后单档净盈亏确实略升（19,717 → 24,023/26,400），但样本只有约 260 笔，
   补不回中分档被砍掉的 18,547 / 32,510；
3. 低分档亏损从 -8,360 缩到 -1,808/-1,676，这正是回撤下降的一部分来源；
   叠加全组合平均暴露下降，回撤自然降，但收益端“最重要的引擎”也被同步按比例削小。
4. 因此 c1/c2 不是“把风险减掉但保留收益”的分层，而是“把整个策略的暴露按档位
   重新分配”：减掉了中分档的右尾，只留下高分档的稳定小收益。

下一轮建议改为“只砍低分档、中分档保持 20%”：

- `c5`：高分 ≥0.7167 20%，中分 0.55~0.7167 20%，低分 <0.55 5%；
- `c6`：高分 25%，中分 20%，低分 5%（把被削减的低分资金尽量移给高分）；
- 或在中分档维持 20% 的同时，把释放的现金用于提高单日建仓/并发持仓上限，
  否则平均暴露下降会继续拖低收益。
