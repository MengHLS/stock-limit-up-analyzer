# composite-runner-newhigh3-t74-trend-gate（P0-2 · 趋势分门槛）

**目的**：P0 已证明「趋势评分按权重混进排序值」会单调恶化收益。这一版换**用法**：
**排序值完全不动（纯 3F）**，趋势分只用来**剔除**差候选（`trendScore < minTrendScore` 不入池）。

假设：若趋势分含任何正向信息，它应当表现为「剔除最差一档 ⇒ 剩下来的 3F 头部更干净」。

### 结论：**门槛化同样被否，而且原因更清楚**

诊断探针（`_probe_p02_gate_diagnosis.mts`，只读基线投影 + 纯计算）：

| 门槛 | 控制臂选股被门槛吃掉的比例 | 被吃掉选股的平均 3F | 留下选股的平均 3F |
| --- | --- | --- | --- |
| ≥ 1/6 | 1373 / 5569（24.7%） | 0.6286 | 0.6765 |
| ≥ 1/3 | 3905 / 5569（70.1%） | 0.6617 | 0.6718 |
| ≥ 2/3 | 4878 / 5569（87.6%） | 0.6667 | 0.6503 |

- 被门槛剔除的**不是明显更差的候选**：门槛 ≥ 1/3 时被剔者平均 3F 0.6617、留下者 0.6718（只差 1pp）；
  门槛 ≥ 2/3 时**留下者的平均 3F 反而更低**（0.6503 < 0.6667）。
- 但门槛吃掉了控制臂 **24.7% / 70.1% / 87.6%** 的选股 ⇒ 策略被迫买入当天 3F 的**下一档**。
- ⇒ **策略的 alpha 集中在「每日 3F 最头部 3 名」这个极窄区间**：任何显著缩小候选池的过滤，都会
  把选股挤到更差的排名上，损失远大于「剔除坏名字」的收益（回撤同步从 43% 抬到 70–80%）。

### 与 P0 合并的总结论

`trendScore` V1（结构 / 动量 / 回踩三档等权）对本策略是**反向指标**，两条用法都已被真实数据否掉：

| 用法 | 结果 |
| --- | --- |
| 作**排序项**（P0） | w=0.2/0.3/0.5 ⇒ −59% / −86% / −95%（控制 151%），单调剂量-反应 |
| 作**门槛**（P0-2） | ≥1/6、≥1/3、≥2/3 ⇒ −21% / −74% / −75%，同样是单调剂量-反应 |

⇒ **不建议**再基于这套 V1 趋势评分继续试权重 / 阈值（换用法不改方向）；也不要反向使用
（低趋势分本来就是 3F 已经在选的方向）。若仍要引入趋势信息，必须先换**定义**（连续化、或反向重定义），
或改放到**仓位 / 退出**维度上。
