## 3. 池、买点与账户的精确定义

### 3.1 保留的研究边界

- 复用现有首板滚动池：主板、事件日非ST、上市至少365自然日。首板为当日涨停且前一交易日未涨停，不宣称是历史首次涨停。
- 同股票保留最早未过期锚点，后续首板不刷新年龄和支撑；按原规则合法切换锚点。池观察范围仍为rd1～40，T+20后继续观察但不因该锚点新买。
- 优先核验 `datasetVersionId=780004` 的真实READY状态和内容指纹；主决策窗口保持2024-01-02～2025-09-30。这是已经观察过的历史窗口，属于探索性续研，不是新OOS。
- 连板、三天两板、五天三板等后续路径保留为事后分层标签；当日尚未知的未来事件不能提前排除。可靠历史支撑破位按当前买点失效规则处理，不能按未来连续跌停筛选样本。
- 因子只排序已触发买点的候选。R沿用原始 `preReturn10 HIGH`；固定rd11～15的 `maxAmp5` 不参与。观察分只判定资格，本轮不混合加权排序。

### 3.2 连续观察规则的唯一变动

基础规则来自 [连续观察入场规则001](RULE-FIRSTBOARD-ROLLING-OBSERVATION-ENTRY-001.md)。本文覆盖其中固定“两日”“T+10”及“同锚点成功买入后永久禁止”的规定；当前续研以本文为准。评分、支撑与价格口径沿用原定义，历史001/002规则仍用于其旧版本复现：

`S_j = 1[L_j >= 0.98*O_0] + 1[V_j <= 0.50*V_0] + 1[L_j >= L_(j-1)] + 1[C_j > C_(j-1)]`。

确认日d收盘后，必须同时满足：

1. `N+1 <= d <= L-1`；相对日按锚点的实际交易日坐标计算。
2. 之前确实回撤：存在 `j∈[1,d-1]`，`C_j < C_0`。
3. 支撑始终有效：`min(L_1,...,L_d) >= 0.98*O_0`。
4. 紧邻确认日的N个观察日 `d-N,...,d-1` **每天分别** `S_j >= 3`，均为连续有效交易日。
5. 确认日突破：`C_d > max(H_(d-2),H_(d-1))`。
6. 确认日量能回升：`V_d >= V_(d-1)`；必要字段、身份和R因子可评估。

突破参照仍为前**两日**高点，不能随着N改为前N日高点，否则同时改变突破难度。评分窗口不包含确认日，确认日不受观察期50%缩量门约束。首次可能成交日由历史成熟决定，不是固定买入日。

缺失、停牌、零量按原规则使有关观察分为null，不能跳过无效日拼成连续N天；必要支撑历史不完整则无法评估，不把缺失当作全程守线。可靠破位永久取消该锚点本轮买入资格，不新增持仓卖出条件。

**边界说明**：取消一次入场限制，并没有取消“历史支撑破位永久失效”。因此，止损后跌破首板支撑、后来收复的路径仍可能无法再次入场。本轮将这些事件与“仅因曾经买过而被阻断”的事件分开统计；不把后续上涨直接解释为主力建仓，不宣称已捕获全部反弹路径。若该桶右尾显著，应另行提出“支撑修复后重新激活”实验，不在本轮悄悄取消支撑门。

### 3.3 再次触发与真实成交

对每组先生成全部日期的原始触发候选，使用当日及以前信息。不能预先只保留每锚点第一次触发。

每账户各自排名/随机选最多3只，再执行已有账户限制；每天最多新买2只、最多持有5只。同股已持仓不加仓，不允许不同事件身份绕过同股票持仓上限。未选中或拒单不算成功入场，后续完整买点成立且仍在期限内时可再次参与；不自动延后旧订单。

两种账户政策明确分开：

- **SIGNAL_REENTRY（A/B/C/D）**：第一次、第二次及后续建仓都必须满足同一完整买点。上一笔已真实全部平仓、当天收盘再次确认且仍可期限内成交时，可以新建仓；不因“该锚点曾买入”永久阻断。不额外设一次或两次总次数上限，实际次数受完整买点、退出、入场期限及账户容量限制。
- **SINGLE_ENTRY（E）**：同锚点最多一次成功建仓；退出后再出现买点也阻断。拒单和未入选仍可重试。仅作为量化原限制代价的对照，不作为主配置默认政策。

新入场必须使用**卖出实际成交后新计算的收盘信号**，不能沿用上笔买入信号或待平仓预测。若当日已实际全部卖出，当日收盘可以重新评估，次一交易日才可买入；仍持仓、仅部分减仓或卖单未成交时禁止再次建仓。不另加固定冷却期，不强制重新等待N个平仓后观察日：评分始终用当前收盘前紧邻的N个交易日，允许这些历史日与前一笔持仓期重叠。

平仓不会重置首板日、T+20截止、支撑破位历史或原池锚点切换规则。再次买入按新的买入价和成交日期重建持有日、止损、盈利激活、峰值、strongHold及Runner状态，不继承上笔的延长期限或峰值。新建仓金额仍是该次决策日权益20%，每次完整扣费。

当日收盘确认，次一交易日开盘撮合，实际成交rd不能超过组内L。无成交如实记录；不能读取未来开盘或涨跌停状态提前移除候选、换成第4名，或顺延至期限之后。交易日映射用平台行情日历，不用自然日加一。

同组R和全部Random使用完全相同的**原始候选池**；账户再入场限制、持仓、现金等可以导致实际可买集合不同。D/E原始买点池也完全相同，不预先截掉E的后续候选，只在E账户层阻断。不同N/L的原始候选池则自然不同，不强行对齐交易数量。

优先核验 `server/research/simulator/reentry.ts#createReentryBlocker` 与 `engine.ts#runTradeSimulation` 的现有入口：`maxEntriesPerMember`按传入securityId累计，而本任务E的次数键为“账户＋锚点事件”。不能在canonical股票身份上设全历史次数=1，误伤原池规则合法切换后的新锚点；不能伪造证券身份来实现重置。主配置透传无总入场次数限制、无额外冷却，并保留同真实股票并发上限1。需要的锚点状态须在既有执行链中透明表达；若现有契约无法表达，明确提出最小兼容扩展并测试，不新建执行器。

## 6. 事前统计与结论规则

### 6.1 主指标和固定比较

主指标为**已完成真实交易、扣除成本后收益≥20%的命中数/比例**，并报唯一股票和锚点命中数。≥50%、≥100%辅助；同时报告单笔均值、分布及真实账户复合收益、年化、MDD、胜率、现金占比、平均持仓/仓位与拒单。

本轮唯一主要比较为 **D_R−B_R**：在相同T+20期限、相同允许再入场政策下，五日观察相对两日观察的增量。**D_R−E_R**单列再入场增量，B_R−A_R为期限延长比较，C_R−B_R为三日观察描述性对照。各组R−Random为排序诊断，重点报告D；这些次要区间不作为独立确认性成功判据，不挑最好组替代主要比较。

日期移动块bootstrap预冻结1000次，block20为主、block40为敏感性，双侧95%区间。使用主决策窗口及允许成交日对应的完整交易日日历，包括无入场日；以实际入场日期归属完成交易，按相同日期块索引同步抽样各比较臂的尾部命中分子、已完成交易分母及单笔收益和。使用主指标比率，不先算每日小样本尾率再平均。抽样后分母为0的次数单列。

Random尾率以200个账户的完成交易合并分子/分母计算；账户收益另报跨seed均值、分位数及R位置。全部Random同一市场历史，应随同相同日期块整体保留，不能把交易或种子视为独立市场历史。重复出现的锚点、股票及相同交易要报告有效样本规模。

再入场的多笔交易不是新增独立首板事件。单列首次、第二次及后续的成交数、≥20%尾率、均值、费用、净损益和累计亏损；报告“至少一笔≥20%”的唯一锚点数/实际成交唯一锚点数，以及同锚点所有已完成交易的合计净损益。命中一笔大涨但此前反复止损使整个交易链净亏的情况单列。每个锚点在50个唯一命中门槛里最多计一次；同锚点整条交易链共同归属锚点首笔入场日期做补充日期块敏感性，避免拆散链条夸大置信度。锚点净损益不是账户复合收益的替代值。

固定全年、2024、2025三层尾率/均值比较。账户逐年权益收益由canonical口径给出，年度基数用上年末权益；若2026只是退出尾部，单列其权益贡献，不纳入2024/2025入场年份的信号稳定性判据。

### 6.2 结论门槛与停止规则

- 主比较需D_R与B_R各至少50个唯一≥20%命中锚点，日期重采样有足够有效观测；否则 `INSUFFICIENT_EVIDENCE`，即使某组总收益很高。
- 只有主尾率差95%区间下界>0、block40不反向、2024和2025同靶差均为正，才能称“本窗口五日观察有右尾改善证据”。这是探索性历史证据，不能升级为OOS通过。
- 若满足样本门槛但改善区间跨0或反向，明确未获得改善证据；不能把不显著解释为等效。某年份尾部样本不足，也不能声称跨年稳定。
- R排序诊断需单独满足唯一命中样本、P3与年度同靶要求，不能用“D比B好”替代“R比Random好”。本轮不将多个次要95%区间的任一正结果包装成正式确认。
- 右尾改善但均值、账户复合收益或风险代价恶化时，分开结论；账户亏损不能称为可交易策略。固定Runner的真实触发可描述，未做退出消融则其因果贡献仍不可量化。
- 零买点配置如实报告 `NO_TRIGGER_IN_WINDOW`，尾率为不可定义，账户为空仓收益0；不是数据失败，也不是有效性通过。全部零买点则完成规则/数据诊断，不伪造成交结果。
- 只执行冻结矩阵；工程失败可以修复后重跑并留痕，经济结果差或样本少不能调阈值、换年份、挑seed补救。

### 6.3 报告必须包含的诊断

P1–P6逐项作答。逐层输出观察→历史回撤→支撑有效→N日得分合格→突破→候选→下单→成交→Runner触发→退出；分别给日行账、唯一锚点账与唯一股票账。重复拒绝日与首次失效事件不要混为一类计数。

每组报告候选日期数、候选日人数分布（≤2、=3、>3）、触发锚点数、再次触发数、实际成交数及成交年龄分布。说明排序真正面临选择的日期与账户空位约束，不能用200个随机账户重复累计来制造“几万笔独立交易”。

另交再入场账：`accountId/anchorEventId/symbol/entryOrdinal/previousActualExitDate/newConfirmDate/newFillDate/entryEquity/targetBudget/exitReason/netPnl`，未成交尝试另记，不增加成功入场序号。分别披露因已持仓、E次数上限、支撑永久破位、观察条件不足、期限结束而不能再买的数量和事后路径画像。D/E差异包含现金、名额与后续选择联动，不能把“D中第二次交易利润之和”冒充整个政策增量。

报告各排除桶在尾率、均值、分位上的事后画像，并给出标签观察时点、统一视界及覆盖分母。这些标签仅用于诊断，不能反向进入资格；缺少完整标签则明确未知，不能填零。

同时报告完整观察路径命中率与真实退出净收益尾率，两者分开命名。期末未平仓交易不按完成交易计入尾率，数量、权益和潜在截尾偏差单列；各组共有评价终点不随赢家的持有长度改变。
