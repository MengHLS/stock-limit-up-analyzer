## 5. 特别要求

### 5.1 VCB：此前 NO_EDGE 在 PIT 后是否仍成立？

**成立，且更明确。** PIT 后逐日 spread = -0.077% / -0.248% / -0.374% / -0.617%（t = -2.45 / -3.99 / -4.67 / -5.80），比 raw（-0.061% / -0.234% / -0.358% / -0.599%）略更负；正年数不变（0/3/3/3）；去重后仍为负。
PIT 新增/删除候选：新增 1,281、删除 62（相对 P0）。这些变化没有改变结果方向——新增候选的加入只把 T+1 spread 从 -0.061% 拉到 -0.077%，T+10 从 -0.599% 拉到 -0.617%。**VCB = NO_EDGE（保留）。**

### 5.2 BB：PIT 新入池 3,402 / raw-only 1,410 与结构字段变化

- PIT 相比 raw：新增 3,402、删除 1,410（Jaccard 0.896，三者中变化最大）。
- 结构字段变化：platformHigh 1,921、platformLow 5,293、platformRange 5,312、platformReturn 8,348、breakoutDistance 1,971。
- 经济结果：raw spread -0.186% / -0.306% / -0.494% / -0.844% → PIT -0.178% / -0.288% / -0.446% / -0.748%；**PIT 后略缓和但依然全期限显著为负（t = -5.5 ~ -7.0）**，且 pooled/截尾/去重全部为负。
- **结论**：此前的 raw BB 结果不是由除权除息造成的系统性**高估**——恰恰相反；PIT 修正后 BB 仍然（甚至更清楚地）NO_EDGE。raw 的 23.40% 公司行为暴露没有制造出假 edge。**BB = NO_EDGE（保留）。**

### 5.3 PR：reclaimLevel / pullbackDepth / impulseReturn 与 rawOnly / PITOnly

- PIT 相比 raw：新增 4,301、删除 1,476（Jaccard 0.974）。
- 字段变化：reclaimLevel 2,170、pullbackDepth 1,715、impulseReturn 5,770、retraceRatio 7,095、swingLowDaysAgo 1,403。
- 出池原因（采样 400/1,476）：reclaimCrossing 326、notBreakout 243、pullbackOk 136、impulseOk 123——是 ex-date 附近 swing/pullback/reclaimLevel 的重新定位，而非单阈值。
- 经济结果几乎不变：T+1 +0.063% → +0.065%（t 3.62 → 3.81）；T+3 -0.028% → -0.023%；T+5 -0.136% → -0.131%；T+10 -0.377% → -0.367%。
- **结论**：PIT 修正没有改变 PR 的统计特征形态（短期限正、长期限负）；按 Gate 仍 NO_EDGE。PR 的 T+1 正信号值得作为**未来其他独立行为假设**的输入，但本轮不满足 EDGE 判定，不能进入 TopN。**PR = NO_EDGE（保留）。**

## 7. 明确说明：哪些 raw 结论被保留，哪些发生改变

**被保留：**

1. **VCB = NO_EDGE** —— PIT 后仍为 NO_EDGE，且 spread 略更负；新增/删除候选未改变方向。
2. **BB 的 raw 结果没有因除权除息而系统性高估** —— raw 与 PIT 都是显著负；PIT 后略缓和，但仍全期限为负。
3. **PR 的形态（T+1 正、T+3/T+5/T+10 负）** —— raw 与 PIT 几乎一致；T+1 的稳健正信号在两种口径下都成立，但都不构成 3/4 期限的 edge。
4. **公司行为调整对候选组成的影响是真实的**：BB 1,410 出池 / 3,402 新入池，PR 1,476 / 4,301，VCB 62 / 1,281；但这些组成变化没有反转任何经济结论。

**发生改变（均非方向性）：**

1. VCB 的 T+1 显著性从 t=-1.88 变为 **t=-2.45**（更显著为负）；其余期限更负。
2. BB 的负 spread 幅度略缓和（T+10 -0.844% → -0.748%），出池/新入池使样本结构变化；结论不变。
3. PR 的 T+1 spread 从 +0.0625% 变为 +0.0652%（t 3.62 → 3.81），T+10 从 -0.3766% 变为 -0.3674%；形态不变。

**没有任何行为从 NO_EDGE 变为 EDGE。**
