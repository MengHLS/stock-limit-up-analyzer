# RESULT-3F-TOPN-3-V1_62_1-T80-001

> 目标：在不改变 1.62.1 选股、3F Top3、入场、仓位、5% 止损和退出规则的前提下，仅把研究数据/路径窗口扩展到 T+80，判断 T+80 是否为后续 Runner/Exit 研究提供增量信息。

## 0. 关键数据坐标纠正

- 用户最初给定 `datasetVersionId=660001`，实际 Registry 验证为 **v5**，`post.relativeDay max=20`，**不支持 T+80**。
- 实际 `v7` 的 `datasetVersionId=750001`，`post.relativeDay ∈ [1,80]`，本轮使用该版本提供 **T+21～T+80** 真实行情。
- 660001 仅用于复现原 1.62.1 T+20 官方基准；没有用 T+20 数据模拟 T+80。
- 信号仍只使用 `rd0..rd5`；`rd21..rd80` 只作为路径研究标签，不参与选股、入场或退出。

## 4. T+20 与 T+80 的信息增量

- T+20 样本：1348；T+80 样本：1304。
- T+80 相对 T+20：MFE 提升的样本 834 / 1302（64.06%）。
- 全局峰值出现在 T+20 之后的样本：856（62.99%）。
- T+20 之后再创新高的样本：856（62.99%）。
- T+20 为正、T+80 转负：258；T+20 为负、T+80 转正：204。
- T+80 趋势状态：UP 288 / DOWN 401 / MIXED 615。

结论：T+20 不是所有交易的终点。超过六成交易在 T+20 之后仍有更高的 MFE，且约六成交易的全局峰值出现在 T+21～T+80；因此 T+80 对 Runner 识别、利润奔跑和退出路径研究有明确增量。但 T+80 同时显著抬高 MAE，且中位收益与胜率下降，不能直接当作策略持有期。

## 6. 结论

1. **T+80 数据链真实可用。** 660001 是 v5/T+20；v7=750001 才提供真实 rd1..80。
2. **现有 1.62.1 策略无法因 T+80 直接获益。** 选股和退出规则不变，T20/T80 策略结果逐项相同。
3. **T+80 的最大增量在右尾和峰值识别。** +20% MFE 概率由 16.39% 升至 45.78%，+50% 由 1.78% 升至 14.26%，+80% 由 0.59% 升至 6.29%。
4. **T+80 应作为 Runner/Exit 研究窗口，而不是新的固定持有期。** T80 的均值提高主要由右尾贡献，中位数、胜率和 MAE 反而恶化。
5. **不创建 Candidate，不修改正式策略。** 本轮只增加了 T+80 研究证据。
