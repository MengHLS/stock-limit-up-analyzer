# RESULT-EXIT-PATH-VALIDATION-009

> 目标：验证“首次 Strong→Weak 后，Recover 继续持有 / Continue Weak 退出”的路径型 Exit 原型是否值得进入正式 Strategy Exit 验证。本轮不新增变量、不搜索阈值、不创建 Candidate。

## 0. 固定口径

- Dataset: `first_limit_pullback` / `datasetVersionId=660001`；初始池 `D20 < -10% && MA20Slope <= 0`。
- T+5 收盘进入，T+6 开盘 Entry；基础事件为 008 的首次 Strong→Weak。
- 路径型 Exit 原型：
  - 在 D+k 前恢复强状态：继续持有至 T+20；
  - 到 D+k 仍持续弱：在 D+k 收盘退出。
- D0 基准：首次转弱当日收盘立即退出。
- 确认窗口：D+1 / D+2 / D+3。所有路径定义与变量均来自 RUNNER-STATE-RESEARCH-004，无新增变量、无参数搜索。
- 同一事件可能在不同首次转弱变量上重复出现，因此汇总表的 N 是 event-transition 记录数，不是独立股票事件数；年度方向用于稳定性判断，不能把 N 当作独立样本量。

## 4. 研究结论

- 路径型 Exit 的核心价值是区分“首次转弱但恢复”和“首次转弱后持续弱”，不是寻找更复杂的阈值。
- 从 D0 到 D+3，策略净收益均值从 10.94% 提升到 11.83%（+10% 激活），从 14.54% 提升到 15.01%（+15% 激活）；+20%/+30% 捕获率同步提高，lost20/lost30 同步下降。
- 方向上支持路径型 Exit，但改善幅度有限且不是所有年份一致：2019 年和 2026 年 D+3 仍低于 D0，其他主要年份多数为正，属于“方向一致但幅度不稳定”。
- PF 随确认延迟下降，因为继续持有 Recover 组承受了更大的路径波动；因此路径型 Exit 只能进入正式验证，不能直接升级为 Exit 规则。
- 本轮不直接修改正式策略，不创建 Candidate。
