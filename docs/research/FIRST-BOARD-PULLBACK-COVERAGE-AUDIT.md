# 首板回撤独立实验分组与退出口径审计

> 审计日期：2026-09-22
>
> 审计范围：`research-experiments/first-board-pullback/**` 下已经注册的 21 个独立实验，以及 `research_experiment_run` 中已经执行的真实 Run。
>
> 不包含：旧 `/research` 链路的 Analysis / Finding / Conclusion 历史数据。本文件只梳理当前「独立实验」体系。

## 1. 一句话结论

当前实验已经覆盖了首板前、首板日、`T+1..T+5` 路径、动态入场和若干动态退出规则，主要缺口不在“因子数量”，而在四个口径问题：

1. 固定 `T+10/T+20` 把完整收益路径压缩成单点，容易把路径风险、退出时点和持有周期混在一起。
2. 固定事件日退出与固定从实际入场日持有，是两个不同问题；现有部分实验把二者混用了。
3. 不同退出视界的可用样本不同，直接比较 `T+5/T+10/T+20` 会发生样本集合漂移。
4. v3 / v4 的复核并不完整，部分实验只跑了一个切片，不能获得同等级的确认强度。

## 3. 合并后的分组词表

### 3.1 事件前

- 距前次涨停间隔：`1~3`、`4~5`、`6~10`、`11~20`、`>20`、`UNKNOWN`。
- 前期涨幅窗口：`T-5`、`T-10`、`T-20`。
- 前期涨幅桶：`<-10%`、`-10%~-5%`、`-5%~0%`、`0%~+5%`、`+5%~+10%`、`+10%~+20%`、`>+20%`。
- 联合分组：涨停间隔 × `T-10` 前期涨幅。
- 冻结联合条件：间隔 `>20` 日且 `T-10` 跌幅 `<-10%`。

### 3.2 首板日

- 严格收盘涨停，剔除非严格涨停事件。
- 沪深主板，Dataset 构建阶段排除 ST。
- 一字板：实验间口径不统一，`hold-open-price-pullback` 默认排除，其他实验多数只标记载体。
- 实体高度：`<=0.1%`、`0.1%~2%`、`2%~4%`、`4%~6%`、`6%~8%`、`>=8%`。
- 首板换手率：`<1%`、`1%~2%`、`2%~3%`、`3%~5%`、`5%~10%`、`>=10%`。
- 同日横截面分位：`0~20`、`20~40`、`40~60`、`60~80`、`80~100` 分位。
- 同日横截面因子：换手率、振幅、实体高度、成交额。
- 历史涨停次数：`0`、`1`、`2`、`3~5`、`6~10`、`>10`。
- 流通市值：字段缺失，当前结论为 `INSUFFICIENT_DATA`。

### 3.3 `T+1..T+5` 路径

- 是否跌破首板开盘价：不破 / 已破。
- 是否跌破首板收盘价：未回踩 / 回踩。
- 回撤深度：`0%~-2%`、`-2%~-5%`、`-5%~-8%`、`-8%~-10%`、低于 `-10%`。
- 首次回撤触发：收盘不高于首板收盘 `100bps`，次日开盘入场。
- 收盘守涨停价：始终不低于 / 略微跌破 / 深度跌破。
- 收盘守线 streak：`0..5`。
- 盘中守线 streak：`0..5`。
- 是否触及涨跌停：`NO_LIMIT` / `HAD_LIMIT`。
- 平均振幅：`<2%`、`2%~4%`、`4%~6%`、`6%~8%`、`>=8%`。
- 较粗平均振幅：`<4%`、`4%~6%`、`6%~8%`、`>=8%`。
- 最大单日振幅：`<8%` / `>=8%`。
- 成交量恢复：`<50%`、`50%~80%`、`80%~120%`、`120%~200%`、`>=200%`。
- 成交量恢复布尔条件：`T+1..T+5` 最大量是否恢复到 `T日` 的 `100%`。
- `T+1` 开盘缺口：`<-5%`、`-5%~0%`、`0%~+5%`、`+5%~+10%`、`>=+10%`。
- `T+1` 量比：`<50%`、`50%~80%`、`80%~120%`、`120%~200%`、`>=200%`。

### 3.4 入场

- `T+1..T+5` 固定开盘入场。
- `T+1..T+5` 决策，之后继续持有到未来视界。
- `T+1..T+5` 首次回撤后，次日开盘入场。
- 动态入场前的过滤：未跌破首板开盘价；实体高度；换手率。
- 可交易性：`canBuyAtOpen`、`canSellAtClose`、停牌、缺 bar、跌停不可卖。

### 3.5 退出与规则竞争

- 固定事件日退出：`T+5`、`T+10`、`T+15`、`T+20`。
- 固定入场规则：`T+1` 开盘持有到固定事件日。
- 动态价格退出：收盘跌破首板开盘价，下一可卖开盘退出。
- 动态量能退出：`T+5` 收盘成交量未恢复，`T+6` 开盘退出。
- 阈值规则：`±2%`、`±5%` 的止盈、止损、对称退出。
- 辅助阈值规则：`+2%` / `-2%` 首次收盘到达后，下一可用开盘退出。
- 时间兜底：动态规则未触发时，最迟 `T+10` 收盘退出。

## 4. 已经形成的证据

### 4.1 比较稳定的负向或风险过滤

- 高换手、高振幅、高实体、高成交额的同日分位组表现较差。
- 历史涨停次数越多，动态交易表现总体越差。
- 深度低开和 `T+1` 缩量表现较差。
- 高振幅是最明确的风险来源。`streak=5` 且平均振幅 `>=8%` 在 v3 中平均净收益约 `-0.89%`，日期聚类 Bootstrap 区间整体低于 0。
- 低振幅能改善均值和回撤，但中位收益仍多为负，不能单独形成正收益策略。

### 4.2 没有形成稳定正向证据

- 单纯“不破首板开盘价”没有稳定正收益。
- 连续 5 日不破涨停价没有稳定正收益。
- 动态价格退出相对条件买入固定 `T+10` 没有增量。
- 成交量未恢复退出相对仅价格退出没有增量。
- `±2%` 早期止损无效，止盈规则最多只有弱候选迹象。
- 超跌长间隔首板冻结假设已经在 Holdout 中 `FAIL`。
- 实体过滤并排除一字板后，v4 的实体 `1%~2%` 在 `T+10` 出现弱正信号，但 v3 没有复现，不能当作稳定结论。

### 4.3 当前不能称为 OOS 的证据

- v2、v3、v4 都是已经查看过结果的数据。
- v3 与 v4 只能称为时间切片复核，不是未来未读数据 Holdout。
- 不能通过删除旧 Run 把已看过的数据重新变回 OOS。
- 真正的新验证必须使用冻结规则和尚未读取的数据窗口。

## 5. 固定 `T+10/T+20` 的问题

### 5.1 样本集合会随视界变化

`T+5`、`T+10`、`T+20` 各自要求对应未来行情完整。越远的视界越容易剔除数据集末端和停牌事件，因此三组收益不一定是同一批股票。

优化方向：

- 增加 `commonSample` 口径，只在 `T+20` 路径完整的事件上同时计算 `T+5/T+10/T+20`。
- 每一个视界同时返回 `fullSample` 和 `commonSample`，不要只给一个数字。
- 显式输出每个视界的右删失数量。

### 5.2 固定事件日与固定持有期混在一起

`entry-day` 中 `T+1` 入场和 `T+5` 入场都退出在 `T+exit`，两组的实际持有日数不同。这会直接制造“晚入场更好或更差”的伪差异。

优化方向：

- 固定从实际入场日起算的持有日 `holdingDay = 1..N`。
- 保留固定事件日退出作为兼容口径，但不要把它作为跨入场日比较的主口径。
- 每个事件生成 `entryDay × exitDay` 收益面板，而不是只生成一个终点。

### 5.3 `T+10/T+20` 只是两个点，不是完整路径

同样的 `T+10` 收益可能来自：

- 稳步上涨；
- 先大幅回撤后反弹；
- 前 5 日上涨，后 5 日下跌；
- 多数时间横盘，最后两日拉升。

这些路径的风险和可执行性完全不同。

优化方向：

- 对每笔交易输出 `T+1..T+20` 的逐日净收益曲线。
- 输出持有期 MFE、MAE、首次 `+2%/-2%/+5%/-5%` 到达日和峰值日。
- 增加路径分类：单调上涨、先跌后涨、先涨后跌、持续弱势、震荡。
- 对每个分组输出收益曲线，而不是只输出 `T+10/T+20` 两个终点。

### 5.4 固定 `T+20` 很容易被少数极端值污染

平均值会被少数暴涨样本拉动，中位数和 Bootstrap 区间通常更可靠。当前结果已经多次出现“平均为正、中位为负”。

优化方向：

- 始终并列输出均值、中位数、胜率、分位数和日期聚类 Bootstrap。
- 增加去除最高 5% 后的均值。
- 增加按年度和市场状态分层的退出曲线。
- 不把 `T+20` 的平均收益单独作为策略通过条件。

### 5.5 收盘退出不一定可成交

固定 `T+10/T+20` 默认都退出在收盘，但没有完整处理收盘涨跌停、停牌和下一可卖点。

优化方向：

- 固定收盘退出时检查 `canSellAtClose`。
- 不可卖时进入下一可卖开盘或下一可卖收盘。
- 同时输出“理想收盘退出”和“真实可执行退出”的差异。

## 6. 建议的新实验

### E1：入场对齐的退出视界曲线

状态：已实现为 `first-board-pullback/body-filtered-exit-curve-study`。

已完成运行：

- v4：`RUN-20260922-5B2359E0`
- v3：`RUN-20260922-F75FC7FC`，使用 `100` 次 Bootstrap 诊断重跑

核心结果：

- v4 实体 `1%~2%` 在 `T+10` 平均净收益约 `+1.16%`，日期聚类区间不跨 0；
- v3 同组 `T+10` 平均净收益约 `-0.35%`，区间跨 0，信号未复现；
- v3 其余实体桶在 `T+10/T+20` 也没有稳定正值；
- 因此实体过滤可以作为风险控制，但当前证据不支持据此建立正收益策略。

首板日固定过滤：

- 默认排除一字板 `O=H=L=C=涨停价`；
- 默认要求实体高度 `(close-open)/previousClose >= 0.1%`；
- 实体高度继续按固定桶分组，防止只输出一个被挑出来的阈值。

目的：替代单点 `T+10/T+20` 解读。

输出：

- `entryDay` 对齐的 `holdingDay=1..20`；
- 每个持有日的均值、中位数、胜率、P5/P25/P75/P95；
- 日期聚类 Bootstrap；
- MFE、MAE、峰值日、谷值日；
- 同一 `commonSample` 下的曲线；
- 不选择最佳退出日。

优先级：P0。
