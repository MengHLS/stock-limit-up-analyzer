# RESULT-TREND-POOL-RIGHT-TAIL-001

> 目标：从“有限股票池中出现大涨股票的概率与右尾捕获”角度，重新评价首板回撤池及各固定状态。
> Dataset: `first_limit_pullback` / `datasetVersionId=660001`。状态形成：T+5 收盘；严格 PIT。未修改 3F、未做 Top3、未搜索参数、未创建 Candidate。

## 0. 固定口径与解释边界

- 状态定义完全沿用既有研究，不根据结果调整：
  - 完整首板回撤池：全部 T+5 可评估事件。
  - B 趋势池：`close(T+5) >= MA10(T+5) && close(T+5) >= MA20(T+5)`。
  - 深度回撤池：`D20 = close(T+5)/MA20(T+5)-1 < -10%`。
  - 深度回撤 + MA20 DOWN：`D20 < -10% && MA20Slope = MA20(T+5)/MA20(T+1)-1 <= 0`。
  - 深度回撤 + MA20 UP：`D20 < -10% && MA20Slope > 0`。
  - 过度上偏：`D20 >= +10%`。
- 入场统一按 **T+6 开盘** 建仓；累计收益节点为 T+6/T+7/T+8/T+9/T+10/T+15/T+20 收盘，扣除单边往返 20bps。
- `+3%/+5%/+10%/+20%/+30%` 为 **T+6 至 T+20 盘中最高价触达率，未扣成本**。这是“碰到过”的概率，不等于按收盘持有的实现收益。
- 失败率定义为 T+20 净收益 `<= 0`；5% 止损触达定义为 T+6 至 T+20 任一盘中 low `<= T+6 open * 95%`。
- P75/P90/P95 是各事件 T+20 净收益的横截面分位；MFE/MAE 是 T+6 至 T+20 的盘中最大有利/不利波动，未扣成本。
- 右尾贡献同时给出两种分母：正收益总额，以及 T+20 净收益总和。后者在总收益为负或小于头部赢家收益时不是边界在 0~100% 的“份额”，只应作为集中度诊断。
- T+20 是 Dataset post 最大可用绝对相对日，不是 T+5 之后的完整 20 个交易日。

捕获倍数 = “该池命中的目标股票占完整池目标股票的比例 / 该池样本占完整池比例”。

- B 趋势池缩至完整池的 55.39%，对 +10%/+20%/+30% 的捕获倍数约 1.01x / 1.01x / 1.02x。它几乎没有损失大涨股票，但也没有把大涨股票比例显著提高。
- 深度回撤 + MA20 DOWN 只占完整池 3.08%，却捕获完整池 +10%/+20%/+30% 命中股票中的 3.71% / 4.24% / 4.09%，捕获倍数分别 1.20x / 1.38x / 1.33x。
- 过度上偏占完整池 22.33%，对 +30% 的捕获倍数为 1.42x，大于深度回撤 + MA20 DOWN 的 1.33x；但该池的整体失败率与左尾也更差。

## 10. 最终回答

### 1. 哪类股票池最容易出现 +10% / +20% / +30% 大涨？

- **+10% 与 +20%：深度回撤 + MA20 DOWN 最高**，命中率分别为 52.96% 与 27.18%；深度回撤池次之。
- **+30%：过度上偏最高**，为 13.63%，略高于深度回撤 + MA20 DOWN 的 12.76%。但它同时是左尾最差的池之一。
- 若以“右尾概率 + 失败率/PF”综合评价，深度回撤 + MA20 DOWN 优于过度上偏；若只问 +30% 触达，过度上偏更极端。

### 2. 哪类股票池虽然平均收益一般，但右尾明显更强？

过度上偏符合“平均收益一般、右尾更厚”的描述：T+20 均值 -1.51%，但 P90 18.71%、P95 29.91%、+30% 命中 13.63% 均不低。然而 MAE 均值 -12.46%、5% 止损触达 78.39%，说明它是双向厚尾，而不是干净的右尾来源池。

### 3. 哪类状态能在缩小股票池的同时，不明显损失大涨股票？

- **B 趋势池**：样本缩至 55.39%，+10%/+20%/+30% 捕获倍数接近 1，几乎按比例保留大涨股票；但没有提高大涨股票密度，且 T+20 均值和失败率更差。
- **深度回撤 + MA20 DOWN**：样本仅 3.08%，但 +20% 捕获倍数 1.38x、+30% 捕获倍数 1.33x，是“大幅缩池后仍保留较高右尾密度”的最强组。
- 因本轮不基于结果反向选阈值，以上是对两个既有固定状态的性质评价，不构成新参数选择。

### 4. 当前策略真正应该优化的是“平均收益”还是“捕获右尾收益的概率”？

两者不能二选一，但当前证据表明：在持仓数量受限时，**右尾命中概率应进入核心目标函数，平均收益和左尾约束必须同时保留**。

原因是完整池 +10% 盘中触达率已达 43.99%，但 T+20 净收益均值仍为 -0.61%，失败率 57.88%。这说明“碰到大涨”并不自动等于“捕获大涨”。真正应优化的是在可控回撤/止损约束下的右尾捕获概率，而不是单独最大化平均收盘收益，也不是只统计盘中触达率。

### 5. 是否可以形成“趋势池”和“回撤反弹池”两个不同的候选股票池？

可以，但二者职责不同，且本轮不创建 Candidate：

- **趋势池（B）**：适合作为宽股票池筛选器，作用是保留与全池近似的大涨股票覆盖；当前证据不支持把它描述成质量增强器，因为其平均收益与失败率并未改善。
- **回撤反弹池（深度回撤 + MA20 DOWN）**：更适合作为独立右尾研究池。它以约 3.08% 的样本占比，显著提高 +10%/+20% 命中密度，并改善 T+20 均值、PF 和失败率；但正收益仍高度依赖头部事件，且 2020/2023 的结构不稳定。
- 过度上偏不宜归入上述两类候选池：它可以作为“极端右尾但有高左尾风险”的对照标签，不应因为 +30% 命中最高而直接交易化。
