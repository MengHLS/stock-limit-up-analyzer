## 5. 结论

- 首次转弱并不等于上涨结束；D+1/D+2/D+3 中恢复强状态的事件，其后续 MFE、最终收益和右尾保留明显不同于持续弱状态事件。
- 创新高恢复、收益恢复和收盘位置恢复都提供了比“单日转弱”更可解释的路径特征；这些特征只是状态恢复证据，不是组合交易条件。
- 延迟确认通常改善退出均值，但同时继续承担路径风险；是否值得延迟必须同时看 MFE、MAE、机会损失和年度稳定性。
- 本轮不选择最佳确认延迟，不将任何路径特征升级为 Exit 规则，不创建 Candidate。

### 5.1 关键量化结论

- MA10支撑转弱后，D+3 恢复率仅为 +10% 组的 41.04%、+15% 组的 33.71%。恢复组的后续 MFE 约为 12.00% / 11.97%，未恢复组仅 3.82% / 3.30%。
- 收益恢复在 +10% / +15% 组的 D+3 比例约为 73.56% / 73.22%；恢复组最终收益仍显著高于未恢复组，说明“首次转弱后收益再次为正”更偏向假衰竭。
- 连续收低由0转1后的恢复率约 88.01% / 85.40%，单次收低更像噪声；由1转>=2后的恢复率降至 45.02% / 40.41%，更接近持续恶化路径。
- 延迟确认会提高平均退出收益并降低机会损失，但 D+1~D+3 仍保留较高 lost20/lost30；延迟只是减少误杀，并不能消除误杀。

## 6. 最终判断

真正接近上涨衰竭的，不是首次 Runner 转弱本身，而是首次转弱后无法恢复强状态、无法重新创新高、收益持续为负或收盘位置持续恶化。由于本轮禁止组合条件，只能确认这些单变量路径的方向；后续若要形成 Exit 规则，必须另行立项验证二次确认结构。
