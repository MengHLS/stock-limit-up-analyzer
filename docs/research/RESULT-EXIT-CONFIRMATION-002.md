# RESULT-EXIT-CONFIRMATION-002

> 目标：研究深度回撤反弹池在达到 +5%/+10%/+15% 后，预先固定的因果“趋势破坏信号”能否减少利润回吐并尽量保留大赢家。
> Dataset: `first_limit_pullback` / `datasetVersionId=660001`。固定池：`D20 < -10% && MA20Slope <= 0`；T+5 收盘形成股票池，T+6 开盘入场，T+6~T+20 研究。未修改首板定义、3F、Top3、仓位或现有策略；未创建 Candidate。

## 0. 固定口径

- 固定池 1,505 个事件；具备完整 T+6~T+20 OHLC 的 1,484 个事件进入路径研究，排除 21 个不完整事件。
- 盈利激活：首次盘中 high 达到 `entry * (1 + activation)`。六个信号只在激活日之后的下一交易日开始检测。
- 破前1日低、破前2日低、破前3日低：开盘跳空低于阈值时按开盘价成交，否则 low 触达阈值时按阈值价成交。
- 连续2日收盘下降：当 `close_t < close_{t-1} < close_{t-2}` 时按当日收盘退出。
- 收盘跌破 MA5 / MA10：MA 为截至当日的简单移动平均；close 低于 MA 时按当日收盘退出。
- 若信号在 T+20 前未触发，则持有到 T+20 收盘。所有实现收益扣 20bps。
- “退出前峰值回撤”使用退出日之前的最高 high；不使用退出后的未来高点。
- “MFE-退出收益(pp)”是全局 MFE 与实现净收益之间的百分比点差，包含“峰后回吐”和“过早退出导致放弃的后段上涨”，因此不是单纯的实现回撤。
- “保留率”分母是全局 MFE 达到对应大涨门槛的事件，分子是策略退出 gross return 也达到该门槛的事件。
- 本轮是固定的 6 信号 × 3 激活状态描述性对照；不新增阈值、不组合信号、不按结果择优。

## 6. 重点问题回答

### 1. 哪类“趋势破坏”最能减少利润回吐？

需要区分“退出时距最近前高的回撤”和“放弃未来峰值利润”：

- 按退出前峰值回撤，`跌破前1日低点` 通常离最近前高最近，其次是 `收盘跌破MA10`；它们的即时回撤较小。
- 但它们更早结束仓位，导致全局 MFE 到退出收益的缺口更大。所有六信号在三个激活组中的 `MFE-退出收益(pp)` 均值都没有优于固定 T+20 基准。
- 因此不能把“退出时点回撤更小”解释为“总利润保持更好”。真正较平衡的是 `连续2日收盘下降`：它退出较晚、均值在六个信号中通常最高，+10% 组的捕获率也较高，但它仍低于固定 T+20 的同条件均值。

### 2. 哪类最容易过早卖出？

`跌破前1日低点` 最容易在全局峰值之前退出：+5%/+10%/+15% 激活组中，退出早于全局峰值的比例分别约 54.95% / 46.25% / 39.97%。`收盘跌破MA10` 在 +10%/+15% 组中退出更晚，较早退出比例分别约 19.70% / 10.03%；但在 +5% 组中它仍可能较早触发。

### 3. 大赢家能否保留？

可以部分保留，但损失明显：

- +5% 激活组中，`连续2日收盘下降` 的 +20% / +30% 保留率约 32.84% / 23.40%，是六信号中最高的；`跌破前1日低点` 仅 16.67% / 8.51%。
- +10% 激活组中，`连续2日收盘下降` 的优势仍然存在；+20% / +30% 保留率约 36.82% / 25.53%。
- +15% 激活组中，`收盘跌破MA10` 的 +20% / +30% 保留率更高，约 40.80% / 29.26%。
- 但没有任何信号能把 +30% 大赢家保留率提高到 30% 以上；晚期大赢家仍大量丢失。

### 4. 当前最值得继续研究的是“固定止盈”还是“趋势破坏退出”？

当前证据更适合表述为：**“达到盈利状态后的趋势破坏退出”比“达到目标立即固定止盈”更值得研究，但还没有证据支持直接采用固定百分比回撤或单一破位信号。**

原因是：

- 在 +5% 后，立即固定 +5% 退出的净收益约为 4.80%，六信号平均退出收益大多高于这一水平。
- 在 +10% 后，立即固定 +10% 退出的净收益约为 9.80%，六信号大多高于这一水平。
- 在 +15% 后，立即固定 +15% 退出的净收益约为 14.80%，六信号多数接近或高于这一水平，且部分信号保留了更多大赢家。
- 但与固定 T+20 对照相比，所有信号在 +5%/+10%/+15 条件样本的整体均值均偏低，且年度方向不稳定。

因此，下一步值得研究的是“利润奔跑 + 收盘确认的趋势破坏”，尤其是较慢的 MA10/连续两日下跌确认；不应把任何单一破前低信号直接升级为 Candidate。

## 7. 结论边界

- 未修改首板回撤定义、3F、仓位、TopN、exit 或成本。
- 六个信号全部预先固定；没有搜索退出阈值或组合信号。
- 连续下跌和 MA 破位采用收盘确认；破前低信号采用盘中触价并按固定成交假设执行。
- 退出早于全局峰值的比例、MFE-退出收益缺口和保留率均表明：退出信号确实存在提前卖掉大赢家的风险。
- 2019-2026 结果不具备稳定一致优势，不能从年度子样本反向选择信号。
- 本轮不创建策略版本或 Candidate。
