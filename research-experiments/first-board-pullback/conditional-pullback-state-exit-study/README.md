# 首板后条件入场与动态退出状态机研究

## 冻结规则

### 入场

- 只看 `T+1..T+5`。
- 一旦某日收盘跌破首板开盘价，则本轮不再入场。
- 首次出现收盘价不高于 `首板收盘 × (1 - 100bps)` 时，视为回撤触发。
- 触发后次一交易日开盘买入，要求可买。

### 退出

- 买入后逐日检查收盘价。
- 若收盘价跌破首板开盘价，则下一可卖开盘退出。
- 下一开盘若跌停不可卖，则继续向后寻找可卖开盘。
- 若最迟窗口内无法按开盘退出，则回退到 `T+10` 收盘退出。
- 未触发动态退出的交易持有到 `T+10` 收盘。

## 对照

- `BASELINE`：`T+1` 开盘买入，`T+10` 收盘退出。
- `CONDITIONAL_FIXED`：条件入场，固定 `T+10` 收盘退出。
- `CONDITIONAL_DYNAMIC`：条件入场，动态退出。

动态退出只有同时优于条件买入固定退出和 `T+1` 固定基准，才有继续研究价值。

## 已知偏差

- 只使用日线；下一开盘卖出以开盘价是否触及跌停价判断可卖性。
- 未实现盘口排队、滑点、部分成交、整手和公司行为。
- 属于探索性研究，不能替代独立 Holdout。
