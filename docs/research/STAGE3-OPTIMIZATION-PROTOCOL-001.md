## 4. 接受 / 拒绝规则（**预声明，先定后测**）

一个改动 **仅当同时满足以下全部条件** 才被**接受**：

| # | 条件 |
|---|---|
| **A1** | **IS Calmar 提升 ≥ +0.02**（绝对，即 ≥ ~6% 相对） |
| **A2** | **IS MDD 不加深**（`\|MDD_IS\| ≤ \|MDD_baseline_IS\|`） |
| **A3** | **IS 正年份比例不下降** |
| **A4** | **IS 熊市年（基准下跌年）仍跑赢基准** |
| **A5** | **OOS Calmar 不恶化**（`≥ OOS_baseline_Calmar − 0.02`）—— **选定后才跑 OOS，且只跑一次** |
| **A6** | **单变量**：一次只改一项；同时改多项的对照**不作为接受依据** |

⇒ **任一不满足 ⇒ 拒绝**（Goal 原则 5：**先定位失败原因，不得为通过而反向修改研究口径**）

### 5.1 🔴 E2 之前的**已知约束**（来自 E1 的实测，避免重复无效方向）

**暴露放大是 Calmar 负向的**：E1 的 TOTAL 相对 **+9.2%**，而 MDD 相对 **+31%** ⇒ **MDD 增长约为收益的 3.4 倍** ⇒ **任何「均匀放大暴露」的方向都可预期为 Calmar 负向** ⇒ **不再重复该方向**。

⇒ E2 因此选择**「降暴露」的非对称方向**（仅在市场下跌时**减少新开仓**），与 Alpha 来源（熊市防御）**同向**，而非反向。

## 6. 测量口径（**与方法一致，不得偏移**）

| 项 | 口径 |
|---|---|
| 年度收益 | **(B) 严格口径** `eq[last of y] / eq[last of y−1] − 1` |
| Calmar | `CAGR ÷ \|MDD\|`（CAGR 按 365.25 日年化） |
| Sharpe | `CAGR ÷ (日收益标准差 × √252)`，**rf = 0** |
| MDD | running-peak 最大回撤（**已修正**，见 `RESULT-OOS-WFA-002` §2） |
| 基准 | `000300.SH` · `index_daily` **同段同期** |
| 成本 | 往返 **20 bps**（不变） |
| 数据源 | **全期单跑 + 离线切段**（避免段界截断伪影，见 `OOS-WFA-CRITERIA-001` §6） |
