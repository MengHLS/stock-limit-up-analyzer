## 9. 关键发现（Findings）

### F-1 没有任何因子达到 A / B（0/20）

按预注册判据，**没有一个因子同时满足**：全历史单调 **且** ≥2/3 时期方向一致 **且** 去最高最低 1% 截尾与每股每年去重后同号。Gate = `NO_MONOTONE_FACTOR_FOUND`。

### F-2 跨因子高度一致的倒 U（INVERTED_U）结构（11/20 判 C）

T+3 / T+5 / T+10 上，**中段 Q2–Q4 的未来收益最高、最高端 Q5 最差、最低端 Q1 次差**。这不是个别因子的现象，而是贯穿动量（ret_*）、均线斜率（ma5_slope）、振幅（amp5/amp20）、换手（turnover_T / turnover_ma5）、量能（vol_ratio）、波动（vol20）、日内位置（close_pos）的**共同形状**。

以 T+5 全历史为例（详见 §4 表）：Q3 普遍在 `+0.36% ~ +0.40%`，而 Q5 只有 `+0.02% ~ +0.16%`，Pool 为 `+0.287%`。**Q5 低于 Q2–Q4 均值** 在全部 20 个因子上成立（Q5−mid 为负，-0.10% ~ -0.34%）。

**读法**：池整体 T+5 是正收益（+0.287%），但"因子值最高的一批"（Top1%）是负收益。即：**在 RCP-P0-v1 内，越极端（越热、越强、越靠振幅顶部）的标的，T+1 开盘买入后的 T+N 收益越差**，且不是由单日噪声造成（t 值全部显著，T+10 更甚）。

### F-4 IC 方向在全历史 8/8 年为负的因子族

`ret_1/3/5/10/20`、`ma5_slope/ma10_slope`、`amp5/amp20`、`vol_ratio`、`volchg5`、`turnover_T/turnover_ma5`、`amt_ratio20`、`vol20` 的 Rank IC **正年数 = 0/8**（8 年全部为负），`dist_high20` 5/8、`dist_high60` 2/8、`dd20/dd60` 2/8、`close_pos` 1/8。

但按预注册规则，B（负单调）要求**分桶形状为单调递减**；这些因子的分桶形状是**倒 U**（Q1 低于中段），因此**只能判 C，不能判 B**。这是刻意的规则约束，不是数据矛盾。

### F-5 IC 与分桶形状可能背离（必须同时看，不能只看 IC）

`dist_high20`（T+5 全历史）Rank IC ≈ `+0.0014`（几乎为零），但 Top−Bottom = `-0.334%`（t=-4.73）。原因是其负向关系**集中在最极端的上端**（Top1% -1.11%），中段之间几乎没有排序能力。**只看 IC 会漏判这种"尾部驱动"的结构；只看 Top/Bottom 又会忽略中段无区分度**——两者必须并列报告。

### F-6 T+1 上不存在任何结构（20/20 判 E）

T+1 收益（即 `Close(T+1)/Open(T+1)-1`，T+1 开盘到收盘）上：20 个因子全部判 E；`|IC| ≤ 0.029`，Top−Bottom 符号不一致（从 `-0.158%` 到 `+0.233%`）。**该倒 U 结构不是 T+1 的日内噪声，而是随持有期展开（T+3 起出现，T+5/T+10 稳定）。**

### F-7 与 RANKING-ALPHA-RESEARCH-001 的结论一致且更一般

既有研究（VCB / BB / PR 三个行为强度分）已发现"分数越高、未来收益越低"。本轮把同一现象扩展到 **20 个预注册量价因子**，并给出更精确的形状刻画：**不是单调反向，而是倒 U——最高端最弱、中段最好**。

| 检验 | T+5 全历史结果 |
|---|---|
| 去最高/最低 1% 截尾 | Top−Bottom 仍为负：`-0.180% ~ -0.489%`（20/20 保持负号） |
| 上下 1% 缩尾 | 同上，`-0.178% ~ -0.489%` |
| 每股每年去重 | 更负：`-0.125% ~ -2.432%`（小样本极端桶权重被放大） |
| 连续命中压缩命中率 | ≈ `49.9% ~ 50.0%`（正 run / 总 run），说明 Top−Bottom 日度符号**无持续性** |

**含义（重要）**：该倒 U 结构是**平均意义上的横截面偏移**，不是"每天都能命中"的方向性信号。任何据此构造的策略都会面对约 50% 的日度命中率、以及微弱的日均价差（<0.5%），在计入 A 股 T+1 交易成本前就不具可行性。这正是预注册规则把 U / 倒 U 定为"仅记录结构、不作为策略"的原因。

## 10. 限制与风险（必须随结论一起读）

1. **未做交易成本 / 滑点 / 涨跌停可成交性建模**。Top1% 极端桶在 T+1 开盘常常是涨停开盘或大幅跳空，实际不可成交概率高；本轮只按"T+1 是否存在 bar 且 Open>0"剔除（全历史 4,368 个证券日剔除），**不构成可交易性验证**。
2. **IC 与分桶形状可能背离**（见 F-5），单一指标会误导。
3. **每股每年去重的量级不可与日度均值直接比较**：前者对每个 (证券,年份) 等权，极端桶中少数高波动证券被放权，故数值更大（-0.13% ~ -2.43%）。
4. **60 日窗口因子存在数据边界**：`stock_daily_prices` 与基准日历均自 `2019-01-02` 起（DB 实测 `MIN(tradeDate)=2019-01-02`，`tradeDate<2019-01-02` 为 0 行），故 `dist_high60` / `dd60` 只有 **1804** 个交易日（2019-04-02 起），其余 18 个因子为 1843 个。**缺 39 天如实保留为不评估，未补值、未前推。**
5. **未做行业 / 市值中性化**（本轮禁止 Composite 与任何调参）。倒 U 可能部分是"小市值/高换手"这一风格因子的代理，本轮无法区分。
6. **绝对收益水平受市场 beta 影响**：Pool 的 T+5/T+10 平均收益为正（+0.287% / +0.489%）是 2019–2026 A 股主板的样本内事实，不是可外推的基准。
7. **单日横截面样本量大（~1900–2800）**，因此 t 值很容易显著；**统计显著 ≠ 经济显著**，本轮的 |Top−Bottom| 普遍 < 0.55%。
8. ST / 停牌过滤依赖 `research_security_status_history`，其 `retrievedAt` 为 2026-09 的存量快照（RCP-P0-v1 已记录的既有 caveat），本轮沿用未改动。
