## 3. 冻结规则（唯一信号求值实现）

### 3.1 共同条件（沿用 003）

首板定义、主板、**事件日非 ST**、上市 ≥365 自然日、最早未过期锚点均沿用 003。
后续涨停**不刷新**锚点或期限。相对日取锚点实际交易日。池仍观察 **rd1..40**，但**确认日最多 rd19、实际成交最多 rd20**。
到期后只观察、不新买，**不无限延期**。确认日收盘产生信号，**次一交易日开盘**执行。
观察数据只用当日及以前；确认日前确实发生过 `C_j < C_0` 的回撤。
仍持仓不加仓；**全部真实平仓后**，由**新收盘信号**才可再次入场；交易成本、持有期及退出状态**重新计算**。
平仓**不清除**首板日期、历史风险、ST 状态或买入截止日。

### 3.2 A 与 B 的未破位分支

复用 `research-experiments/shared/rollingPoolEarlyEntry/entry.ts#evaluateEarlyEntry` 的 **003 N=5 / L=20** 语义
（调用 `{ observationDays: 5, entryFillMaxRd: 20 }`，**不重写**）：

```
S_j = 1[L_j ≥ 0.98·O_0] + 1[V_j ≤ 0.5·V_0] + 1[L_j ≥ L_(j−1)] + 1[C_j > C_(j−1)]
```

全程支撑不破、**前五日每一天 S ≥ 3**、确认日 `C` 高于前两日 `H`、`V` 不低于前日 `V`、必要数据有效。
A 在**历史首次可靠破位**后永久停用该锚点；B 只停原分支，进入修复观察。

### 3.3 B 破位后的局部修复分支（冻结）

首次可靠 `L_t < 0.98·O_0` 时进入 `RECOVERY_WATCH`，记录破位日与局部低点 `p = t, F = L_t`，
**不删池成员**。之后每个有效交易日，若 `L_t < F`，更新 `p = t, F = L_t`，**重新积累**修复观察。
（`p` 是**截至当日**的低点记录，不是事后确认的最低点。）

日 `d` 触发修复买点须**同时**满足：

| # | 条件 |
|---|---|
| 1 | `d ≤ 19`；前五个观察日 `W = [d−5, d−1]` **全部在最新低点 p 之后**（`d−5 > p`）；按实际交易日连续；日 `d` 也有效 |
| 2 | `W` 五日均有**有效 OHLC、正成交量**及所需前日比较值；**停牌、缺行、零量不能跳过拼接**。不可评估日**中断本次观察**；下一有效日建立**新的局部观察段与低点基准**并重新积累五日，**保留历史缺口及破位记录** |
| 3 | `W` 及日 `d` 都**没有低于局部低点 F**。若日 `d` 创更低点 ⇒ 先更新 `p/F`、回到观察、**不发信号**；**与 F 相等不算创新低** |
| 4 | `Q_j = 1[L_j ≥ F] + 1[V_j ≤ 0.5·V_0] + 1[L_j ≥ L_(j−1)] + 1[C_j > C_(j−1)]`，**ΣQ_j ≥ 15（满分 20）**。报告四项原始值与总分；**不要求每一天 Q ≥ 3**。该综合分是**观察证据，不参与横截面排序** |
| 5 | 确认日 `C_d > max(H_(d−2), H_(d−1))` 且 `V_d ≥ V_(d−1)`；确认日**不受缩量评分门限制**；确认日前回撤已经发生、当日**非 ST**且因子可评估 |

**无需收复 `0.98·O_0`**。破位后的参考支撑来自已观察到的局部低点；`F` **不作为持仓退出价**，退出仍用冻结 Runner 政策。

### 3.4 状态分离（冻结）

分开记录并在产物中各自成列：

- `priceState` ∈ `ORIGINAL_WATCH | RECOVERY_WATCH | RECOVERY_MATURE | SIGNAL_FORMED | EXPIRED`
- `buyEligibility` ∈ `NORMAL | ST_BLOCKED | UNKNOWN_BLOCKED`
- `positionState` ∈ `空仓 | 持仓`

**ST 或账户容量不能抹掉价格观察历史。** `repairEpisodeId = anchorEventId + p` 用于追踪，**不是**新锚点或新期限。
新低可开启下一修复段；新信号可**再次参与**，是否成交由账户决定。

## 4. ST 硬闸门与数据来源（冻结口径）

### 4.1 时点

| 时点 | 检查 | 不通过 |
|---|---|---|
| **资格**（确认日收盘） | 历史 NORMAL ⇒ 允许；`ST`/`*ST` ⇒ 拒绝候选；**未知 ⇒ 拒绝** | 不进候选、不进排序 |
| **执行**（真实成交前） | 再次检查；**隔夜转 ST 取消订单** | 不成交、**不扣现金**、**不计入场**、**不自动换成第 4 名** |

**首次、重试、再次入场，以及 R / Random 全部使用同一闸门。**

### 4.2 来源与 PIT 口径

- ST 源**必须经平台数据服务/契约供给**；实验函数**不直接 SQL**、不绕过 Dataset 端口。
- 判定按**状态生效时间**及**公告可获知时间**；**不得**把近期 `retrievedAt` 当历史公告时间，
  **不得**把收盘日线状态当开盘前公告，**不得**用今天的名称回填历史。
- **不得**依赖 `canBuyAtOpen` 的涨跌停含义充当 ST 检查。
- 不可在**前日候选构造**中偷看次日状态。

### 4.3 🔴 当前不可用（S1 实测），故闸门默认拒绝

| 证据 | 实测 |
|---|---|
| ST 行可获知性 | 841 行 / 734 symbol，`availability` **全 `UNKNOWN`**；**窗口内可获知时间 = 0** |
| 采集时间 | 全部 `retrievedAt` ∈ 2026-09-06 ~ 09-09（窗口后约一年） |
| 数据集字段可靠性 | 窗口 366,910 检查格中 `limitRuleUp=5%` = **0**；平台 ST 历史判定**确属 ST** 的 948 格**全部 `limitRuleUp=0.1`、`canBuyAtOpen=1`** ⇒ **放行 ST 日** |
| 覆盖面 | 2,378 / 2,827（84%）窗口 symbol **无任何 ST 行** ⇒ absence ≠ NORMAL |

⇒ **无已验证 provider 时，闸门对所有候选返回 `UNKNOWN_BLOCKED`，并中止收益矩阵（`ST_COVERAGE_BLOCKED`）。**
**禁止**用「大面积 UNKNOWN 拒单导致的空仓结果」评价新买点。

### 4.4 未越界的说明

事件当天非 ST **不代替**动态检查；后来成为 ST **不反向删除**其先前事件或合法交易。
已持仓转 ST 时**禁止新增仓位**，继续已有退出及真实可成交约束；**本轮不另改强制退出政策**，风险单列。

## 6. 判据、统计与停止规则（冻结）

### 6.1 主比较

**`B_R − A_R`** —— 共同观察池锚点中，**至少一笔已完成净收益 ≥ +20% 的唯一锚点数及覆盖率**。

- **共同分母固定为两组共有且数据资格可核实的锚点宇宙**；**不用各组成交数作唯一分母**。
- **披露所有数据缺口及 ST 排除**；**不能按事后盈利改分母**。

### 6.2 同时报告

实际交易 ≥+20% 尾率、唯一股票命中数、≥50%/≥100%、单笔均值、**锚点整链净损益（扣全部试错成本）**、
账户复合收益/MDD、资金与容量、交易次数、持有期，以及**前 3/5 交易日的不利波动和收益**。
**新增买点与原买点分开画像**；账户收益必须**完整重放**，**不能把事后最高价差额加总**。

### 6.3 统计

- **固定 1000 次配对日期块 bootstrap**；`block20` 主、`block40` 敏感性；**95% 区间**。
- **覆盖指标**按共同锚点**首次进入观察池的日期**聚类；双方**同日历、同抽样索引**；**空日保留**。
- **交易/整链指标另按声明的入场日期键聚类**；**两者不得混用**。
- 逐年报告**相同靶**与账户收益；2024/2025 为已见探索窗口，**不是 OOS**。
- 无已核验、PIT 可用的市场状态标签时，**熊市效果为未验证**；**不事后择市场分段**。

### 6.4 判定规则（事前）

只有**同时**满足下列条件才可列为「待未见样本验证的候选」：

1. 两组各 **≥ 50 个独立命中锚点**；
2. 主/敏感性区间**下界 > 0**；
3. **逐年同向**；
4. 账户收益与风险**未显示相反取舍**。

否则 ⇒ **`INSUFFICIENT_EVIDENCE`** 或明确风险权衡。
**样本量不足不靠随机账户数补足**；42 账户完成即可报告，**不为取得正结论扩 seed / 参数**。

### 6.5 停止规则

- 不追加分组、不调阈值、不换年份、不挑 seed；
- `SMOKE` 只验工程正确，**不做收益筛选**；
- 所有工程闸门通过后，**STUDY 无论方向好坏均完整执行一次**；**完整矩阵不再先执行一遍当作预检**。

### 6.6 归因时点修正（本轮必做，来自归因 §14.2）

以**机会确认日**逐层输出：`ST → 价格状态 → 评分/突破 → 因子 → 排序 → 账户 → 成交 → 退出`。

- **机会日至少包括未触发观察日**，**不能只在已触发子集归因**；
- **只读截至该日的数据**；**机会日之后**的破位**单独标记**；
- 最高价标签**仅事后诊断**；
- 逐机会匹配实际成交日期，分开**未买 / 容量导致迟买 / 持仓内回吐 / 退出后上涨**；
- 记录峰值日期、退出后最大涨幅、持有期间不利波动；
- **不再用 rd19 末态解释早期机会**（修正归因 §14.2 的 `derivePrimaryRejection` 固定 rd19 缺陷）。

P1 排除桶输出靶画像；P2 尾部与均值并报；P3 入选边界四件套 + 破平键；P4 退出固定但仍报量级与观察局限；
