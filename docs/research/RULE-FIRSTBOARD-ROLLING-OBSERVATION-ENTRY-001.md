# RULE · 首板滚动池：连续观察评分后触发入场

> ID：`FIRSTBOARD-ROLLING-OBSERVATION-ENTRY-001`，版本0.1，2026-10-10。
> 状态：**首次提出的待验证规则**，不是历史实验结论，不保证有效。
> 用途：补充 [滚动池续研目标](GOAL-FIRSTBOARD-ROLLING-POOL-EARLY-ENTRY-RUNNER-002.md) 的入场层；保持已有池和固定退出方案。
> 本次只写规则与目标文档，不启动实验。后续用户明确要求执行本修订文档，即视为接受本轮冻结配置，不重复询问同一买点。

## 1. 交易假设与范围

本轮仅检验“首板后回撤，连续两日显示稳定，再出现局部突破确认”这一种路径。未回撤的连续上涨股票仍留观察池，但本轮不交易；结果不能推断追涨或其他入场路径无效。

每天收盘重新计算，买入日期由信号决定。实际买入最晚为锚点事件 T+10，故最晚确认日为 T+9。最早确认日为 T+3：先有两个完整观察日，再确认。T+4是最早可能成交日，不是固定买入日。

符号：首板锚点日为0，`O_d/H_d/L_d/C_d/V_d` 为该相对交易日的开/高/低/收/成交量。单位沿用Dataset，量比同单位相除。首板参考支撑位采用 `O_0`（首板日开盘价），不是低点、涨停价或MA；0.98容差为本轮冻结提案。

所有判断仅使用当日及之前的真实行情。不得使用未来最高价、完整未来路径、下一日能否成交或后来是否涨停决定当日资格。原 `maxAmp5` 在rd15才可得，本轮完全不参与入场及排序。

## 2. 每日观察分：四项各1分，总分0～4

| 分项 | 当日条件 | 解释 |
|---|---|---|
| 守线 | `L_d >= 0.98 * O_0` | 首板开盘支撑未明显失守 |
| 缩量 | `V_d <= 0.50 * V_0` | 相对首板日，成交量收缩 |
| 低点稳定 | `L_d >= L_(d-1)` | 当日没有继续创新低 |
| 收盘改善 | `C_d > C_(d-1)` | 收盘开始改善 |

`S_d` 为四项0/1之和，只从rd1开始计算。rd1的前一日为事件日rd0。每个分项单独存档；不只保留总分，避免总分掩盖路径差异。

**不累计从入池到现在的总分。** 临近确认日只看最近两个观察日 `S_(d-2)`、`S_(d-1)`，避免较老事件天然得分更高。

## 3. 入场触发：以下全部成立

确认日 `d` 必须在3～9之间，收盘后判断：

1. **确实发生过回撤**：存在 `j∈[1,d-1]`，满足 `C_j < C_0`。只按当时已知历史识别，触发当天不能才补足历史回撤条件。
2. **支撑全程未失守**：`min(L_1,...,L_d) >= 0.98 * O_0`。当日守线得1分还不够，之前已经跌破过的不能靠反弹重新通过。
3. **连续两日观察合格**：`S_(d-2) >= 3` 且 `S_(d-1) >= 3`；两日都必须是有效且非停牌的相邻交易日。
4. **当日突破确认**：`C_d > max(H_(d-2), H_(d-1))`，收盘严格高于前两个交易日高点。
5. **量能回升**：`V_d >= V_(d-1)`。确认日不再要求缩到首板日50%以下；观察期缩量与确认期量能回升分属不同阶段。
6. **时间与数据资格成立**：锚点仍有效，且有下一交易日可在锚点rd≤10执行。缺失 `preReturn10` 时R与Random共同不进入本轮排序，并记录缺失原因。同股已持仓、同锚点曾买入等各账户状态在排序后的账户执行层检查，不影响双方共同的原始买点候选池。

确认日可以是T+3、T+4……T+9。没有满足全部条件，就不产生新买信号，不为了凑每日名额买入。

## 4. 状态与失败处理

`OBSERVING`（观察）→ `ARMED`（已回撤、支撑未破且连续两日观察合格）→ `TRIGGERED`（局部突破和量能确认）→ `HELD`（真实买入）。

`ARMED` 每天重算，不永久锁定。最近两个观察日不再合格，则回到观察；不是“某天得分高了，以后任何一天都能买”。

- **支撑破位**：相对日1～9中一旦可靠低点低于 `0.98*O_0`，该锚点本轮早期入场资格为 `INVALIDATED_SUPPORT`，不恢复；原观察池成员保留。已有持仓的退出仍按固定退出方案，不额外新增此支撑卖出规则。
- **期限到达**：T+9之后不再产生新确认信号；已在T+9收盘形成的订单可T+10开盘执行。T+10后标 `ENTRY_EXPIRED`，继续观察而不新买。
- **缺失/停牌/零量**：涉及的观察日不打分为0，也不插值；分数为null并记录原因，当日不能满足连续两日条件。停牌或零量不得被当成“缩量优秀”。历史支撑路径缺失时不能声称全程未破位；该锚点本轮无法评估并明确记录。
- **拒单或未选中**：不视为成功建仓。不保留自动补买订单；之后只有重新满足全部触发条件且仍可T+10前成交，才允许再次参与排名。禁止买入失败后顺延到T+11。
- **同锚点重复**：一旦成功建仓，该锚点不再允许新买，平仓后也不重复；不同事件不绕过同股票持仓限制。
- **新首板**：沿用原最早未过期锚点，不刷新期限、支撑价、评分历史。锚点按旧池规则合法切换时才使用新事件坐标。

OHLCV必须满足已有结构有效性检查；必要字段非空、有限，价格与成交量为正，且不是真实停牌。原始价和公司行为口径沿用平台。若某事件观察期存在无法处理的价格断点，不凭空重写复权公式，单列口径缺口；先核验是否有PIT公司行为端口可复用。

## 5. 买点与排序、仓位的边界

观察分只决定阶段和触发资格，**本轮不以观察分与 `preReturn10` 混合加权排序**。这样能单独研究“相同买点下，已有因子的排序增量”。

触发候选分别按R（`preReturn10 HIGH`，原始值）或Random（同批候选均匀无放回）选最多3只，依已有账户约束每日最多新买2只、最多持有5只，每只目标预算为决策日收盘权益20%。排名变化不触发卖出。

下一日实际不可买时如实NO_FILL，不根据未来成交信息提前排除或递补。退出政策、成本、随机种子和统计判据全部沿用续研目标。T+10约束针对实际成交，不能只检查信号日。

## 6. 可直接实现的逻辑

```text
对每个当天有效的原滚动池锚点：
  记录当日S_d四个分项、回撤历史、支撑历史；保留所有拒绝原因
  若rd不在3..9：观察，不生成新买信号
  若必要历史缺失/停牌/零量：UNASSESSABLE，不生成信号
  若历史支撑破位：INVALIDATED_SUPPORT，不生成信号
  若无历史回撤，或前两日任一S<3：OBSERVING
  否则：ARMED
  若当日收盘突破前两日高点，且量能较昨日不减：TRIGGERED
  经过期限和因子可评估检查后，加入双方共同候选池
  分别排序/随机，再检查各账户同股持仓、同锚点曾买、空位和资金，计划下单
  下一交易日撮合且禁止rd>10的新买
```

前两日观察分比较中不得使用确认日分数代替，不能用“这三天事后看都好”反推昨天已触发。`ARMED`是解释状态，实际发信号必须包含全部第3节条件。

## 7. 事前冻结、样本账与检查

本轮只用：支撑98%首板开盘、缩量50%、四项等权、连续两日各≥3分、突破前两日高点、最晚T+10成交。都是研究假设，不是已证明最优参数。预检只验证执行与记账；结果差或样本少时如实收口，不改阈值补样本。

逐层报告日账、唯一锚点账及阶段转移：观察→曾回撤→支撑完整有效→两日合格→突破确认→排序入选→下单→成交→Runner→退出。各层排除原因与未来标签画像用于事后诊断，不能反向修改当时资格。无回撤、支撑破位、条件不足、期限过期、缺失分别记账；边界分辨力在**最终触发候选池**上重新检查，不能套用旧晚期池结果。

执行测试必须覆盖：得分高但不突破不买；突破但无两日历史不买；中间停牌不把两个有效日拼接成连续；确认日放量不被“50%缩量”误杀；破位后反弹不能恢复同锚点资格；T+9信号/T+10成交允许、T+10信号/T+11成交禁止；未来数据扰动不改变既有历史信号；权益涨跌使真实预算同比变化。

持续按回测收益挑选阈值会增加过拟合风险，故本轮冻结后不搜索；参见 [Bailey等，The Probability of Backtest Overfitting](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)。该研究支持实验纪律，**不提供上述阈值的有效性证据**。
