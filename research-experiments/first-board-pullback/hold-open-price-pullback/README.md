# 首板后回撤但不破开盘价交易研究

## 研究问题

首板事件 T0 之后等待一次温和回撤；如果等待期间从未跌破首板日开盘价，就在首次回撤后的
次一交易日开盘入场，并观察固定退出视界的收益。研究重点是：

- 有多少事件触发首次回撤；
- 有多少事件在入场前已经跌破首板开盘价；
- 触发日次一交易日是否可买；
- 入场后是否再次跌破首板开盘价；
- 固定退出视界的净收益，以及相对全首板 `T+1 开盘入场` 基准的差异。

## 默认口径

| 项目 | 默认值 |
|---|---|
| 等待窗口 | T+1..T+5 |
| 回撤触发 | `low <= eventClose × (1 - 100bps)`，同时 `low >= eventOpen` |
| 入场 | 触发日次一交易日开盘 |
| 失效 | T+1..触发日前 `low < eventOpen` |
| 退出视界 | T+10 / T+15 / T+20 收盘 |
| 成本 | 20 bps |
| 一字板首板 | 默认排除 |

## 不输出

- 最优回撤阈值；
- 最优触发日或退出日；
- 自动策略、参数推荐或排序；
- 将入场后破位直接当作已实现的止损成交。

## 已知边界

- 日线级可交易性只能表达开盘涨停不可买、收盘跌停不可卖、停牌与缺 bar；
- 未实现破位后的下一可卖点、滑点、冲击成本、整手与部分成交；
- 当前 Dataset 只覆盖沪深主板。
