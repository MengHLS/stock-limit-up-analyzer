# composite-runner-newhigh3-t74-carryover（P6 · 跨日候选池第一轮）

**目标**：验证前一日 top5 中未进入常规买入名额的候选，是否值得在下一日与新候选共同竞争。

## 口径

- 控制臂：top3 / 2 笔 / 5 仓，与 T74 现役完全一致；
- carry 臂：top5 / 2 笔 / 5 仓；
- fresh 前 2 名进入常规买入尝试，未进入者进入 pending；
- pending 保留原始 3F 分，与下一日 fresh 统一重排；
- margin=0.03：pending 必须比某只 fresh 高至少 0.03，才能插到该 fresh 前面；
- pending 最长保留 1 / 2 个决策日；
- 退出链、Runner NEW_HIGH_3 / 5 / 74、仓位、成本、数据集坐标全部冻结。

## 第一轮边界

- 这是 **intent-level carry**：source-run 不知道 simulator 实际成交回执；
- 不做新窗口重评分，避免同时改变“跨日”和“评分公式”两个变量；
- 正式策略版本、历史 Run、模拟器均不改。

### 结论：第一轮 REJECTED

- carry1/margin0 的 carry 成交本身略正（+3,130、1 笔 >=+50%），但组合收益从 151.10% 降到 99.35%、最大回撤从 43.30% 升到 55.41%；
- 加 margin 或延长到 2 日后，carry 成交净利转负，>=+50% 为 0；
- 三条 carry 臂都没有增加实现 >=+50% 的总笔数，控制臂仍是唯一最优；
- 原因是 pending 主要排挤 fresh 候选的资金与仓位，而不是补上空仓位；“跨日候选”在没有**新信息**的情况下，不具备独立 alpha。
