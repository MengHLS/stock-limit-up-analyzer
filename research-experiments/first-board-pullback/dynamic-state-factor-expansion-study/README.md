# 动态状态机扩展因子研究

固定动态状态机：

- `T+1..T+5` 首次回撤 100bps，且未跌破首板开盘价，次日开盘买入。
- 买入后跌破首板开盘价，下一可卖开盘退出；否则 T+10 收盘退出。

## 因子范围

### 同日横截面

- 换手率同日分位
- 振幅同日分位
- 实体高度同日分位
- 成交额同日分位

### 历史涨停行为

- `historicalLimitCount`：历史涨停次数。

### 执行与容量

- `T+1` 开盘缺口
- `T+1` 成交量 / T日成交量

## 未覆盖

- 连板高度历史、失败板恢复和更细的历史状态。
- 封单额、排队、开板次数、成交概率和滑点。

这些需要新的 Dataset / 分钟级或盘口数据。
