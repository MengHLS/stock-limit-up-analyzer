## 4. 时间尺度

**判定口径（预注册）**：每个持有期打分 `score = sig + (年+ ≥ 6) + agree`（各 1 分，满分 3）；
尺度得分 = 该尺度内持有的最高分；并列时比 `CI 下界`；再并列取**更短**尺度。
**不只看最高收益。**

| 持有 | `sig`（Top3 CI 下界 > 0） | 年+ ≥ 6 | `agree`（Top5 CI 下界 > 0） | **score** |
|:---:|:---:|:---:|:---:|:---:|
| H5 | ✅ | ❌ (5/7) | ❌ | **1 / 3** |
| H10 | ✅ | ✅ (6/7) | ✅ | **3 / 3** |
| H20 | ✅ | ✅ (7/7) | ✅ | **3 / 3** |
| H60 | ✅ | ✅ (7/7) | ✅ | **3 / 3** |

| 尺度 | 构成 | 最高分 | 最高 CI 下界 |
|---|---|---:|---:|
| SHORT | H5 | 1 | +0.118 |
| **MEDIUM** | H10, H20 | **3** | **+0.865** |
| **LONG** | H60 | **3** | **+2.055** |

> ### 🔴 最适合的时间尺度：**LONG（H60）**，**但 MEDIUM（H20）同等稳定，且实现成本低得多。**

**结论要点（任务书要求同时考虑 4 个维度）：**

| 维度 | SHORT (H5) | **MEDIUM (H10/H20)** | **LONG (H60)** |
|---|---|---|---|
| 显著性 | Top3 ✅ / Top5 ❌ | ✅✅ | ✅✅ |
| 年度稳定性 | 5/7 | 6/7 → **7/7** | **7/7** |
| Top3/Top5 一致性 | ❌ 不一致 | ✅ 一致 | ✅ 一致 |
| `ExcessMean` 随持有期 | +0.384 | +0.761 → +1.458 | **+3.041** |
| **判定** | ❌ **不足** | ✅ **同等稳定，持有期短 3×** | ✅ **幅度最大** |

⇒ **若只按 `ExcessMean` 幅度判 → LONG（H60）**；
⇒ **若同时考虑「同等稳定性下持有期越短越好」（资金周转、暴露时间、成本累积）→ MEDIUM（H20）是更优的实现选择**：

⇒ **SHORT（H5）明确不合格**（Top5 不同向、年度仅 5/7）。
⚠️ **不建议只报 H60 的 +3.041 而不提 H20 的同等稳定性** —— H60 的幅度部分来自**池在 H60 的负漂移更大**（随机基准 H60 = −0.503% vs H20 = −0.372%），即「躲开更多下跌」而非「选了更强的股票」。

### 5.1 🔴 一个重要的结构性发现

`MEAN-FACTOR-RESEARCH-001` 的结论是「均值与右尾是同一根轴的两端、22 格中 A ∩ B = ∅」。
**`amountPercentile` 是这条规律的一个【关键例外】**：

| 因子族 | 均值方向 | 该方向的尾部代价 |
|---|---|---|
| 振幅 / 换手族（`meanAmplitude` / `maxAmplitude` / `turnover` / `limitGap` …） | 显著正 | 🔴 **显著负**（`ExcessTCR50` 大幅为负 ⇒ **拿均值必须付尾部**） |
| **`amountPercentile` LOW** | **显著正** | ✅ **无显著代价**（`ExcessTCR50` ≈ 0，CI 跨 0） |

⇒ **`amountPercentile` 是唯一「两个方向都没有显著尾部信号」的因子**（`HIGH` 方向亦无：`ExcessTCR50` 不显著）。
⇒ 它**不是**「方差/彩票性选择器」；它更像**流动性/关注度代理**：低成交额分位组**整体分布上移 + 左尾变薄**，而右尾与池同级。
⇒ **这正是它能在 12 因子里脱颖而出的原因，也是本链上第一个「不与尾部冲突」的均值因子。**

## 7. 分类判定

**预注册判定树**（先定后用；只允许四个分类）：

```text
sig(h)    = Top3 ExcessMean > 0 且 日簇 95% CI 下界 > 0
agree(h)  = Top5 ExcessMean > 0 且 日簇 95% CI 下界 > 0
yp(h)     = 「Top3 ExcessMean > 0」的年份数（共 7）

stable(h) = sig ∧ agree ∧ yp ≥ 6
regime(h) = sig ∧ agree ∧ 4 ≤ yp ≤ 5
weak(h)   = ¬sig ∧ (Top3 或 Top5 的 ExcessMean 点估计 > 0)

MEAN_SIGNAL_STABLE           if ∃h: stable(h)
MEAN_SIGNAL_REGIME_DEPENDENT elif ∃h: regime(h) ∨ (sig(h) ∧ ¬stable(h))
MEAN_SIGNAL_WEAK             elif ∃h: weak(h)
NO_MEAN_SIGNAL               else
优先级：STABLE > REGIME_DEPENDENT > WEAK > NO_MEAN_SIGNAL
```

### 9.3 本轮最重要的意义

`MEAN-FACTOR-RESEARCH-001` 得出「12 因子的均值与右尾是同一根轴的两端，**A ∩ B = ∅**」。
本轮的独立验证发现 **`amountPercentile` 是这条规律的结构性例外**：

- 它不是「方差/彩票性选择器」（两方向都**无显著尾部信号**）——它更像**流动性 / 关注度代理**；
- 它**同时**做到：**均值显著上移**（+3.04 pp @H60）**+ 右尾不损**（`Lift` ≈ 1.02）**+ 左尾显著变薄**（−8.62 pp @H60）。

⇒ 这是整条研究链上**第一个不与尾部冲突的均值因子**。
⇒ 也是「**右尾 + 风险约束**能在同一因子上共存」的第一个正面证据 —— 与 `RIGHT-TAIL-SELECTION-RULE-001` 在 8 个尾部因子上的**全部失败**形成鲜明对照（那 8 个因子的尾部与均值严格对立）。
