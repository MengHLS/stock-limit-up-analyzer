## A. P0 缺陷定位结果

### A.1 缺陷本体（**单点错误，8 步排查收敛于此**）

```js
// ❌ 修复前
const ret = (o.exitPrice / o.entry) - cost;
cash += o.w * (1 + ret);

// ✅ 修复后
const grossRet = (o.exitPrice / o.entry) - 1;
const netRet   = grossRet - cost;
cash += o.w * (1 + netRet);
```

`exitPrice/entry` 是**价格比率**（均值 **0.9987**，恒为正），**不是收益率**。因此：
- `ret ≈ 1.0 − 0.002 = 0.998` **恒为正** ⇒ `winRate ≡ 1`、`avgLoss ≡ null`
- `cash += w*(1+ret)` 中 `ret` **已含本金** ⇒ 每笔重复计入 `w` ⇒ 累计虚增 `Σw = 6999×0.005 = 34.995`
- 净值 = `1 + Σ w×ret = 1 + 35.46 = 36.46` ⇒ 与旧报告 `totalReturn = 35.4559` **完全吻合** ⇒ **自证闭环**
