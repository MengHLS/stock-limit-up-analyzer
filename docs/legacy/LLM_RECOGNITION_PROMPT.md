# 股票涨停复盘图片 - LLM 识别指令详解

## 📌 概述

本文档详细说明了 `uploadAndRecognize` 接口中 LLM 使用的识别指令、规则和数据格式。这些指令用于指导 LLM 从涨停复盘图片中准确提取股票数据。

---

## 🎯 核心识别任务

LLM 需要完成以下任务：

1. **识别涨停日期** - 从图片中提取日期（格式：YYYY-MM-DD）
2. **识别股票列表** - 提取所有涨停股票的信息
3. **提取股票属性** - 获取代码、名称、时间、板数等
4. **分类题材** - 判断股票所属的题材/板块
5. **提取关键词** - 识别涨停的驱动因素

## 📝 系统指令（System Prompt）

### 完整指令

```
你是一个专业的股票数据识别助手。请分析用户提供的股票涨停复盘图片，提取其中的股票信息。

请严格按照以下JSON格式返回数据：
{
  "date": "图片中的涨停日期，格式为YYYY-MM-DD",
  "stocks": [
    {
      "stockCode": "股票代码，如002361.SZ",
      "stockName": "股票名称",
      "limitUpTime": "涨停时间，如14:56:30",
      "boardCount": "板数，如10天9板",
      "circulationValue": "流通市值（亿元）",
      "turnover": "成交额（亿元）",
      "sector": "所属题材分类",
      "keywords": "涨停关键词"
    }
  ]
}
```

### 指令设计理由

- **角色定位**：明确 LLM 的专业身份，提高识别准确性
- **输出格式**：指定 JSON 格式，便于后续数据处理
- **字段示例**：提供具体示例，减少歧义
- **单位说明**：明确各字段的单位和格式

## 🔍 详细识别规则

### 1. 涨停日期识别

#### 格式要求
- **格式**：YYYY-MM-DD
- **范围**：2020-01-01 至 2030-12-31
- **示例**：`2026-03-04`、`2025-12-31`

#### 识别位置
- 通常在图片标题或顶部
- 可能显示为 "2026年3月4日"、"2026/03/04"、"2026-03-04" 等格式
- 需要转换为标准格式 YYYY-MM-DD

#### 处理规则
- 如果图片中有明确日期，使用该日期
- 如果日期不清晰，尝试从文件名或其他线索推断
- 如果无法确定，返回 null（但通常图片会包含日期）

#### 示例

| 图片中的日期 | 识别结果 |
|------------|---------|
| 2026年3月4日 | 2026-03-04 |
| 2026/03/04 | 2026-03-04 |
| 03-04 | 2026-03-04（假设当前年份） |
| 明天 | null（无法确定具体日期） |

---

### 2. 股票代码识别

#### A 股代码规则

| 市场 | 代码范围 | 后缀 | 示例 |
|------|---------|------|------|
| 深圳主板 | 000000-000999 | .SZ | 000858.SZ |
| 深圳创业板 | 300000-300999, 301000-301999 | .SZ | 300750.SZ, 301001.SZ |
| 深圳科创板 | 688000-688999 | .SZ | 688111.SZ |
| 北交所 | 920000-929999 | .BJ | 920000.BJ |
| 上海主板 | 600000-600999, 601000-601999 | .SH | 600000.SH, 601988.SH |
| 上海科创板 | 688000-688999 | .SH | 688001.SH |

#### 识别步骤

1. **提取代码**：从图片中找到 6 位数字代码
2. **判断市场**：根据代码范围判断所属市场
3. **添加后缀**：根据市场添加相应后缀
4. **验证格式**：确保格式为 `XXXXXX.XX`

#### 常见错误及修正

| 错误格式 | 正确格式 | 说明 |
|---------|---------|------|
| 002361 | 002361.SZ | 缺少后缀 |
| 002361.sz | 002361.SZ | 后缀应为大写 |
| 2361.SZ | 002361.SZ | 代码不足 6 位 |
| 002361SZ | 002361.SZ | 缺少点号 |

### 3. 股票名称识别

#### 要求
- 必填字段
- 中文名称，通常 2-6 个字符
- 从图片中直接提取

#### 示例

| 代码 | 名称 |
|------|------|
| 002361.SZ | 神剑股份 |
| 600000.SH | 浦发银行 |
| 000858.SZ | 五粮液 |
| 688111.SZ | 金山办公 |

---

### 4. 涨停时间识别

#### 格式要求
- **格式**：HH:MM:SS（24 小时制）
- **范围**：09:30:00 ~ 15:00:00（A 股交易时间）
- **可选字段**：无法识别时设为 null

#### 识别规则

- **开盘时间**：09:30:00（集合竞价结束）
- **午间休市**：11:30:00 ~ 13:00:00（无交易）
- **收盘时间**：15:00:00（交易结束）

#### 示例

| 图片中的时间 | 识别结果 | 说明 |
|------------|---------|------|
| 14:56:30 | 14:56:30 | 标准格式 |
| 14:56 | 14:56:00 | 补充秒数 |
| 下午2:56 | 14:56:00 | 转换为 24 小时制 |
| 14时56分 | 14:56:00 | 转换为标准格式 |
| 不详 | null | 无法识别 |

---

### 5. 连板数识别

#### 格式要求
- **格式**：`N天M板`
- **N**：连续交易天数
- **M**：涨停板数
- **可选字段**：无法识别时设为 null

#### 识别规则

- **首次涨停**：`1天1板`
- **连续涨停**：`N天N板`（通常连续涨停时相同）
- **非连续涨停**：`N天M板`（M < N，表示中间有未涨停的交易日）

#### 示例

| 图片中的信息 | 识别结果 | 说明 |
|------------|---------|------|
| 10天9板 | 10天9板 | 标准格式 |
| 10连板 | 10天10板 | 转换为标准格式 |
| 连板9天 | 9天9板 | 转换为标准格式 |
| 首板 | 1天1板 | 首次涨停 |
| 信息不详 | null | 无法识别 |

---

### 6. 流通市值识别

#### 格式要求
- **单位**：亿元（CNY）
- **格式**：纯数字或小数
- **可选字段**：无法识别时设为 null

#### 识别规则

- 从图片中提取流通市值数值
- 确保单位为亿元
- 如果单位为其他（如万元、百万元），需要转换

#### 示例

| 图片中的信息 | 识别结果 | 说明 |
|------------|---------|------|
| 116亿 | 116 | 直接提取 |
| 116亿元 | 116 | 去掉单位 |
| 1160000万 | 116 | 转换为亿元 |
| 市值不详 | null | 无法识别 |

---

### 7. 成交额识别

#### 格式要求
- **单位**：亿元（CNY）
- **格式**：纯数字或小数
- **可选字段**：无法识别时设为 null

#### 识别规则

- 从图片中提取成交额数值
- 确保单位为亿元
- 如果单位为其他，需要转换

#### 示例

| 图片中的信息 | 识别结果 | 说明 |
|------------|---------|------|
| 51亿 | 51 | 直接提取 |
| 51.5亿元 | 51.5 | 保留小数 |
| 510000万 | 51 | 转换为亿元 |
| 成交额未知 | null | 无法识别 |

3. **优先级排序**：如果有多个匹配，选择最相关的
4. **默认分类**：无法确定时使用 "其他"

### 9. 涨停关键词

#### 格式要求
- **格式**：多个关键词用 `+` 连接
- **内容**：涨停的驱动因素或相关概念
- **可选字段**：无法识别时设为 null

#### 常见关键词

- **政策相关**：国产替代、自主可控、产业升级、政策支持
- **技术相关**：技术突破、新产品、创新、研发成果
- **市场相关**：需求增长、市场扩大、订单增加、销售增长
- **资本相关**：融资、并购、重组、增发
- **事件相关**：业绩超预期、新合同、新客户、新市场

#### 示例

| 股票 | 涨停关键词 |
|------|----------|
| 神剑股份 | 商业航天+军工+碳纤维 |
| 宁德时代 | 新能源+电池+订单增加 |
| 中芯国际 | 芯片+国产替代+技术突破 |
| 浦发银行 | 金融+银行+业绩超预期 |

#### 提取规则

1. **从题材标签提取**：图片中通常会标注题材标签
2. **从新闻或说明提取**：图片中可能包含涨停原因说明
3. **从股票属性推断**：根据股票所属行业推断可能的关键词
4. **多个关键词**：用 `+` 连接，通常 2-4 个关键词

## ⚠️ 常见错误及修正

### 错误 1：日期格式不正确

```json
// ❌ 错误
{
  "date": "2026/03/04"
}

// ✅ 正确
{
  "date": "2026-03-04"
}
```

### 错误 2：股票代码格式错误

```json
// ❌ 错误
{
  "stockCode": "002361"
}

// ✅ 正确
{
  "stockCode": "002361.SZ"
}
```

### 错误 3：时间格式不规范

```json
// ❌ 错误
{
  "limitUpTime": "14:56"
}

// ✅ 正确
{
  "limitUpTime": "14:56:30"
}
```

### 错误 4：连板数格式错误

```json
// ❌ 错误
{
  "boardCount": "10连板"
}

// ✅ 正确
{
  "boardCount": "10天10板"
}
```

### 错误 5：单位错误

```json
// ❌ 错误（包含单位）
{
  "circulationValue": "116亿",
  "turnover": "51亿元"
}

// ✅ 正确（纯数字）
{
  "circulationValue": "116",
  "turnover": "51"
}
```

## 🧪 测试场景

### 场景 1：标准清晰图片

**输入**：清晰的涨停复盘表格图片，包含所有信息

**预期输出**：所有字段都有值，没有 null

### 场景 2：信息不完整

**输入**：图片中缺少某些字段（如时间、板数）

**预期输出**：缺失的字段设为 null，其他字段正常识别

### 场景 3：低质量图片

**输入**：模糊、倾斜或部分被遮挡的图片

**预期输出**：尽力识别必填字段，可选字段无法识别时设为 null

### 场景 4：多语言混合

**输入**：包含中文、英文、数字混合的图片

**预期输出**：正确解析各种格式，转换为标准格式
