# RESULT-DYNAMIC-3F-ENTRY-MECHANISM-001

> 目标：验证动态 3F 入场是否优于固定 T+5 入场。
> 基线：`first-limit-pullback-3f-top3@1.62.1`。
> 因子：`maxAmplitude_Te` LOW、`meanAmplitude_Te` LOW、`t1VolumeRatio` HIGH，等权横截面排名。
> 结论：**动态首次入场不优于固定 T+5；它同时恶化收益、最大回撤和 PF。**

## 0. 结论摘要

- 基线口径校验通过：原始 `v1.62.1` 桶分模型在 v5 缓存与现有执行引擎上精确复现 `+57.7330% / 最大回撤 47.9631% / PF 1.13663 / 1359 笔`。
- 但将 3F 改为“等权横截面排名”后，固定 T+5 对照臂已降至 `-41.1750% / 最大回撤 62.9879% / PF 0.9694`。因此横截面排名本身已经破坏了原桶分基线的收益优势。
- 动态首次入场进一步降至 `-72.2185% / 最大回撤 79.8831% / PF 0.9218`；相对固定 T+5 排名臂，收益 `-31.0435pp`，回撤恶化 `+16.8952pp`。
- 成本×2 下，动态首次入场为 `-86.8877%`，固定 T+5 排名臂为 `-73.6928%`，原桶分基线为 `-20.5700%`；动态机制没有成本优势。
- 动态首次入场只提前捕获固定 T+5 信号的 `51.01%`；按实际成交事件计，只捕获固定 T+5 成交的 `24.24%`。提前入场捕获了大量不同机会，但这些新增机会整体为负。
- 单 Te 诊断臂随入场时点推迟单调改善：T+1 `-88.6170%`，T+2 `-80.5265%`，T+3 `-72.6052%`，T+4 `-48.9976%`，T+5 `-41.1750%`。在本样本中，越早入场越差。

## 7. 最终判断

**动态 3F 入场不优于固定 T+5 入场。**

- 就核心对照 `dynamic_first` vs `fixed_t5_rank`：收益 `-72.2185%` vs `-41.1750%`，最大回撤 `79.8831%` vs `62.9879%`，PF `0.9218` vs `0.9694`，成本×2 `-86.8877%` vs `-73.6928%`。动态机制四项全败。
- 机会捕获不充分：只提前捕获固定 T+5 信号的 `51.01%`，实际成交捕获率仅 `24.24%`；新增成交机会整体为负。
- 越早入场越差：单 Te 收益从 T+1 `-88.6170%` 单调改善到 T+5 `-41.1750%`。
- 更根本的问题：把原 3F 桶分排序改成等权横截面排名后，固定 T+5 控制臂就已从原始 `+57.7330%` 跌到 `-41.1750%`。因此动态入场不能在“保留原3F经济含义”这一层成立。
- 本轮不支持创建动态入场策略版本，也不支持继续以该横截面排名合成方式优先做参数搜索或市场状态过滤。

## 8. 限制与审计声明

- 本结果是已读 v5 数据的样本内研究，不是 OOS / Walk-Forward 通过证据，不创建策略版本。
- 动态臂在信号产生时即消耗 event，即使后续买入因资金/涨跌停/持仓上限未成交，也不在后续 Te 重试；这与“同一 event 只允许第一次满足入场条件时进入”一致。
- 保持原仓位分档意味着 `0.55 / 0.7167` 阈值直接作用于横截面排名分位；这不等价于原桶分边界，是排名化后的口径差异，必须明确保留。
- `maxAmplitude_Te < 14%` 为 v1.62.1 固定风险阈值，只用于保持原入场边界，没有做阈值搜索。
- 成本×2 同时翻倍佣金、印花税、过户费与滑点；最低佣金仍保留原值。
