## 3. 修复状态与买点：唯一规则定义

### 3.1 池、时间与共同条件

首板定义、主板、事件日非ST、上市至少365自然日、最早未过期锚点均沿用003。后续涨停不刷新锚点或期限。相对日取锚点实际交易日；池仍观察 rd1..40，但买点确认日最多 rd19、实际成交最多 rd20。到期后只观察、不新买，不无限延期。

确认日收盘产生信号，次一交易日开盘执行。观察数据只用当日及以前；确认日前确实发生过 `C_j<C_0` 的回撤。仍持仓不加仓；全部真实平仓后，由新收盘信号才可再次入场，交易成本、持有期及退出状态重新计算。平仓不清除首板日期、历史风险、ST状态或买入截止日。

### 3.2 A与B未破位分支

复用 `rollingPoolEarlyEntry/entry.ts#evaluateEarlyEntry` 的003 N=5/L=20语义：

`S_j=1[L_j≥0.98O_0]+1[V_j≤0.5V_0]+1[L_j≥L_(j−1)]+1[C_j>C_(j−1)]`。

全程支撑不破、前五日每一天 S≥3、确认日 C高于前两日H、V不低于前日V、必要数据有效。A在历史首次可靠破位后永久停用该锚点；B只停止原分支，进入修复观察。

### 3.3 B破位后的局部修复分支

首次可靠 `L_t<0.98O_0` 时进入 `RECOVERY_WATCH`，记录破位日和局部低点 `p=t, F=L_t`，不删池成员。之后每个有效交易日，若 `L_t<F`，更新 `p=t, F=L_t`，重新积累修复观察；这里的p是截至当日的低点记录，不是事后确认的最低点。

日d触发修复买点须同时满足：

1. `d≤19`；前五个观察日 W=`[d−5,d−1]`全部在最新低点p之后，即 `d−5>p`；按实际交易日连续，日d也有效。
2. W五日均有有效OHLC、正成交量及所需前日比较值；停牌、缺行、零量不能跳过拼接。不可评估日中断本次观察；下一有效日建立新的局部观察段和低点基准并重新积累五日，保留历史缺口及破位记录。
3. W及日d都没有低于局部低点F。若日d创更低点，先更新p/F、回到观察，不发信号；与F相等不视作创新低。
4. W上的每日修复分为 `Q_j=1[L_j≥F]+1[V_j≤0.5V_0]+1[L_j≥L_(j−1)]+1[C_j>C_(j−1)]`，总分 **ΣQ_j≥15（满分20）**。报告四项原始值和总分；不要求每一天Q≥3。这是综合观察证据，不参与横截面排序。
5. 确认日 `C_d>max(H_(d−2),H_(d−1))` 且 `V_d≥V_(d−1)`；确认日不受缩量评分门限制。确认日前回撤已经发生、当日非ST且因子可评估。

**无需收复 `0.98O_0`**：破位后的参考支撑来自已观察到的局部低点，保留在原首板支撑线下整理后转强的路径。F不作为持仓退出价；退出仍使用冻结Runner政策。

状态展示分开记录 `priceState`（原观察/修复观察/修复成熟/信号成立/到期）、`buyEligibility`（NORMAL/ST_BLOCKED/UNKNOWN_BLOCKED）与 `positionState`（空仓/持仓）。ST或账户容量不能抹掉价格观察历史。`repairEpisodeId=anchorEventId+p`供追踪，不是新锚点或新期限。新低可开启下一修复段；新信号可以再次参与，是否成交由账户决定。

代码必须只有一个信号求值实现，归因直接消费其逐日证据，避免再写一套接近但不相同的条件解释器。涉及可持久化策略语义时使用既有Strategy Core接口；研究侧纯函数只做已授权的实验投影，不能新开legacy执行路径。

## 4. 每日ST硬闸门与数据覆盖

资格时点：确认日收盘检查历史 NORMAL，ST/*ST拒绝候选；未知拒绝。执行时点：真实成交前再次检查，隔夜转ST取消订单。首次、重试、再次入场，以及R/Random全部一致。拒单不扣现金、不计入场，也不自动换成第4名。

把 ST 检查接到既有执行资格接口，不能在前日候选构造中偷看次日状态、不能仅依赖 `canBuyAtOpen` 的涨跌停含义。执行检查用成交前可获知且已生效的状态；回测中的缺失/未知明确拒绝。所有实际成交必须带状态证据，ST/*ST成交数和无证据成交数均为0。

S1先核对 `server/securityStatus/**` 的区间、`DbDatasetBuildIO.resolveStSync` 及历史数据覆盖。现有 `baostockStatus.ts#inferStIntervals` 只保存ST片段，availability为UNKNOWN；没有ST片段**不等于**已证明NORMAL。有日期覆盖不等于开盘前可知：区分生效时间、公告可获知时间、采集时间，不能将近期retrievedAt当历史公告时间，不能把收盘日线状态当开盘前公告。

输出 `status-coverage.csv`：逐symbol/date/检查时点的来源、status、effectiveFrom/To、availableAsOf、confidence、覆盖依据和证据指纹；缺失时记录UNKNOWN，不伪造。事件级缺失可保守拒单，但若任一计划候选资格/潜在成交检查时点缺少可验证NORMAL或ST结论，**默认暂停收益矩阵**，先交付覆盖缺口及必要补数影响，不用大面积UNKNOWN拒单导致的空仓结果评价新买点。用户确认接受特定覆盖子集后须另冻版本、披露删样本影响。

当前事件当天非ST不代替动态检查；后来成为ST也不反向删除其先前事件或合法交易。已持仓转ST时禁止新增仓位，继续已有退出及真实可成交约束；本轮不另改强制退出政策，风险单列。

## 6. 靶指标、归因与结论规则

主要问题是右尾覆盖。主比较B_R−A_R：共同观察池锚点中，至少一笔已完成净收益≥20%的**唯一锚点数及覆盖率**；共同分母固定为两组共有且数据资格可核实的锚点宇宙，不用各组成交数作唯一分母。披露所有数据缺口及ST排除，不能按事后盈利改分母。

同时报实际交易≥20%尾率、唯一股票命中数、≥50/100%、单笔均值、锚点整链净损益（扣全部试错成本）、账户复合收益/MDD、资金与容量、交易次数、持有期，以及前3/5交易日的不利波动和收益。新增买点与原买点分开画像；账户收益必须完整重放，不能把事后最高价差额加总。

固定1000次配对日期块bootstrap，block20主、block40敏感性，95%区间；覆盖指标按共同锚点首次进入观察池的日期聚类，双方用同日历同抽样索引，空日保留。交易/整链指标另按声明的入场日期键聚类，不能混用。逐年报告相同靶与账户收益；2024/2025为已见探索窗口，不是OOS。没有已核验、PIT可用的市场状态标签时，熊市效果为未验证，不事后择市场分段。

报告判定：两组各至少50个独立命中锚点、主/敏感性区间下界>0、逐年同向、账户收益与风险未显示相反取舍，才可列为待未见样本验证的候选；不满足则INSUFFICIENT_EVIDENCE或明确风险权衡。任何样本量不足不靠随机账户数补足；42账户完成即可报告，不为了取得正结论扩seed/参数。

补齐归因：以**机会确认日**逐层输出ST→价格状态→评分/突破→因子→排序→账户→成交→退出。机会日至少包括未触发观察日，不能只在已触发子集归因；最高价标签仅事后诊断。逐机会匹配实际成交日期，分开未买、容量导致迟买、持仓内回吐、退出后上涨。记录峰值日期、退出后最大涨幅、持有期间不利波动；不再用rd19末态解释早期机会。

P1排除桶输出靶画像；P2尾部与均值并报；P3入选边界四件套、破平键；P4退出固定但仍报告其量级和观察局限；P5本协议及停止规则冻结；P6逐年。P3出现足以主导Top3的并列或任意身份破平时，停止因子效应解释，不临时换因子。
