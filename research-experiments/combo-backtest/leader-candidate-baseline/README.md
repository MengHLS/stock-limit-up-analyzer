# 原组合回测主模式迁移

## 来源

迁移自 `/backtest` 当前默认主模式 `leader-candidate-baseline`，不包含五策略研究面板。

## Dataset

- `datasetCode = first_limit_pullback`
- 版本标签固定为 `combo-v1`
- 构建窗口：`2025-11-01..2026-09-23`
- 事件：沪深主板全部收盘涨停，事件维度为 `limitUp`
- 行情窗口：`T+1..T+30`
- `combo-v1` 事件行同时保存原始来源事实：
  - 封板时间
  - 题材与关键词
  - 成交额
  - 流通市值

## 实验口径

- 候选评分严格从 Dataset 事件行重建；
- 冻结原全周期策略使用的 `score >= 65` 候选阈值；
- 信号日收盘生成候选排序；
- `T+1` 开盘买入；
- 最多 5 个持仓，等权分仓；
- 从 `T+2` 起执行动态止盈、开盘 / 收盘止损、强势续持和最多持有 5 日；
- 初始资金 100000 元，整手 100 股，含佣金、印花税、过户费和 10bps 滑点。

## 已知边界

- 当前实现只迁移原主模式，不迁移风险扣分、质量复合和样本外参数搜索面板；
- Source record 缺失的价格检测涨停不计入候选池，保持与原 `limit_up_records` 候选口径一致；
- 退出使用 `post` 行情与涨跌停事实；极端停牌路径按下一可见 bar 继续尝试卖出。
