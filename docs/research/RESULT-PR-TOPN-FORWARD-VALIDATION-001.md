## 0. Gate

```text
PR_T1_RANKING_EDGE
```

**判定依据**：`Top3 / Top5 在扣除交易成本与实际成交约束后，稳定跑赢 Pool`——全历史 Top5−Pool 日均 +0.064%（t=3.43，正日 52.0%），Top3−Pool +0.068%（t=3.02）；三个子区间（2019-2022 / 2023-2024 / 2025-2026）Top5−Pool 均为正（t=1.92 / 2.40 / 1.80）。

**但必须同时明确三个反向事实（进入下一阶段前必须作为前提）**：

1. **TopN 并没有跑赢 Bottom10**：Top5−Bottom10 日均 **-0.017%**（t=-0.61），Top3−Bottom10 -0.013%，Top10−Bottom10 -0.029%——即"最高分"并不优于"最低分"。
2. **Rank IC ≈ 0**：mean IC -0.0060，ICIR -0.041，IC 正日 48.3%——**没有正向横截面秩相关**。
3. **Top3/Top5 的绝对收益为负**：全历史 CAGR -4.98% / -5.59%，最大回撤 -66.5% / -65.7%（扣成本后）。

⇒ 结论应表述为：**PR T+1 存在"相对 Pool 的排序价值"（来自规避池内最差部分），但不是"最高分绝对更强"的正向 alpha**。Gate 按任务强调的 Top3/Top5 vs Pool 判 `PR_T1_RANKING_EDGE`，但下一阶段只能作为"Pool 内相对排序/规避尾部"的信号研究，不能当作正向选股 alpha。

## 6. 必须明确的前提与残余风险

1. **Gate 是"相对 Pool"的排序价值**：Top3/Top5 稳定跑赢 Pool（扣成本、含成交约束），但 **Top < Bottom10、Rank IC≈0**。若下一阶段需要"绝对正向 alpha"，本轮不成立。
2. **成本是结果的支配项**：来回 0.25-0.30%，毛日内收益不足以覆盖，除 Bottom10 外全为负；任何降低换手/持仓周期之外的成本假设变化都会改变绝对结论。
3. **T+1 Open→Close 日内策略**：未模拟开盘集合竞价冲击、资金容量、最小佣金 5 元、部分成交；涨跌停/停牌/缺价已按要求剔除。
4. **未做反向调参**：PR 定义、阈值、score 方向均未修改；全部结果来自固定口径。
5. 等权复利假设无限可分、每日全额调仓；未做仓位/风险控制。

## 7. 结论

**`PR_T1_RANKING_EDGE`**——但准确表述是：**PR T+1 分数具备稳定的"相对 Pool 排序/规避池内尾部"能力**（Top3/Top5−Pool 三区间为正、全历史 t 3.0-3.4），**不具备"Top > Bottom"的正向横截面 alpha**（Top<Bottom10、Rank IC≈0、绝对 CAGR 为负）。

下一阶段若要继续：只能围绕“Pool 内相对排序 / 规避 Bottom10”做研究（例如把 PR score 作为负向/规避因子），并且必须以扣成本后的相对基准为评价口径；不得据此直接进入正向 TopN 选股策略。
