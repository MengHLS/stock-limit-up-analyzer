## 判据

1. **实现 ≥ +50% 的笔数**（现役 9）——抓更多超级票的直接指标；
2. C 收益（现役 151.10%）；
3. C 最大回撤（现役 43.30%）；

### 结论：**第 4、5 名不值得买**（P4 被否）

- 真正买到 rank4/5 的成交：22 / 28 / 174 笔，**总净利全部为负**（−10.6k / −12.9k / −12.5k）；
- **rank4-5 里一笔 ≥+50% 都没有**（0/22、0/28、0/174）；
- 组合收益 151.10% → 116.17% / 82.47% / −11.35%，回撤 43.30% → 44.12% / 46.08% / 64.28%。

⚠️ 与召回诊断的差异（值得记住）：召回口径说 rank4/5「**曾经**涨过 +50%」的密度与 rank1-3 同档（11.3%/11.8%），
但**买入后没有一笔实现 ≥+50%** —— 因为「曾经到过」≠「在本策略的持有期与退出规则下能实现」（这正是 P3 诊断过的同一件事：
20 笔曾达 +50%，只有 9 笔实现）。**召回口径的密度不能直接当作可实现的收益预期。**
