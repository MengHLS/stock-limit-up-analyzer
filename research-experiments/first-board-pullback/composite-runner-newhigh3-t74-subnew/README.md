## 口径

- **上市日** = Security Master `research_securities.listedDate`（PIT：决策日已知）。
- **上市龄** = 决策日 − 上市日（**自然日**，非交易日）。
- **上市日不可得** ⇒ **不剔除**并如实计数（本规则是 alpha 资格过滤，不是风控；不可证实的身份
  不得被静默排除）。实测四臂该计数为 0。
- 「剔除」发生在**排序前** ⇒ 被剔除名额由低名次**递补**（这与 P9「只过滤 intent、不补 rank4/5」
  是两件不同的事；P4 已实测 rank4/5 递补本身为负，读数时必须区分）。

- **`excl365` 最差（151.10% → 65.39%，−85.7pp）**，最大回撤 43.30% → 50.77%：剔除 1591 个候选后，
