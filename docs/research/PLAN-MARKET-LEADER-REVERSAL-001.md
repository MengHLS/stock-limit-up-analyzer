# PLAN-MARKET-LEADER-REVERSAL-001 — 市场总龙生命周期与断板反抽研究计划

> 状态：**PHASE_0_COMPLETE / READY_FOR_PHASE_1**
> 日期：2026-09-26
> 范围：独立研究实验；不直接进入生产策略、纸面交易或实盘。

## 0. 本轮冻结的用户口径

1. **总龙不是连板高度的单指标定义**。高连板只是领导力维度之一，不得把“6 板”或“最高板”当成唯一真值。
2. **总龙允许多个成员并存**。研究对象是“总龙候选集合 / 领导力集合”，不是强行选出一个唯一股票。
3. **只研究沪深主板、非 ST 股票**。
4. 历史缺失的题材、封单、分钟、竞价等数据暂不阻塞研究；第一版只使用当前可稳定获得的数据。
5. 先完成计划、数据普查和实验体系，再讨论策略化。

## 1. 研究定位

本专题回答：

```text
市场领导权形成
  -> 总龙集合确认
  -> 高位加速 / 分歧 / 见顶
  -> 断板或失位
  -> 首次反抽 / 二次退潮
  -> 不同市场环境下的后续收益与风险
```

它适合作为独立实验加入，原因：

- Dataset 已支持主板、PIT ST、停牌、连板、日线路径与可交易性事实；
- 已有周期龙头 / 原生龙 / 穿越龙 / 补涨龙词汇，可作为研究命名基础；
- 已有龙头候选评分，可作为多维度领导力的基线，而不是唯一权威；
- 已有独立实验、协议、Holdout、Bootstrap、路径曲线和产物持久化基础设施。

它当前不适合直接作为生产策略，原因：

- “总龙”是市场共识概念，必须先证明不同可观测定义下的稳定性；
- 历史题材、封单、开板和分钟执行数据不完整；
- 总龙断板样本天然较少，必须先做样本量普查；
- 反抽定义容易事后择优，必须先冻结再验证。

## 2. 操作定义

### 2.1 股票池

- 交易所：Shanghai / Shenzhen。
- 板块：`boardType = main`。
- 排除：ST / *ST / 退市整理；历史状态未知不得默认视为非 ST。
- 上市、停牌、退市状态按事件日 PIT 解析。

### 2.2 总龙候选集合

总龙不作为唯一股票定义，而定义为**某日或某周期内的多维领导力集合**。

第一版只使用稳定可得的日线维度：

- 高度与连续性：连板高度、最近 5 / 10 / 20 个交易日涨停次数、连续涨停段长度；
- 市场关注：成交额、成交量、换手率、相对自身历史的量能放大；
- 容量与可交易性：流通市值、总市值、成交额/市值比；
- 相对强弱：阶段收益、相对主板基准收益、断板前最大涨幅、回撤位置；
- 可执行性：一字板、涨跌停、停牌、可买可卖事实；
- 市场环境：主板最高板、涨停家数、连板家数、指数状态、市场成交额。

历史题材数据和封板时间在当前库中存在覆盖缺口，先作为**近期增强维度**，不作为第一版全历史确认性研究的前置条件。

### 2.3 非唯一性与定义对照

必须并行研究至少四类领导权定义：

| 定义 | 含义 | 用途 |
|---|---|---|
| `HEIGHT` | 当日最高连板 / 连板高度排名 | 仅作为控制组，不单独代表总龙 |
| `RANK_CONSENSUS` | 多维横截面排名的一致度 | 第一版主定义 |
| `PARETO` | 任一核心维度处于领先前沿，保留并列 | 检验“总龙不唯一” |
| `PRODUCTION_SCORE` | 既有龙头候选评分 | 现有系统基线 |

`RANK_CONSENSUS` 第一版只使用**等权排名聚合**，不做权重搜索。领导权集合允许 `Top-K`、并列和同一周期内的多个成员。

### 2.4 生命周期事件

- `LEADER_EMERGENCE`：某股票首次进入领导权集合；
- `LEADER_CONFIRMATION`：连续 N 日留在领导权集合，或领导力排名持续处于前列；
- `LEADER_PEAK`：领导力维度达到周期高点，不要求断板；
- `LEADER_BREAK`：此前为领导权成员，但当日不再封住涨停或退出领导权集合；
- `REBOUND_TRIGGER`：断板后出现预定义止跌/修复信号；
- `REBOUND_FAILURE`：反抽后再次跌破关键结构或进入二次退潮。

### 2.5 反抽定义候选

第一版只比较预先固定的日线口径：

1. 断板后首次收盘上涨；
2. 断板后首次收盘高于前一日最高；
3. 断板后首次收复 MA5；
4. 断板后首次缩量止跌；
5. 断板后首次不再创出新低。

不得先看收益再挑选触发条件。

## 3. 数据与 Dataset 计划

### 3.1 数据使用原则

- 实验只能通过 Dataset 访问数据，不能直接读取 `limit_up_records`。
- 第一版新建 `market_leader_reversal` Dataset Family。
- 不直接复用 `first_limit_pullback v5`，因为它的锚点是首板，无法表达高位连板生命周期。
- 不直接复用 `combo-v1`，因为它是短窗口且不排除 ST。

### 3.2 第一版 Dataset 口径

```text
datasetCode: market_leader_reversal
boards: main
excludeSt: true
events: limitUp / consecutiveBoard
preWindowDays: 20~30
postWindowDays: 30~60
outcomeHorizons: 1 / 2 / 3 / 5 / 10 / 20
research phase: EXPLORATORY -> OBSERVATION -> HOLDOUT
```

第一版依赖字段：

- 证券身份、交易所、上市/退市、ST、停牌；
- 未复权 OHLCV、前收、成交量、成交额、涨跌停价；
- 连板/涨停序列、历史涨停次数、距上次涨停交易日；
- 换手率、流通市值、总市值；
- 一板、一字板、可买、可卖、停牌与顺延事实；
- 指数与市场层面的基础上下文。

### 3.3 暂不阻塞研究的缺失项

- 历史题材成员与题材热度；
- 首封/最后封板时间、开板次数、封单金额；
- 集合竞价、分钟线和订单簿。

这些能力只在数据补齐后开增强实验，不进入第一版确认性 Gate。

## 5. 执行顺序

### Phase 0：样本与数据普查

- 统计主板非 ST 涨停次数、连板段、不同高度顶部事件；
- 统计领导权集合规模、并列比例和断板事件；
- 按年份统计样本；
- 统计核心字段覆盖率；
- 给出“可描述、可确认、样本不足”的结论。

### Phase 1：Dataset

- 新建 `market_leader_reversal` Dataset Definition / Provider / Version；
- 构建第一版只读 Dataset；
- 验证 PIT、ST、停牌、板块、窗口和样本账。

### Phase 2：P0 实验

- 只做描述性统计、路径、定义敏感性和样例账；
- 不搜索权重，不选择最佳触发条件。

### Phase 3：规则对照与验证

- 同事件比较反抽触发和退出规则；
- 时间切片；
- 稳健性；
- 冻结协议后 Holdout。

### Phase 4：策略化裁定

只有 Phase 2/3 全部通过，才允许讨论 Strategy Core 回测。
Strategy Bridge 要求 Holdout `PASS`；仅“强通过”报告但平台 Gate `INSUFFICIENT` 时不得直接生产化。

## 6. 放行门槛

- 每只股票每天最多一条领导权记录；
- 同一周期允许并列和多个总龙成员；
- 领导权识别不得读取未来数据；
- 所有榜外 / 未入选样本必须有剔除原因；
- 样本不足时只允许描述性结论；
- 第一版不得使用缺失字段做硬过滤；
- 不得用同一窗口反复调整总龙定义、反抽定义或 Top-K；
- 任何策略化讨论必须晚于真实执行口径验证。

## 7. Phase 0 样本普查结果

执行证据：

- 探针：`docs/evidence/_probe_market_leader_census.mts`
- 结果：`docs/evidence/_probe_market_leader_census.out.json`
- 数据范围：2019-01-01 至 2026-09-23，1,877 个交易日。

### 7.1 股票池与样本量

- `limit_up_records` 共 100,187 条；
- 按 `classifyBoard = main` 过滤后 98,333 条；
- 其中身份可解析且按历史 ST 区间判定为非 ST 的 98,332 条；
- 1 条无法解析证券身份，单独排除；
- 涉及 3,345 只主板股票；
- 连板段 73,679 段；
- 峰值高度分布：1 板 60,018、2 板 8,671、3 板 2,504、4 板 1,178、5 板 575、6 板 292、7 板及以上 441。

### 7.2 反抽研究可用样本

断板事件按“连板段结束后仍有下一交易日”统计：

| 峰值高度 | 断板事件 |
|---|---:|
| 4 板及以上 | 2,482 |
| 5 板及以上 | 1,307 |
| 6 板及以上 | 733 |
| 7 板及以上 | 441 |

2024 至 2026-09-23 的“6 板及以上”断板事件为 **233** 个：

- 2024：125；
- 2025：79；
- 2026：29。

结论：样本量允许做描述性路径研究；但确认性 Holdout 必须考虑样本随时间减小，不能把全部维度同时拆得过细。

### 7.3 字段覆盖

`limitUpTime` / `sector` / `keywords` 的年度覆盖率：

| 年份 | 覆盖率 |
|---|---:|
| 2019 | 0% |
| 2020 | 0% |
| 2021 | 0% |
| 2022 | 0% |
| 2023 | 0% |
| 2024 | 0.94% |
| 2025 | 21.48% |
| 2026 | 100% |

结论：

- 全历史第一版不得依赖题材、封板时间和关键词；
- 2026 可以做增强描述，但不得把 2026 结果外推到全历史；
- 第一版领导权识别以高度、连续性、成交额、市值、相对强弱和市场状态为核心。

### 7.4 Phase 0 裁定

**通过。**

- 6 板以上事件总量足够；
- 2024 年以后仍有 233 个确认性候选事件；
- 不需要等待缺失的题材和日内数据；
- 可以进入 Phase 1：实现 `market_leader_reversal` Dataset 与只读 Reader。

## 8. 非目标

- 不定义唯一总龙；
- 不以连板高度作为唯一标准；
- 不搜索主观评分权重；
- 不预测具体涨幅；
- 不把“反抽”直接等同于买点；
- 不在第一版引入分钟、盘口或补数据阻塞。
