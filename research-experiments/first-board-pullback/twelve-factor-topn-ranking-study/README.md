# 十二因子综合评分 · Top-N 排名可用性研究（第一版）

## 这个实验回答的唯一问题

> **这个评分到底能不能帮助我每天从首板股票里挑出前几名？**

「等权综合评分」实验（`first-board-pullback/twelve-factor-composite-study`）回答的是
**全样本分档**问题（评分十分位与净收益有没有梯度）。每天实际要做的动作是
**同日横截面排序取头部**，这是**另一个**问题：

| | 分档实验 | 本实验 |
|---|---|---|
| 单位 | 档（全样本切成 10 份） | 决策日（首板日 T） |
| 问题 | 档均值是否单调 | 同日排序取前 N 名，相对当日全部候选有没有优势 |
| 反例 | 有漂亮单调梯度的评分，头部与中部差距仍可能小于日内噪声 ⇒ Top-N 无优势 | — |

## 口径

| 项 | 取值 |
|---|---|
| Dataset | `first_limit_pullback` / **v5**（`eventScanPolicy = FULL_DATASET`） |
| 样本 | 与 12F 实验**逐字相同**（共用 `twelve-factor-composite-study/derive.ts`） |
| 决策时点 | 首板日 T 的 **T+5 收盘**（用到 T+1..T+5 行情 ⇒ 入场只能落 T+6） |
| 入场 | **T+6 开盘**，等权 |
| 退出 | **T+10 收盘**（不可卖则顺延，最多到 T+20） |
| 成本 | **20 bps 往返**（在 `netReturn` 内扣除） |
| 排序键 | 综合评分（12 因子等权桶位分，`FROZEN-BUCKET-CONTRACT-001`）降序 |
| 档位 N | 固定 `1 / 2 / 3 / 5 / 10`；比例档 `当日样本 × 20%`（至少 1 个） |
| 日集 | **本职日集**（当日样本 ≥ 该档所需 N）／**固定日集**（当日样本 ≥ 10，所有档共用） |
| 基准 | **当日池** = 同一天全部可用样本的等权均值（= 随机抽 N 个的期望） |
| **主判据** | `excess_d = mean(topN_d) − mean(pool_d)` 的日度等权均值，日期聚类 Moving-Block Bootstrap 95%（block = 20 交易日，1000 次，固定种子） |
| 三态 | CI 下界 > 0 ⇒ `POSITIVE`；上界 < 0 ⇒ `NEGATIVE`；跨 0 ⇒ `INCONCLUSIVE`；决策日 < 100 ⇒ `INSUFFICIENT` |

## 输出

- **主表**：综合评分 6 档 × 2 日集 —— 组合日均收益、当日池日均、超额 + CI + 判定、日胜率、选中胜率。
- **对照矩阵**：15 个排序键（综合评分 / 9 因子子评分 / 反转臂 / 12 个单因子）× 6 档（固定日集）。
- **深度曲线**：`K = 1..20` 的超额，看信号是不是只在最头部。
- **随机 N 基准**：给定当日候选池随机抽同样多，1000 次模拟 ⇒ 观测值的分位与单侧 p。
- **年度切片**：逐年超额（描述性，**不是**稳健性检验）。
- **决策日样本量分布**：「每天挑前几名」在数据上有没有可操作空间。

## 刻意不做

- ❌ 不改因子、不改桶、不重估方向、不优化权重（全部 import 自 12F 的冻结落地处）；
- ❌ 不做 OOS / Holdout（`researchPhase = EXPLORATORY`）；
- ❌ 不做归因（「为什么头部好」不在范围内）；
- ❌ 不做资金曲线 / 复利 / 仓位管理 / 涨跌停不可成交的二次建模（沿用底座既有 `canBuyAtOpen` / `canSellAtClose` 闸门）。

## 已知限制（必须与结论一起读）

1. 🔴 **持仓重叠**：持有 5 个交易日 ⇒ 相邻决策日持仓互相重叠，日度序列**不是独立观测**。
   CI 用 block = 20 的日期聚类 Bootstrap 吸收这一点，但**不得**把 N 个决策日当作 N 个独立实验。
2. 🔴 **等权口径**：主指标 = 各决策日组合收益的等权平均（每决策日一单位资金），
   与「始终满仓滚动」的真实资金曲线不同。
3. 🔴 **超额 ≠ 可交易收益**：基准与组合同处 20 bps 成本口径，且基准是「当日全部候选等权」——
   这是一个**不可交易**的对照（真实资金无法同时买入当天全部候选）。
   `POSITIVE` 只说明「排序有信息」，不说明「这样能赚钱」。
4. ⚠️ **多重比较**：15 键 × 6 档 × 2 日集 ≈ 180 个判定，α = 0.05 下假阳性期望 ≈ 9 ⇒ 全部结论为**探索性**。
5. ⚠️ **窗口限定**：v5 的窗口是单一区间，`v5` 之外的年份不可外推。
6. ⚠️ 比例档 Top-20% 的 N 随当日样本量浮动 ⇒ 跨档比较请以**固定日集**为准。
