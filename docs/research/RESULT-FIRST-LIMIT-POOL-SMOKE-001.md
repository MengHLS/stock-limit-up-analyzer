# 首板股票池滚动 3F 冒烟结果

> 该结果仅验证代码路径，不构成策略收益结论。

- 窗口：2025-01-01 ~ 2025-03-31
- 数据集：`first_limit_pullback` / v5（用于短池龄冒烟，非正式 60 日实验）
- 临时策略：`smoke-pool-rolling-3f-top3@0.0.2`
- 池龄：5 个交易日
- 结果：闭环 5 个核心阶段 `ALL_EXECUTED`，留档成功
- 累计收益：`+4.8406%`
- 最大回撤：`0.0837%`
- 成交：6 笔（1 笔完成，5 笔期末仍持仓）
- v6 同池龄复跑：`ALL_EXECUTED`，累计 `+4.8406%`，最大回撤 `0.0837%`，6 笔，与 v5 短窗逐项一致。
- v6 正式池龄 60 短窗：`ALL_EXECUTED`，累计 `-7.3533%`，最大回撤 `9.9581%`，47 笔；已覆盖 60 日池龄、main-only 事件过滤和次日执行行情。

对照组短窗冒烟：

| arm | 结果 |
|---|---:|
| baseline（同数据集 v1.62.1 配置） | `ALL_EXECUTED`，累计 `+13.6711%`，最大回撤 `5.7520%`，49 笔 |
| no-pullback-event（无回踩事件窗） | `ALL_EXECUTED`，累计 `+10.6222%`，最大回撤 `5.5852%`，46 笔 |
| fixed-pool（固定冻结桶池化） | `ALL_EXECUTED`，累计 `+8.2599%`，最大回撤 `0.7738%`，8 笔 |
| calibrated-event（N=5 校准事件窗） | `ALL_EXECUTED`，累计 `-0.7662%`，最大回撤 `1.4400%`，5 笔 |

正式研究必须使用 `v6` 的 80 日后窗、60 日池龄，并运行
`scripts/runFirstLimitPoolRollingStudy.mts` 的主策略与归因对照。
