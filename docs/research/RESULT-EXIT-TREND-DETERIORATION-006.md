# RESULT-EXIT-TREND-DETERIORATION-006

> 目标：基于 RUNNER-SELECTION-005 的 Runner 状态，研究 Runner 强状态转为弱状态后，哪些单变量转移更接近“上涨开始衰竭”，并评估退出后的机会损失。未新增变量、未组合条件、未搜索阈值、未创建 Candidate。

## 0. 固定口径

- Dataset: `first_limit_pullback` / `datasetVersionId=660001`；固定池 `D20 < -10% && MA20Slope <= 0`。
- T+5 收盘形成池，T+6 开盘入场，T+6~T+20；严格 PIT。
- 激活：+10% / +15%；从激活后第 1 个交易日扫描至 T+19。
- 每个转移单独检测“上一日处于强状态、当前日进入弱状态”的首次发生；触发后按当前收盘描述性退出。
- 本轮比较的转移只使用 RUNNER-STATE-RESEARCH-004 固定变量：MA5/MA10支撑、MA5/MA10斜率、近2/3日收益、2/3日创新高、连续创新高、收盘位置、量能、连续收低、近5日高点距离。
- “丢失 +20%/+30% 机会”定义为：事件全局 MFE 达到该门槛，但首次转移退出时的 gross return 未达到该门槛。
- 所有净收益扣 20bps；所有机会损失均使用事后标签，只用于评价，不作为当前状态输入。

## 5. 与 Runner 状态的衔接

- RUNNER-SELECTION-005 表明，接近近5日高、站上 MA5/MA10、短收益非负、创新高和连续创新高提高了后续 +20%/+30% 密度。
- 本轮进一步检查这些强状态是否会在之后的某一日转为弱状态。结果是：一旦强状态消失，许多后续大赢家仍会继续扩张，因此“强状态转弱”本身不等于“上涨结束”。
- MA10 支撑转弱、MA10 斜率转负等转移尤其容易发生在大赢家后续上涨之前；它们更适合作为风险提示，不足以单独承担 Exit 职责。
- 连续收低由 0 转 1、由 1 转 >=2 是更明确的短期衰竭信号，但事后仍有相当多 +20%/+30% 事件会经历它。

## 6. 重点判断

### 6.1 哪个信号最接近上涨衰竭？

从“机会损失较低”的角度看，较慢且条件更严格的转移相对更有研究价值，例如连续创新高 >=2 中断、由 1 转 >=2 连续收低；但这不代表它们已经是可用退出规则：

- 它们仍然会丢失大量 +20%/+30% 事件；
- 不同年份的均值差并不稳定；
- 许多事件在触发转移后仍出现新的高点。

### 6.2 Exit 后机会损失

所有单变量转移都存在明显的右尾机会损失。MA10 相关转移、短期收益转负和创新高能力消失都发生在大量最终大赢家的中段上涨之前。因此“避免回撤”和“保留大赢家”在这一层仍然存在直接冲突。

### 6.3 当前最值得继续推进的是

当前仍然是 **Exit 趋势衰竭**。

- 初始选股已经由固定深跌池完成；
- RUNNER-SELECTION-005 已验证上涨后可以识别更高密度的 Runner；
- 但本轮发现，现有单变量“强转弱”信号仍过早，几乎没有一个能同时控制回撤并保留大部分右尾。

下一步不应创建 Candidate，而应继续研究：
1. 趋势破坏后的“二次确认”是否能减少假触发；
2. 不同强状态对应的衰竭速度是否不同；
3. 退出后的机会损失是否能通过更高层级的路径状态区分。
