# RESULT-TREND-POOL-3F-BREADTH-001

> 目标：在固定 B 趋势池内，验证原 3F 综合分是否具有固定的 Q1-Q5 质量排序能力。
> 本阶段不使用 Top3、不搜索分桶边界、不修改 3F、不创建 Candidate。

## 0. 研究坐标

- 固定股票池：`B = close(T+5) >= MA10 && close(T+5) >= MA20`。
- 评分：原 3F 等权合成分，定义与方向不变，高分仍记为 Q5。
- 分位边界：仅用 B 池内 `2019-2024` 的 3F 分数冻结为 `Q20/Q40/Q60/Q80`，全样本和 OOS 不重新估计。
- 冻结边界：`0.350000 / 0.416667 / 0.483333 / 0.583333`。
- 质量标签：`T+1 开盘 → T+5/T+10/T+20 收盘`，净收益扣 20bps；与上一步研究保持一致。
- 严格 PIT：趋势、3F 和分层信息均不超过 T+5；Q1-Q5 边界只由 2019-2024 训练段确定。

## 5. 最终回答

1. **高分组是否稳定优于低分组？**
   否。Q5 在 full 和 OOS 的 T+20 都低于 Q1；2020/2023/2025/2026 也没有稳定的高分优势。

2. **3F 是否存在单调质量梯度？**
   否。H20 顺序为 `Q2 > Q1 > Q3 > Q5 > Q4`，没有单调趋势；高分段整体更像被现有 3F 组合方式反向标记。

3. **3F 是否值得作为 B 趋势池的质量评分器？**
   以当前原 3F 定义，**不值得直接保留为质量评分器**。它没有改善 B 池整体质量，且高分组表现更差。若继续研究 3F，应重新研究其有效因子、方向和组合方式，而不是继续使用当前 Top3/高分组路径。

4. **B 池本身与加入 3F 后的各分层相比，质量是否继续改善？**
   B 池整体 T+20 -1.58%；Q2 为 +0.84%，但 Q3/Q4/Q5 为 -1.87%/-3.23%/-2.19%。只有非单调的 Q2 局部更好，不能据此保留现有 3F 分层作为质量评分。

## 6. 结论边界

- 本阶段只验证固定分位，不搜索最佳分组，不创建策略版本。
- Q1-Q5 边界只从 2019-2024 B 池冻结，之后不重估。
- 当前结论只适用于 Dataset `first_limit_pullback` id=660001、B 趋势池、原 3F 定义。
- 下一步若继续 3F，应拆解其成员因子在 B 池中的独立排序能力；当前不应把原 3F 作为趋势池质量评分器，也不应进入买点优化或 Candidate。
