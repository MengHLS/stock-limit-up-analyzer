## 0. 本方案回答的问题，以及一个必须写清的歧义

**「综合因子实验」有两种读法，本方案把两种都排进路线，但**不合并成一件事**：**

| 读法 | 本文档对应的阶段 |
|---|---|
| (甲) 「综合」= **整体/汇总** —— 即「下一步那一批因子实验的总方案」 | 全文（Phase 0~4） |

## 4. Phase 2 · 五个单因子实验（F1–F5）

**规格见 `PLAN-COMBO-BT-EXP-001.md §4`**（本文件只固定它们的**共同形态**）：

```
一个因子 → 固定桶（服务端档位，不自造）→ 每桶输出：
  样本数 · 事件日数 · 均值 · 去最高5%均值 · 中位 · 净胜率 · P5/P25/P75/P95
  · MFE/MAE · 首达 ±2%/±5% 的持有日
  · 日期聚类 Moving Block Bootstrap 95% CI（1000 次 / block 20 / 固定种子）
→ 三态判定
```

**判定必须写死、可复现**（沿用 `PLAN-COMBO-BT-EXP-001 §0.2 D2`）：

| 判定 | 条件 |
|---|---|
| 有效·正向 | 该桶净收益 95% 聚类 Bootstrap **CI 下界 > 0** |
| 有效·负向 | CI **上界 < 0** |
| 不确定 | CI 跨 0 |
| 样本不足 | 桶内可用样本 **< 100** ⇒ 强制不判定（**不得**用「趋势」代替判定） |

**有效区间 = 「有效·正向」的桶的并集**（分段必须原样呈现，禁拼接成「最优区间」）。

🔴 **多重比较必须披露**：5 因子 × ~6 桶 × 3 视界 ≈ **90 个判定**，`α=0.05` 下假阳性期望 ≈ 4.5 ⇒ **所有结论只能声明为「探索性」**，报告里出现「长期有效 / 稳定有效」直接判不合格。

**执行顺序**：先跑 F3/F4/F5（列直接可得），再跑 F1/F2（需派生）。⚠️ F2/F3/F4/F5 的可用样本受列填充率约束（`limitUpTime` / `sector` / `sourceTurnoverAmount` / `sourceCirculationValue` 填充率均约 **82.4%**，实测约 13,370 / 16,221），可用子样本**偏向窗口后段**（2025-11 缺 22.5% → 2026-09 缺 1.2%）⇒ 必须**逐月披露缺失 + 做缺失期对照切片**。

## 5. Phase 3 · 因子正交性（**必须先于任何「综合」**）

**为什么不能跳**：若 F1（连板数）与 F2（题材家数）高度共线（高连板的票，题材家数往往也多），那么「F1 有效」可能只是「F2 有效」的影子 —— 单因子结论会**互相污染**，而单因子设计本身检测不出这件事。

**输出（两项，都必须给数）**：

1. **同日横截面相关矩阵**：5 因子两两 Spearman ρ，**按事件日聚类**给 CI（不能按事件给，同日事件不独立）。
2. **top-N 重叠度**：每个因子取自身 top 20% 的票，两两算重叠率（Jaccard）。重叠率 ≥ 0.7 的因子对，**结论必须合并陈述**，不得分别宣称有效。

**判据**：重叠度矩阵先出、再解释 Phase 4 的结果；若某因子对重叠极高，Phase 4 的「逐层叠加」里它们**只能算一层**。

## 6. Phase 4 · 跨因子综合（「综合」的正确做法）

### 6.1 🔴 先写禁止项

**禁止加权综合评分**，理由（`PLAN-COMBO-BT-EXP-001 §0.1` 已逐条论证，此处只列结论）：

1. 加权和 ⇒ 因子互相掩蔽（`6板×1题材` 与 `1板×6题材` 可能同分，结构完全相反）；
2. `min(100, …)` 截断 ⇒ 高分区间边际加分被吃掉，第一名与第二十名同分；
3. 阈值卡在综合分上 ⇒ **改一个因子动的是「谁能进池」，不是「池内怎么排」** ⇒ 观测到的差异**无法归因到该因子**。

### 6.2 允许的两种表达（都要做，产出的是**结构**不是**分数**）

**(a) 条件交集（conjunctive screen）**
把各自判定为「有效·正向」的因子桶条件**取交集**（例：`boards ≥ 3` ∧ `sectorCount ≥ 4` ∧ 封板 ≤ 10:00），在交集子样本上跑**同一套**曲线 + Bootstrap。
- 必须同时报告**交集样本量**；样本 < 100 的桶强制不判定（与 Phase 2 同一阈值）。
- ⚠️ 已知风险：交集会迅速吃空样本（`combo-v1` 只有 11 个月 / 16,221 事件 / 因子列 82.4%）⇒ 交集最多容纳 2~3 个条件，超出即无意义。

**(b) 逐层叠加（layer-by-layer，可归因的「综合」）**
从全样本出发，**一次只加一个因子条件**，报告每加一层的**增量 Δ**（均值 / 中位 / 净胜率 / MFE / MAE / CI 变化）。

```
L0 全样本  →  L1 +F1 条件  →  L2 +F2 条件  →  L3 +F3 条件 …
每层都输出：样本量 / Δ均值 / Δ中位 / Δ净胜率 / ΔMAE / CI 是否跨 0
```
- 这是「综合」的正确形态：**每一步都可归因**，而不是一次给一个总分。
- 层级顺序由 Phase 3 的正交性结果决定（重叠高的因子合并为同一层）。

### 6.3 ⭐ 建议**第一个**跑的：R6 随机基准对照

**同信号日、同候选池**，随机选 N 只（N = 实际策略每日持仓数），**固定种子重复 200 次**，看真实策略落在收益分布的哪个分位。

- 这是判断「评分排序到底有没有信息」的**唯一诚实做法**，而且**与窗口长度无关** ⇒ 在 `combo-v1` 只有 11 个月的约束下，它是效力**不受影响**的判据。
- 若真实策略落在**中位数附近** ⇒ 后续所有因子结论**降级为描述性统计**，可省掉大量工作。

### 6.4 强制区间限定

所有结论必须带 **「`combo-v1` 窗口限定」**（2025-11 ~ 2026-09，**11 个月 / ≈3.7 个季度**，无牛熊切换）。⚠️ **禁止**用 `v5` 当替代长窗口：`v5` 是 `firstBoard` 事件 ⇒ 评分里 `boards` **恒为 1**、高位连板风控整体失效 ⇒ **不是同一个策略**，结论是伪结论。
