### 0.1 三类退出口径的精确定义（本报告一律不混用）

| 代号 | 名称 | 精确语义 | 性质 |
| --- | --- | --- | --- |
| E_close(D) | 固定事件日退出 | 在【事件相对日 rd=D】的【收盘】计价离场 | 研究标签口径（T+20/T+80 路径研究的通用口径） |
| H_signal(K) | 实际入场日计持有（信号日） | 从【实际入场成交日】起算第 K 个持有日的【收盘】产生离场信号 | 引擎 maxHoldingDays / strongHold / Runner 的判据日 |

4. H_fill 的结算差在面板中稳定为负（-0.08 ~ -0.17pp），与真实样本同向、同量级 => 结算口径的影响比入场日错位更稳定、更可复制。
5. 数据边界：rd7~rd10 入场时 H_fill(74) 需要 rd81~rd84 的行情（数据集只到 rd80），因此这些组合不可测 —— 已在 evidence 中显式留空，未做任何外推。

## 3. 事实结论

### 3.1 已由本轮实验确认（事实）

| # | 事实 | 证据 |
| --- | --- | --- |
| F1 | 已验证执行链中实际入场日 100% = T+6（1,619/1,619），无入场延迟 => 事件日时钟与持有日时钟不发生日期错位 | 1.1 节 |
| F2 | 本报告的 H_fill(5) 定义与引擎逐笔一致：358/358 成交日相同、358/358 成交价在 5.18bp 内（= 滑点） | 0.2 节 |
| F3 | 研究标签口径（事件日收盘）系统性高估可执行收益 7~15bp/笔，方向在所有持有期一致 | 1.3 节 |
| F4 | 各持有期收益分布均值>0、中位<0（右偏），且裂口随持有期单调扩大 | 1.2 节 |
| F5 | 持有期越长，亏损尾部与窗口回撤单调恶化：<=-10% 由 5.2%->34.4%，窗口最差回撤由 -37%->-78% | 1.2 / 1.4 节 |
| F6 | 5% 止损触达率随持有期单调上升：37.8%（K=5）-> 85.8%（K=74） | 1.4 节 |
| F7 | 入场日晚于 rd6 时，两类口径的风险暴露长度相差数个交易日，止损触达率可差 30pp（rd10+K5：35.6% vs 6.0%） | 2 节 |

### 3.2 具有稳定性（可复制）

- 结构层（F1、F2）：由确定性代码路径与逐笔断言保证，重跑可完全复现。
- 结算差（F3）：在全部 6 个持有期为负均值；短持有期在 7/8 年、长持有期在 5/8 年以上为负；受控面板 20 个组合中亦稳定为负 => 方向稳定、量级稳定（约 -0.05 ~ -0.17pp）。
- 分布形态（F4、F5、F6）：在 6 个持有期、3 类口径下方向完全一致，属分布本身的性质而非某年噪声。

### 3.3 仍需后续实验验证

1. 结算差只对 TIME_EXIT 做过逐笔一致性验证；趋势退出、止损、strongHold、Runner 延长这些路径的成交口径尚未逐一验证（它们的成交价可能落在盘中任意价位，不一定是次日开盘）。
2. 入场延迟在真实链中为 0 笔，因此第 2 节的入场错位效应目前只是受控面板推断，未在真实成交中检验（如停牌、开盘涨停一字板导致延迟或无法成交的场景）。
3. 组合层最大回撤：本轮只给出【逐笔窗口回撤】；事件日口径的组合级 MaxDD 在当前引擎中不可直接度量（引擎没有事件日退出的 Exit 类型），本轮没有为此改动架构。
4. 隔夜跳空的成因（流动性冲击 vs 涨停/情绪日效应）本轮未拆解；也未按流动性分层检验结算差是否只是固定成本。
5. 结算差的尾部（负偏）能否通过避开开盘瞬间成交、改用限价/日内择时改善，本轮未测。

## 4. 推荐的下一项研究实验方向（只描述研究问题）

> 研究问题（不构成策略推荐）：在【实际入场 -> 事件日固定离场】口径下，把已经验证的 Runner / Exit 状态变量（newHigh3、连续创新高、MA5/MA10 关系、连续收低等）重新评估一遍，看哪些结论在事件日时钟下会翻转、哪些不翻转。

理由：本轮已证明「标签口径（事件日收盘）」与「可执行口径（持有日信号 -> 次日开盘）」存在稳定的 7~15bp 系统性差，且持有期越长、风险暴露口径差异越大；此前所有 Runner / Exit 结论都建立在持有日时钟 + 次日开盘成交之上。若要把它们转写成事件日坐标系（例如「T+20 之后是否继续持有」这类可跨事件比较的表述），必须先确认哪些结论对时钟选择敏感、哪些不敏感。
